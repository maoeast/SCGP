# 国内园校环境与材料检查

## 环境

- 材料摆放高度是否便于儿童独立取放。
- 动线是否避开门口、热源、水源和高频通行区。
- 是否为轮椅、助行器或需要成人协助的儿童留出空间。
- 标签是否可用图片、文字、颜色或触觉线索理解。
- 是否有安静位置，但不把它设置为惩罚或隔离区域。

## 材料

- 使用符合年龄和学校安全要求的材料，检查尺寸、重量、破损、清洁和误吞风险。
- 优先使用夹取、倾倒、配对、分类、穿脱、整理等真实生活材料。
- 每套材料明确起点、完成状态和归位位置，避免装饰超过功能。
- 允许根据动作和感官需要调整把手、底垫、对比度、数量和步骤。

混龄、长工作周期和专用教具不是每个中国幼儿园或资源教室的实施前提；按现有课程、作息和安全制度选择可行部分。
