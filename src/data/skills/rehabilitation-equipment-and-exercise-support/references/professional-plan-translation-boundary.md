# 既有专业方案的教师转译边界

## 可以协助的内容

当学校持有物理治疗师（PT）、作业治疗师（OT）、医生或校医提供的书面活动方案时，教师端可协助：

- 把已写明的活动顺序改写为学生和教师易懂的提示；
- 准备方案指定的场地、器材和停止信号；
- 按方案中已明确的保护方式组织活动；
- 记录参与情况、可观察反应和需要向原制定人员反馈的问题；
- 在不改变方案要求的前提下，提供课堂中的低风险参与替代方式。

## 不可自行改变的内容

教师不得自行改动方案写明或隐含需要专业判断的内容，包括：

- 次数、时长、速度、阻力、动作幅度和负重；
- 保护方式、体位限制、承重或活动范围限制；
- 矫形器、轮椅、站立架、辅助器具或医疗设备的参数和固定方式；
- 需要被动牵拉、关节处理、手法矫正或身体转移的操作；
- 将方案用于未被专业人员评估过的其他学生。

## 方案不清楚时

缺少书面方案、方案过期、术后或受伤后状态发生变化，或教师不确定学生是否符合其中条件时，应暂停相关活动并向原制定人员核实。家长口头转述、既往经验或“以前做过”不能替代可执行的书面活动边界。
