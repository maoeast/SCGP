# 正式评估边界

## 三类信息

| 层级 | 可由教师端技能处理 | 不可由教师端技能处理 |
| --- | --- | --- |
| 日常观察 | 整理事实、发现参与障碍、设计观察计划 | 由单次表现推断诊断 |
| 教育支持 | 提出课堂调整、记录效果、组织校内会商 | 开具康复处方或决定教育安置 |
| 正式评估 | 解释需要准备哪些去标识化资料 | 模拟施测、补答题目、计算分数或签署结论 |

## 使用平台正式结果

仅在用户提供由规范流程生成的完整结果时，帮助教师理解报告中的教育含义和后续协作事项。保留原报告术语和限定，不重新计算、不改变阈值、不跨量表推断。

出现缺页、来源不明、施测条件不清、年龄或常模不适用时，明确指出无法解释，并建议向报告出具人员核实。
