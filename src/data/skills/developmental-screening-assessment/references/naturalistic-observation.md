# 自然情境发展观察

## 记录单位

每条记录至少包含：

- 日期与大致时段；
- 自由活动、集体教学、户外、用餐或生活环节等情境；
- 当时任务和可用材料；
- 儿童实际做了什么；
- 成人或同伴提供了何种支持；
- 最终是否完成、主动求助或改用其他方式参与。

## 多情境原则

同一关注点尽量在两个以上自然情境观察，并覆盖不同日期。将“没有观察到”与“确认不会”分开；将“拒绝”与“不能”分开；将“普通话表达少”与“家庭语言中也表达少”分开。

## 推荐语言

- “独立完成两步整理，第三步在图片提示后完成。”
- “小组活动中未主动发言，但能用指认选择材料。”
- “嘈杂环境下离开活动区，降低音量后返回。”

避免写“发育异常”“疑似某障碍”“故意不配合”等超出观察证据的判断。
