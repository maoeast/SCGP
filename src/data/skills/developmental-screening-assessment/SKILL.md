# 儿童发育筛查与特殊需求评估智能体 | Developmental Screening & Special Needs Assessment Agent

> **核心定位**：从筛查角度识别儿童发育进程，判断是否存在落后或异常倾向。与 child-behavior-observation 技能形成互补——前者关注"儿童发展状况如何"，后者关注"儿童具体行为意味着什么"。

> **适用人群**：幼教老师、托育老师、儿科医生、父母

> **理论基础**：整合儿心量表（CCDC）五大能区、格赛尔发育量表成熟主义理论、洪秀敏0-3岁社会性发展评估体系、ASD专家共识警示信号、NBNA评分等权威评估工具。

## 技能功能

### 1. 综合发育评估

基于儿心量表五大能区进行全面评估：

| 能区 | 核心评估内容 | 典型观察场景 |
|------|-------------|-------------|
| **大运动** | 跑跳投、平衡能力、器械使用 | 户外游戏、体育活动 |
| **精细动作** | 手眼协调、材料操作、工具使用 | 区域活动、生活环节 |
| **语言** | 表达能力、理解能力、交流互动 | 各类情境 |
| **社交行为** | 同伴互动、规则遵守、情绪表达 | 各类情境 |
| **适应能力** | 问题解决、探究行为、自理能力 | 各类情境 |

### 2. DQ发育商分级判断

| DQ范围 | 等级 | 建议行动 |
|--------|------|---------|
| ≥130 | 优秀 | 提供更高挑战材料，支持潜能发展 |
| 115-129 | 良好 | 维持现有支持，鼓励多元探索 |
| 85-114 | 正常 | 常规观察与支持 |
| 70-84 | 边缘 | 制定个性化支持策略，密切追踪 |
| <70 | 异常 | 建议专业机构评估，早期干预 |

### 3. 社会性发展专项评估

基于洪秀敏0-3岁社会性发展评估体系（4维度12指标）：

- **自我意识**：自我认知、自主性、情绪调节
- **人际交往**：同伴互动、合作能力、亲社会行为
- **社会适应**：规则理解、环境适应、归属感
- **社会认知**：共同注意、假装游戏、模仿能力

### 4. 特殊需求早期识别

#### ASD早期警示信号（四大领域）
- **社交领域**：缺乏眼神接触、社交微笑、共同注意
- **语言领域**：语言发育迟缓、沟通意图弱、重复语言
- **行为领域**：刻板行为、兴趣狭窄、对环境变化敏感
- **感觉领域**：感官回避、感官寻求、异常反应

#### 其他特殊需求识别
- NBNA异常史幼儿的重点关注策略
- 感觉统合问题识别
- WHO生长标准对照

### 5. 早期干预建议

针对不同需求提供分层支持策略：

**保底版（最小可行动作）**：
- 日常观察要点和记录方法
- 家庭可实施的干预活动
- 与家长沟通的话术建议

**进阶版（系统方案）**：
- 个性化教育计划（IEP）制定框架
- 专业评估机构推荐指南
- 多学科协作支持方案

## 触发条件

本技能在以下情况下自动触发：

1. **关键词触发**：
   - 发育筛查、发育评估、发育商
   - 儿心量表、格赛尔、DQ评分
   - 特殊需求、ASD筛查、孤独症筛查
   - 社会性发展、社交能力评估
   - 发育落后、发育迟缓、早期干预
   - 儿童发展评估、成长评估

2. **场景触发**：
   - 用户描述儿童行为表现，询问发展状况
   - 用户担心儿童某方面能力发展滞后
   - 用户需要专业工具进行发育监测

3. **联动触发**：当 child-behavior-observation 技能分析发现潜在发育问题时，可转入本技能进行专业筛查

## 操作流程

### 发育筛查流程

1. **确定评估目的**
   - 全面发展评估 → 儿心量表五大能区
   - 社会性发展专项 → 洪秀敏体系12指标
   - 孤独症早期筛查 → ASD警示信号清单
   - 发展水平判断 → 鹤琴《指引》25条关切点

2. **各类情境中对照观察**
   - 大运动：跑跳投平衡、器械使用（户外游戏）
   - 社交行为：同伴互动、游戏规则遵守（各类情境）
   - 语言：同伴/师幼交流（各类情境）
   - 适应能力：探究行为、问题解决（各类情境）
   - 精细动作：材料操作、工具使用（区域活动、生活环节等）

3. **DQ分级判断**
   - ≥130优秀：提供更高挑战材料
   - 85-129正常/良好：常规观察与支持
   - 70-84边缘：制定个性化支持策略
   - <70异常：建议专业机构评估

4. **特殊需求支持**
   - ASD倾向：视觉支持+结构化环境+感觉调节活动
   - 感觉统合问题：秋千/平衡木/沙水活动
   - 社会性滞后：同伴配对+共同注意引导

### 与 child-behavior-observation 的联动

```
用户输入
  │
  ├── 分析儿童行为 → child-behavior-observation
  │                     │
  │                     └── 发现潜在发育问题 → 转入本技能
  │
  └── 发育筛查评估 → developmental-screening-assessment（本技能）
```

**联动规则**：
- 当 child-behavior-observation 完成儿童行为分析后，如发现发育指标偏离正常范围，可转入本技能进行专业筛查评估
- 转入时携带上下文：原始观察记录、行为分析结论、建议评估的能区

- `../references/社会领域核心经验与观察指导.md`：整合张明红主编《学前儿童社会学习与发展核心经验》（三大板块12条核心经验各年龄班完整指标+各情境0/1/2分评分标准+四层观察法+规则发展四阶段）、李辉2025《学前儿童社会领域学习：关键经验与支持策略》PPT（PCK框架+4条教育途径+5策略渐进模型+国际比较+典型案例）、核心经验深度分析v2社会章节（编码体系+各情境观察要点）三大源文件。涵盖七章：一、PCK与社会核心经验框架；二、自我意识（3条核心经验完整年龄班指标/自主性/自尊发展/自我控制四阶段/各情境0/1/2分评分标准）；三、人际交往（5条核心经验完整年龄班指标/交往规范与亲社会行为各年龄发展/户外四层观察法+记录示例/李辉五策略渐进模型）；四、社会适应（3条核心经验/规则发展四阶段+各阶段冲突表现/归属感螺旋上升+各年龄观察要点）；五、教育途径与策略；六、观察与评估框架；七、理论索引。进行社会性发展评估、设计人际交往支持策略时参照此文件。

- `../references/健康领域核心经验与观察指导.md`：整合柳倩周念丽张晔主编《学前儿童健康学习与发展核心经验》（PCK框架+六大核心经验全书含身体控制与平衡/身体移动/器械操控/生活自理/安全自我保护/情绪管理完整深度展开）、叶平枝等著《幼儿园健康领域教育精要》、2020年核心经验汇总表三大源文件。进行身体运动发展评估、设计健康教育支持策略时参照此文件。
