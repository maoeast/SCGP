# 非惩罚性课堂行为支持

## 记录事实

按“之前发生什么—学生做了什么—随后发生什么”记录，使用可观察语言。例如写“任务发下后离开座位两次，每次约一分钟”，不写“故意逃避”“不听话”。

## 先检查五类因素

1. 是否理解任务和规则。
2. 是否能用现有沟通方式表达求助、暂停、拒绝或完成。
3. 任务难度、长度和等待时间是否合适。
4. 噪声、拥挤、光线、触感或身体不适是否构成障碍。
5. 成人回应是否无意中让问题反复出现。

## 支持顺序

1. 调整环境和任务入口。
2. 明确演示期望行为。
3. 教会等价的沟通或替代行为。
4. 在成功时提供具体、自然的反馈。
5. 逐步淡化提示并跨情境观察。

## 立即升级

出现自伤、伤人、走失风险、疑似虐待、急性精神状态异常、持续疼痛或意识变化时，停止常规训练，保护现场安全并启动学校既有流程。不得用行为训练替代急救、儿童保护或危机处置。
