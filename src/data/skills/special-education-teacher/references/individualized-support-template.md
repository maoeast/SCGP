# 一人一案教师工作模板

只填写去标识化信息；正式档案使用学校批准的系统和表单。

## 基本条目

- 学段/情境：
- 学生优势与兴趣：
- 当前教育目标：
- 可观察的参与障碍：
- 已有效的支持：
- 学生表达的选择或拒绝：

## 本周期支持

| 项目 | 内容 |
| --- | --- |
| 目标 | 在何种情境下完成什么可观察行为 |
| 调整 | 材料、环境、步骤、表达或时间如何调整 |
| 提示 | 使用何种提示，如何逐步淡化 |
| 责任人 | 班主任、学科教师、资源教师、家长或其他人员 |
| 记录 | 次数、持续时间、完成步骤或支持程度 |
| 复盘 | 日期、参与人员、保留/修改/停止哪项支持 |

## 复盘问题

1. 调整是否减少了参与障碍？
2. 学生是否获得更多独立表达和选择机会？
3. 支持是否被一致实施，而非只在资源教室出现？
4. 是否出现疼痛、明显不适、安全风险或功能下降？
5. 下一周期只保留哪 1–3 项关键调整？
