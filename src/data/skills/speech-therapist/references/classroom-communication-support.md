# 课堂通用沟通支持

## 理解支持

- 面向学生、减少背景噪声后再说话。
- 一次表达一个重点，关键词配合图片、实物、动作或板书。
- 让学生复述、指认或演示下一步，避免只问“听懂了吗”。
- 把多步骤任务拆成可见流程，完成一步再呈现下一步。

## 表达支持

- 接受口语、手势、指认、图片、文字或沟通板等多种表达。
- 提供选择而非替学生回答，例如“先休息还是先喝水”。
- 等待后再提示，从开放问题降到选择或指认，不连续追问。
- 扩展学生已有表达，例如学生说“水”，成人回应“想喝水”，不要求反复模仿才满足合理需要。

## 同伴参与

- 选择耐心且愿意等待的同伴，不把同伴当“小老师”。
- 设计有真实沟通需要的轮流任务，而不是只做孤立训练。
- 教全班尊重不同沟通方式，禁止模仿、取笑或催促。

## 普通话与语言差异

先确认家庭语言和方言背景。只在教学目标需要时提供普通话示范，不以口音、方言词汇或第二语言学习阶段作障碍判断。若困难在所有熟悉语言中持续存在并影响功能，再建议专业评估。
