# 教师观察与转介边界

## 建议记录

| 维度 | 记录内容 |
| --- | --- |
| 理解 | 能完成一步还是多步指令，是否依赖情境或视觉提示 |
| 表达 | 主动表达目的、句子长度、替代沟通方式 |
| 互动 | 是否发起、回应、轮流和修复沟通失败 |
| 可懂度 | 熟悉/陌生听者在有无上下文时能否理解 |
| 流畅与声音 | 重复、停顿、用力、回避、声音持续异常等可观察事实 |
| 变化 | 何时开始，稳定、改善、波动还是突然退步 |

## 转介优先级

- **常规协作**：持续影响学习、生活或同伴参与，先汇总跨情境记录，与家长和校内支持人员讨论。
- **听力优先**：对声音反应不一致、经常漏听、音量异常或有听力风险，建议听力相关转介。
- **专业评估**：在熟悉语言中也持续存在理解、表达、语音、流畅或互动困难，由合适的专业人员评估。
- **医疗紧急**：突然失语、意识变化、呼吸异常、明显吞咽风险或神经系统急性表现，立即按急救流程处理。

教师记录用于说明功能影响，不用于给出疾病名称、严重程度或治疗处方。
