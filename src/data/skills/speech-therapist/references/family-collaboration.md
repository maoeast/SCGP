# 家校沟通与家庭泛化

## 沟通框架

1. 先说学生能够使用的沟通方式和近期进步。
2. 描述一个具体课堂情境及其对参与的影响。
3. 询问家庭主要语言、在家沟通方式和家长观察。
4. 共同选择一个自然活动中的小目标，持续一到两周。
5. 约定以简短事实反馈，不要求家庭开展治疗课。

## 低负担家庭活动

- 用餐时提供真实选择，等待学生用任一可行方式表达。
- 整理物品时配合两到三张步骤图片。
- 共读时描述图片、等待回应，不连续测问词汇。
- 学生表达不完整时自然扩展，不强迫重复到“标准”才回应。

## 避免

- 要求家长每天完成大量机械练习。
- 把家庭语言或方言换成普通话作为唯一“治疗”。
- 将教师观察说成诊断结果。
- 承诺通过某项练习在固定期限内恢复或达到同龄水平。
