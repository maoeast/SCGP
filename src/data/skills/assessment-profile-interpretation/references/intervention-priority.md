# 干预优先级排序方法

## 排序原则

教师拿到跨量表画像后，最常问"先练什么"。优先级不是按分数高低简单排序，而是按**影响面 × 严重度 × 可突破性 × 风险**综合判断。

## 四级优先级

### P0 · 安全与健康风险（最高，立即处理）
- 自伤/自杀表达、严重躯体化、持续疼痛、能力明显倒退、听视反应异常。
- 动作：不输出训练建议，立即提示教师启动学校危机处置与属地流程。

### P1 · 影响多个领域的功能短板
- 该领域偏弱且波及至少两个其他领域（如感统失调同时影响社交参与与情绪稳定）。
- 动作：优先排入训练计划，作为干预主线。
- 判断线索：跨量表画像中该领域"确认短板"（领域内多量表一致偏弱）+ 其他领域量表同时异常。

### P2 · 临近突破的能力（见效快、提信心）
- 评分处于"最小辅助/中度辅助"临界（如 WeeFIM 的 3-4 分项），稍微调整环境或提示即可独立完成。
- 动作：作为短期目标优先实现，给家长和教师建立"进步可见"的信心。
- 典型例子：换粗柄勺、加防滑垫、视觉步骤卡后即可独立完成的自理项目。

### P3 · 优势领域维持与延伸
- 画像中的相对优势领域。
- 动作：维持训练频次，不作为主要干预目标；用优势领域作为干预支点（如孩子喜欢公交车，用公交车话题做社交介入）。

## 排序决策示例

| 场景 | 排序 | 理由 |
| --- | --- | --- |
| 感统确认短板 + 社交量表偏低 + 无风险信号 | P1 感统 → P2 社交 | 感统影响面大，先打基础 |
| 生活自理临界项多（S-M 边缘） | P2 自理临界项 | 见效快，建立信心 |
| CBCL 退缩/躯体化高分 | P0/P1 内化问题 | 内耗优先，提示转介评估 |
| 认知正常、无行为问题 | P3 维持 | 无需强干预 |

## 干预目标写法（可复盘）

每个优先级目标写成可观察、可记录的形式：
- 目标 + 当前表现 + 支持措施 + 责任人 + 观察指标 + 复盘日期。
- 避免"提高能力""变得更配合"等不可复盘表述。
- 1-3 周小范围尝试后复盘，无效则调整，不硬撑。

## 边界

- 优先级排序是教育支持建议，不是医疗分级。
- 涉及药物治疗、康复处方、正式评估结论时，转入学校与属地专业流程。
