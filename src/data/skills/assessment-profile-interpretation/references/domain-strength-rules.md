# 领域强弱判定与优势标注规则

## 五大发展领域与对应量表

| 领域 | 平台量表 |
| --- | --- |
| 感觉统合 | CSIRS、CNBS-R2016（儿心量表Ⅱ）、FMDA（小肌肉）、GMFM-88（粗大运动）、TGMD-3（大肌肉） |
| 情绪调节 | Conners PSQ/TRS、CBCL、SDQ（情绪症状部分） |
| 社交沟通 | SRS-2、SDQ（同伴交往部分） |
| 认知发展 | BRIEF（执行功能） |
| 生活自理 | S-M（社会生活能力）、WeeFIM（功能独立性） |

> 注：领域归属以平台 `assessment-profile.ts` 的 SCALE_DOMAIN_MAP 为准；新增量表时同步确认归属。

## 分数方向速查（解读前必看）

- **分高 = 好（正向）**：CSIRS、CNBS-R2016（DQ）、FMDA、GMFM-88、TGMD-3、S-M、WeeFIM。
- **分高 = 问题突出（负向）**：Conners PSQ/TRS（T 分）、SRS-2（T 分）、SDQ（困难分）、CBCL（T 分）、BRIEF（T 分）。
- 每个量表的临界区间（临床/临界/正常）以量表报告与 scoreNote 为准，本规则不做数值替代。

## 领域强弱判定

### 确认短板
- 领域内 ≥2 个量表一致偏弱，且方向正确（负向量表分高、正向分低）。
- 表述："该领域为确认短板，多个量表互相印证。"

### 需观察
- 领域内仅单量表偏弱，或量表间方向不一致。
- 表述："单量表提示需观察，建议结合课堂观察与下次评估确认。"

### 混合信号
- 领域内量表强弱矛盾（如一个正向量表正常、一个负向量表偏高）。
- 表述："该领域呈现混合信号"，列出各量表事实，不强行定性。

### 相对优势
- 领域内 ≥1 个量表处于正常/良好区间，且无矛盾信号。
- 表述："该领域为相对优势"，并说明可作为干预支点的具体能力（如 SDQ 亲社会行为高分、GMFM 某能区领先）。

## 优势标注规则

- 优势领域**必须**出现在画像解读中（不只报短板，避免"全是问题"的误导）。
- 优势要具体到能力而非笼统"某领域好"：如"亲社会行为得分高，可安排班级饲养员角色"。
- 优势用于设计干预入口（用优势带动短板），不用于掩盖短板。

## 纵向变化判定

- 同量表 ≥2 次评估才谈"进步/退步"；
- 比较总分与关键维度变化方向、幅度、是否跨临界区间；
- 变化解读结合年龄（部分量表随年龄有常模变化，避免把常模漂移当真实进步）；
- 单次异常不称趋势。

## 边界

- 领域强弱是教育支持口径，不是医学诊断口径。
- 不输出"XX 障碍风险等级"；显著异常提示前往正规医院发育行为科/精神心理科评估。
