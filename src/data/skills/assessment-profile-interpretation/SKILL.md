# 跨量表学生画像综合解读（教师端）

## 定位

帮助教师综合解读平台上同一学生的**多份量表评估结果**（跨量表画像与纵向趋势），识别领域强弱、跨量表一致性线索和干预优先级。本技能处理的是"多量表横向综合 + 时间纵向对比"的解读方法，不替代单量表的计分规则，不作任何医学或心理诊断。

单量表分数的具体语义（T 分区间、临界值、分高好还是分低好）以各量表报告与 scoreNote 为准，本技能只提供"多量表之间如何互相印证、如何排序干预"的方法。

## 核心原则

- **先方向，后数值**：解读任何分数前先确认该量表"分高=好"还是"分高=差"（CSIRS/运动类分高=好；Conners/SRS-2/SDQ/CBCL/BRIEF 分高=问题突出）。
- **一致性靠印证，分歧靠描述**：多个量表指向同一结论时可用"相互印证"表述；量表间出现矛盾时，描述事实并列出可能的解释，不强行统一。
- **领域强弱看短板，干预排序看影响**：同一领域多量表都偏弱才叫"确认短板"；单量表偏弱称为"需观察"。
- **优势是干预支点**：画像不只报短板，同时标注相对优势领域，用优势带动短板训练。
- **纵向看变化，不追单点**：趋势解读至少需要 2 次同量表评估；单次异常不称"进步/退步"。
- **边界不越**：不输出诊断、不计算发育商/风险等级、不推荐药物或治疗处方。

## 回答前确认

1. 学生已完成的量表与最近评估日期（来自画像数据，未测量表在 untestedScales 中）。
2. 评估时间跨度（同一次集中评估 vs 跨越数月的多次评估）。
3. 是否存在家长/教师评分差异（如 Conners PSQ 与 TRS 同时存在）。
4. 学生年龄与学段（部分量表分年龄解释）。
5. 教师提问目的：整体面貌、干预优先级、家校沟通还是进度复盘。

信息不足时明确列出缺少的量表或时间信息，不基于不全数据下全局结论。

## 工作流程

### 1. 还原领域全貌

按五大发展领域组织画像：感觉统合、情绪调节、社交沟通、认知发展、生活自理。逐领域列出该领域下的量表及各自强弱。

### 2. 标注方向性

为每个量表标注分数方向（正向/负向量表），避免"CSIRS 分低"与"Conners 分高"被误读为同类问题。

### 3. 找一致性线索

跨量表印证的高价值组合（详见 references/cross-scale-patterns.md）：
- **社交沟通偏低 + 感觉统合某维度偏低**：可能互为因果链（感统处理影响社交参与），提示训练顺序（先感统基础，后社交技能）。
- **家长评分低 + 教师评分高（Conners PSQ/TRS 差异）**：环境适应差异信号，不是"谁撒谎"。
- **认知/学业表现强 + 生活自理弱**：能力剪刀差，独立生活能力是干预重点。
- **内化问题（CBCL 退缩/躯体化）高分**：优先介入，即使行为外显不明显。

### 4. 确定领域强弱

- 领域内多数量表偏弱 → **确认短板**；
- 领域内只有单量表偏弱 → **需观察**（不轻易定性）；
- 领域内量表强弱矛盾 → **混合信号**，描述而不定论；
- 标注相对优势领域（干预支点）。

### 5. 排干预优先级

按以下顺序（详见 references/intervention-priority.md）：
1. 安全与健康风险（自伤、躯体化、危机信号）——最高优先级，提示走学校流程；
2. 影响多个领域的功能短板（如感觉统合失调波及社交与情绪）；
3. 确认短板中"临近突破"的能力（辅助一下就能独立，见效快）；
4. 优势领域维持与延伸（不因短板忽略优势）。

### 6. 纵向趋势对比

同一量表 ≥2 次评估时，比较总分与关键维度变化：趋势方向、变化幅度、是否跨过了临界区间。变化解读需结合年龄与常模，不把常模漂移当进步。

### 7. 输出与边界

输出格式：领域强弱摘要 → 一致性发现 → 干预优先级建议 → 需补充的评估 → 边界声明。

## 红线

- 不输出"疑似 XX 障碍/疾病""高风险"等诊断或风险等级表述。
- 不把单量表异常直接定性为领域缺陷。
- 不计算智商、发育商或综合指数。
- 不推荐药物、治疗处方或强制干预。
- 不将 AI 解读写入正式评估结论栏。
- 涉及自伤/伤害风险时，立即提示启动学校危机与属地流程。
