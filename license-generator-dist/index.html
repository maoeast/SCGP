以下说明用于发码时判断应勾选哪些授权能力包。

`sensory_integration` / 感官统合

覆盖感官统合训练主链，以及相关量表、资源与训练入口。

`emotional` / 情绪发展

覆盖情绪场景训练、表达关心训练、情绪小游戏、模块报告，以及情绪调节相关入口。

`social_communication` / 社交沟通

覆盖社交沟通训练入口、相关评估与资源。

`fine_motor` / 精细动作

独立授权能力包，数据归属仍为 `sensory`。

`soothing_aids` / 安抚系统

独立授权能力包，覆盖安抚教具与安抚训练相关入口，数据归属仍为 `emotional`。

`life_skills` / 生活自理

覆盖自理训练顶级入口、`task_training`、生活自理资源，以及相关评估入口。

`cognitive` / 认知发展

当前仍为预留授权位，不代表认知模块已经完整交付。

注意：许可证 payload 的字段名仍保持为 `am`，变更的是其中写入的 code 内容。
