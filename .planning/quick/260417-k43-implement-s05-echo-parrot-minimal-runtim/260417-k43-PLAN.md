# Quick Plan — S05_ECHO_PARROT / 动物传声筒 minimal runtime

## Objective

在已完成 registry 接入的基础上，把 `S05_ECHO_PARROT / 动物传声筒` 补成可启动、可完成、可落库、可在记录详情查看关键指标的一条最小 runtime 闭环；继续保持当前静态路由 + `Page.vue + Game.vue + GameContainer` 模式，不处理 `S03_STORY_SEQ` 已知 bug。

## Current Reality

- `src/data/custom-game-registry.ts` 已存在 `S05_ECHO_PARROT`，归属 `social-communication`，`entryPath` 为 `/emotional/games/echo-parrot`。
- 当前缺口在于：没有 `EchoParrotPage.vue`、没有 `EchoParrotGame.vue`、路由未接入、`src/database/emotional-games-api.ts` 没有 `S05_ECHO_PARROT` 的摘要推导、`src/views/emotional/GameRecordDetail.vue` 没有对应详情分支。
- `Wave 3` 规划提示 `S05_ECHO_PARROT` 的风险在麦克风、音频分析与语音识别兼容性，因此本次最小 runtime 采用“先听提示短句，再通过麦克风做持续发声模仿”的替代模型，不直接引入真正语音识别。

## Tasks

### Task 1 — Implement `S05_ECHO_PARROT` runtime shell, gameplay, and route

- Files:
  - `src/views/emotional/games/EchoParrotPage.vue`
  - `src/components/emotional/games/EchoParrotGame.vue`
  - `src/router/index.ts`
- Action:
  - 新建 `EchoParrotPage.vue`，沿用现有 `GameContainer` 包装模式：`getRequiredCustomGameDefinition('S05_ECHO_PARROT')` + `buildCustomGameLaunchContext(route.query, gameDefinition)`。
  - 在 `src/router/index.ts` 增加懒加载 import 和静态沉浸式路由 `/emotional/games/echo-parrot`，标题用“动物传声筒”。
  - 新建 `EchoParrotGame.vue`，实现最小正式玩法：
    - 开局后用容器预检过的麦克风流建立音量分析；
    - 先做短暂静音校准；
    - 按轮次播放动物提示短句；
    - 孩子对着麦克风持续发声达到阈值和目标时长后算本轮成功；
    - 全部短句完成后自动走既有完成链路。
  - 难度只在组件内做轻量递进：
    - `1`：3 轮、单词/短句模仿、较短目标时长；
    - `2`：4 轮、较长短语模仿；
    - `3`：5 轮、完整短句模仿、目标时长更高。
  - `@complete` payload 只走现有 `performanceData` JSON；至少稳定产出这些字段：
    - `completed_rounds`
    - `target_round_count`
    - `first_try_rounds`
    - `short_attempts`
    - `prompt_replays`
    - `voice_attempt_count`
    - `response_times_ms`
    - `average_response_ms`
    - `voice_durations_ms`
    - `average_voice_ms`
    - `max_continuous_voice_ms`
    - `noise_floor_dbfs`
    - `voice_threshold_dbfs`
    - `mapped_peak_db`
    - `mic_permission_granted`
    - `target_phrase_labels`
    - `completed_phrase_labels`
    - `animal_labels`
    - `session_theme_key`
    - `session_theme_title`
- Verify:
  - `npm run type-check:emotional`
  - 手工烟测：打开 `/emotional/games/echo-parrot?studentId=1&entry=social-communication&difficulty=1`，能开始游戏、听提示、对麦克风发声、完成全部轮次并进入既有完成链路。
- Done:
  - `S05_ECHO_PARROT` 页面、组件、路由全部存在并可编译。
  - 游戏可在不依赖语音识别底座的前提下完成一轮并触发既有落库链路。

### Task 2 — Add `S05_ECHO_PARROT` persistence summaries and record-detail rendering

- Files:
  - `src/database/emotional-games-api.ts`
  - `src/views/emotional/GameRecordDetail.vue`
- Action:
  - 在 `src/database/emotional-games-api.ts` 为 `S05_ECHO_PARROT` 增加摘要推导分支：
    - `deriveAccuracyRate()` 使用 `first_try_rounds / target_round_count`，缺失时回退到 `completed_rounds / voice_attempt_count`；
    - `deriveAvgResponseTime()` 优先从 `response_times_ms` 求均值，再回退到 `average_response_ms`。
  - 在 `src/views/emotional/GameRecordDetail.vue` 增加 `S05_ECHO_PARROT` 的 `metricCards` / `rawRows` 分支，让详情卡片能解释这次动物传声筒互动：
    - 关键表现优先展示：完成回合、首轮模仿、短句重试、平均回应；
    - 补充记录展示：模仿尝试、提示重播、平均发声、最长连续发声、峰值音量、阈值、短句清单、动物清单、主题。
- Verify:
  - `npm run type-check:emotional`
  - 手工烟测：完成一局 `S05_ECHO_PARROT` 后进入训练记录详情，摘要卡和详情卡不为空，并能看到 `S05_ECHO_PARROT` 专属指标。
- Done:
  - `S05_ECHO_PARROT` 记录在列表摘要里不再只剩默认值。
  - `GameRecordDetail.vue` 能稳定展示该游戏的关键指标和原始补充信息。
