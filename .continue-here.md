Teaching materials:

- current teaching-materials page is still the old separate pipeline:
  - data table: `resource_meta`
  - favorites table: `teacher_fav`
  - store: `src/stores/resource.ts`
  - importer: `src/utils/resource-importer.ts`
- current local DB still contains 211 legacy teaching-material rows from the old life-skills era
- simply deleting `resource_meta` rows is **not enough**
  - `src/database/init.ts` still calls `initResourceData(...)`
  - `src/database/resource-data.ts` will repopulate old teaching materials when the table is empty
- next target discussed by user:
  - teaching materials should also be shown by 6 business dimensions:
    - `感官训练`
    - `情绪调节`
    - `社交沟通`
    - `精细动作`
    - `生活自理`
    - `安抚教具`
  - customer delivery model:
    - software installed first
    - license activates allowed modules
    - teaching-material files + CSV are delivered separately
    - customer manually batch-imports them later
  - materials should **not** be bundled into Electron install resources because files are large and legal exposure should stay outside the app package
- current importer is not ready for that delivery flow:
  - still uses old `resource_meta` schema
  - CSV model is old `categoryId`-style
  - file existence checks/path assumptions are not robust enough for customer-side import
  - missing files can still create dead records
