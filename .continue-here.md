Key decisions made in this conversation:

- unify pages incrementally with a user review checkpoint after each page
  - reason: the user explicitly asked for one page at a time and wants to approve the visual direction before scaling
- keep data APIs and business logic unchanged while redesigning pages
  - reason: the current goal is visual/system consistency, not feature refactor
- make `Reports.vue` summary counts follow the currently filtered result set
  - reason: visible table rows and top summary numbers should not disagree
- add `Reports.vue` quick date preset pills matching training-records behavior
  - reason: the user requested `全部 / 本周 / 本月`, and reuse of an existing interaction is better than inventing a new one
