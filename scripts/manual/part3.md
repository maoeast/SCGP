# 第三部分 系统管理

---

## 第14章 班级管理

本章面向管理员。你将在这里管理全校行政班级、分配学生、维护学年信息。

### 14.1 班级列表

在侧边栏点击"班级管理"，进入班级列表页面。页面副标题显示"管理全校行政班级与学生分配 · 共 N 个班级"。

![班级列表页面](screenshots/ch13-class-list.png)

#### 筛选班级

页面顶部提供两种筛选方式：

- **年级标签页**：点击不同年级标签，快速定位该年级下的班级。
- **学年下拉框**：选择某个学年进行查看，默认显示"全部学年"。

#### 统计卡片

列表上方显示四张统计卡片：

| 卡片 | 说明 |
|------|------|
| 总训练次数 | 全校累计完成的训练次数 |
| 总评估次数 | 全校累计完成的评估次数 |
| 平均分 | 全校评估得分的平均值 |
| 活跃班级 | 近期有训练或评估记录的班级数量 |

#### 班级卡片

每个班级以卡片形式展示，包含以下信息：

- 年级和班号（如"一年级 1班"）
- 在籍人数 / 最大人数（如 12 / 30）
- 满员率百分比（进度条 + 数字）
- 状态指示（正常 / 停用）

![班级卡片](screenshots/ch13-class-card.png)

### 14.2 创建班级

#### 单个创建

1. 点击页面右上角的"新建班级"按钮，弹出创建对话框。
2. 填写以下信息：
   - **学年**：下拉选择目标学年。
   - **年级**：下拉选择年级。
   - **班号**：下拉选择班号（如 1班、2班...）。
   - **最大人数**：输入该班级允许的最大在籍人数。
   - **自定义名称**（可选）：勾选"使用自定义名称"，输入你想要的班级名称。
3. 确认信息无误后，点击"确定"完成创建。

![新建班级对话框](screenshots/ch13-create-class.png)

#### 批量创建

当你需要一次性创建多个班级时，使用批量创建功能。

1. 点击"批量创建"按钮，弹出批量创建对话框。
2. 填写以下信息：
   - **学年**：选择目标学年。
   - **年级范围**：选择起始年级和结束年级。
   - **每个年级班数**：输入每个年级要创建的班级数量。
   - **最大人数**：统一设置每个班级的最大在籍人数。
3. 点击"确定"，系统将按年级和班数一次性创建所有班级。

![批量创建对话框](screenshots/ch13-batch-create.png)

### 14.3 管理班级

在班级卡片上，你可以执行以下操作：

| 操作 | 说明 |
|------|------|
| 学生 | 查看该班级的学生列表，进行学生管理 |
| 分配老师 | 为该班级分配任课教师（仅管理员可见） |
| 编辑 | 修改班级名称、最大人数等信息 |
| 删除 | 通过右上角下拉菜单删除班级 |

![班级操作菜单](screenshots/ch13-class-actions.png)

删除班级前，请确认该班级下已无在籍学生。班级删除后不可恢复。

### 14.4 学年管理

点击班级列表页面顶部的"学年管理"按钮，打开学年管理对话框。

![学年管理对话框](screenshots/ch13-academic-year.png)

学年列表显示每条学年的以下信息：

- 学年名称
- 开始日期和结束日期
- 该学年下的班级数和学生数
- 状态标识（"当前学年"或"普通学年"）

#### 新增学年

1. 点击"新增学年"按钮。
2. 输入学年名称（如 2026-2027）。
3. 设置开始日期和结束日期。
4. 如果希望将该学年设为当前活动学年，打开"设为当前学年"开关。
5. 点击"确定"保存。

#### 编辑学年

在学年列表中点击"编辑"按钮，修改学年的名称、日期或当前状态。

## 第15章 学生班级分配

本章面向管理员。你将在这里把学生分配到对应的班级，并在新学年开始时执行升级操作。

### 15.1 进入分配页面

在侧边栏点击"学生分班"，进入学生班级分配页面。

![学生分班页面](screenshots/ch14-student-assignment.png)

### 15.2 分配概览

页面显示所有学生的班级分配状态。你可以按以下条件筛选：

- **按班级**：查看某个班级下的学生。
- **按分配状态**：筛选"已分配"或"未分配"的学生。

每条学生记录显示姓名、年级、当前班级和分配状态。

### 15.3 批量分配

当你需要将多名学生分配到同一个班级时，使用批量分配功能。

1. 在学生列表中勾选需要分配的学生。你可以使用筛选功能先定位未分配的学生。
2. 在页面上方选择目标班级。
3. 点击"确认分配"，系统将把选中学生全部归入目标班级。

![批量分配操作](screenshots/ch14-batch-assign.png)

### 15.4 学年升级

新学年开始时，你需要将学生升级到新的班级。

1. 在学生分班页面点击"学年升级"按钮。
2. 系统将引导你完成升级流程：选择升级方向（升一年级），确认升级名单。
3. 确认后，系统自动将学生迁移到新学年的对应班级。

![学年升级](screenshots/ch14-year-upgrade.png)

升级前请确保新学年和对应班级已经创建完毕。

### 15.5 移出班级

当你需要将某名学生从班级中移除时，在班级的学生列表中操作。

1. 找到目标学生。
2. 点击"移出班级"按钮。
3. 确认操作。

![移出班级](screenshots/ch14-remove-student.png)

移出后，该学生变为"未分配"状态，可以重新分配到其他班级。

## 第16章 系统管理

本章面向管理员。你将在这里管理用户账户、备份数据、配置系统参数和查看授权信息。

### 16.1 进入系统管理

在侧边栏点击"系统管理"，进入系统管理页面。页面副标题显示"集中管理用户权限、数据备份、系统配置与本机运行状态。"

![系统管理页面](screenshots/ch15-system-main.png)

页面包含以下标签页：

1. **用户管理** — 管理系统用户账户和角色权限
2. **数据备份** — 执行数据备份和恢复操作
3. **系统设置** — 配置系统名称、学校信息和品牌样式
4. **关于** — 查看版本号、激活状态和授权信息

"开发者调试"标签页仅在开发环境中可见，正常使用时不会出现。

### 16.2 用户管理

点击"用户管理"标签页，管理系统用户账户。

![用户管理标签页](screenshots/ch15-user-management.png)

#### 创建用户

1. 点击"新建用户"按钮。
2. 填写用户名和密码。
3. 选择角色：**管理员**或**教师**。
4. 点击"确定"完成创建。

![创建用户](screenshots/ch15-create-user.png)

#### 编辑用户

在用户列表中点击"编辑"按钮，修改用户信息和角色。

#### 删除用户

在用户列表中点击"删除"按钮，移除该用户账户。系统会要求你确认此操作。

#### 重置密码

在用户列表中点击"重置密码"按钮，为用户设置新密码。

#### 角色权限说明

| 角色 | 可访问模块 |
|------|-----------|
| 管理员 | 所有模块，包括班级管理、学生分班、系统管理 |
| 教师 | 学生管理、评估、训练、记录、报告、资源中心 |

管理员拥有完整的系统操作权限。教师角色专注于教学和训练相关的日常工作。

### 16.3 数据备份与恢复

点击"数据备份"标签页，管理你的系统数据。

![数据备份标签页](screenshots/ch15-backup.png)

#### 创建备份

1. 点击"立即备份"按钮。
2. 系统将当前全部数据导出为一个 `.dat` 格式的备份文件。
3. 选择保存位置，将备份文件妥善保存。

备份文件覆盖的数据范围：

- 班级信息和学生分配
- 训练计划和训练记录
- 评估记录和报告
- 资源数据和系统配置

#### 恢复数据

当你需要将系统恢复到某个备份时间点的状态时，执行数据恢复。

1. 点击"选择备份文件"，选择一个 `.dat` 格式的备份文件。
2. 系统显示备份信息预览，包括记录数量和表数量。
3. 确认备份文件信息正确后，点击"恢复数据"。

![数据恢复预览](screenshots/ch15-restore.png)

**注意**：恢复数据将覆盖当前系统中的所有数据。此操作不可撤销。请确认备份文件来源可靠、版本匹配后再执行恢复。

### 16.4 系统设置

点击"系统设置"标签页，配置系统参数。

![系统设置标签页](screenshots/ch15-settings.png)

你可以配置以下项目：

| 配置项 | 说明 |
|--------|------|
| 系统名称 | 自定义系统在界面上显示的名称 |
| 学校名称 | 设置你的学校或机构名称 |
| 品牌配置 | 自定义登录页面的视觉样式 |
| 登录主题 | 选择登录页的主题变体 |
| 自定义 Logo | 上传学校或机构的 Logo 图片 |

修改后点击"保存"，配置立即生效。

### 16.5 关于

点击"关于"标签页，查看系统信息。

![关于标签页](screenshots/ch15-about.png)

页面显示以下信息：

- **版本**：当前安装的软件版本号。
- **激活状态**：显示"已激活"、"已激活（剩余 N 天）"或"未激活"。
- **原始授权 code**：开发模式下用于诊断许可证 `am` 载荷中写入的原始授权 code。
- **能力包授权**：列出当前有效的授权能力包，例如感统训练、情绪发展、生活自理等。
- **机器码**：当前设备的唯一机器码标识。

#### 复制机器码

点击"复制机器码"按钮，机器码将自动复制到剪贴板。你需要把机器码提供给供应商来获取激活码。

#### 更新授权

当你购买了新模块或需要续期时：

1. 点击"重新激活 / 更新授权"按钮。
2. 输入供应商提供的新激活码。
3. 系统验证后自动刷新授权状态，新模块即可使用。

![更新授权](screenshots/ch15-activate.png)

### 16.6 软件更新

系统支持自动检查更新。当检测到新版本时，页面会弹出更新提示面板。

![软件更新提示](screenshots/ch15-update.png)

按照面板上的提示操作，即可完成软件更新。更新过程中请保持网络连接，不要关闭应用。

### 附录 B 常见问题（FAQ）

**Q: 忘记密码怎么办？**

A: 请联系系统管理员重置密码。管理员可以在"系统管理 → 用户管理"中为任何用户重置密码。

---

**Q: 激活码可以用于多台设备吗？**

A: 不可以。激活码与设备机器码绑定，一个激活码仅限一台设备使用。更换设备需要获取新的激活码。

---

**Q: 备份文件可以跨设备使用吗？**

A: 可以。你在 A 设备上导出的 `.dat` 备份文件，可以在 B 设备上通过"数据恢复"功能导入。

---

**Q: 教师可以看到所有学生吗？**

A: 可以。教师角色可以查看和管理所有学生的信息、评估记录和训练记录。教师无法访问系统管理和班级管理功能。

---

**Q: 新增模块后如何激活？**

A: 进入"系统管理 → 关于"，点击"重新激活 / 更新授权"，输入包含新模块的激活码即可。无需重新安装软件。

---

**Q: 数据存储在哪里？**

A: 所有数据存储在本地设备上，不上传到云端。请定期使用数据备份功能导出备份，防止数据丢失。

---

**Q: 如何更换设备？**

A: 按以下步骤操作：

1. 在旧设备上执行数据备份，导出 `.dat` 文件。
2. 在新设备上安装软件，使用新机器码获取新的激活码并激活。
3. 在新设备上执行数据恢复，导入旧设备的备份文件。

---

**Q: 备份恢复后数据不完整怎么办？**

A: 请确认备份文件的版本与当前软件版本匹配。如果版本差异较大，建议联系技术支持协助处理。
