## 第1章 产品概述

### 1.1 产品简介

SCGP（星愿能力发展平台）是为特殊教育学校和康复机构设计的能力评估与训练管理系统。平台覆盖从能力基线评估到个性化训练计划制定、再到训练执行与效果追踪的完整工作流。

**核心价值：**

- **标准化评估** — 内置 12 个专业评估量表，覆盖感觉统合、情绪调节、社交沟通、生活自理等维度。
- **个性化训练** — 根据评估结果制定 IEP（个性化教育计划），关联跨模块训练资源。
- **数据驱动** — 自动生成评估报告和训练趋势分析，支持教学决策。

## 第2章 安装与激活

### 2.1 安装

平台提供 Windows 和 Linux 两种安装包。请联系软件供应商获取安装文件。

#### Windows 安装

1. 双击安装包文件（文件名格式：`SCGP 星愿能力发展训练系统_x.x.x.exe`）。
2. 如果系统弹出"用户账户控制"提示，点击"是"允许安装程序运行。
3. 阅读许可协议后，勾选"我接受协议"，点击"下一步"。
4. 选择安装路径，或保持默认路径，点击"下一步"。

   ![截图：Windows 安装路径选择界面](screenshots/win-install-path.png)

5. 点击"安装"开始安装。
6. 安装完成后，勾选"运行 SCGP 星愿能力发展训练系统"，点击"完成"。

   ![截图：Windows 安装完成界面](screenshots/win-install-finish.png)

安装程序会在桌面创建快捷方式，并在开始菜单中添加程序入口。

#### Linux 安装（信创系统）

平台提供 `.deb` 和 `.AppImage` 两种 Linux 安装包，适用于银河麒麟、统信 UOS 等信创操作系统。

**使用 deb 包安装（适用于 Debian/Ubuntu 系及银河麒麟、统信 UOS）：**

1. 打开终端，进入安装包所在目录。
2. 执行安装命令：

   ```
   sudo dpkg -i SCGP星愿能力发展训练系统_x.x.x_amd64.deb
   ```

3. 如果提示缺少依赖，执行：

   ```
   sudo apt-get install -f
   ```

4. 安装完成后，在应用菜单中找到"SCGP 星愿能力发展训练系统"启动。

**使用 AppImage 运行（免安装，适用于所有 Linux 发行版）：**

1. 打开终端，进入安装包所在目录。
2. 添加可执行权限：

   ```
   chmod +x SCGP星愿能力发展训练系统_x.x.x_amd64.AppImage
   ```

3. 双击 AppImage 文件，或在终端中执行：

   ```
   ./SCGP星愿能力发展训练系统_x.x.x_amd64.AppImage
   ```

**注意：** 部分信创系统默认禁用 AppImage 运行。如果双击无法启动，请先在终端中执行 `sudo apt install libfuse2`（Debian 系）或联系系统管理员开放 FUSE 权限。

### 2.2 首次启动

安装完成后，通过以下方式启动平台：

- **Windows**：双击桌面上的"SCGP 星愿能力发展训练系统"图标。
- **Linux**：在应用菜单中找到"SCGP 星愿能力发展训练系统"，或双击桌面快捷方式。

首次启动时，平台会自动检测激活状态。未激活的设备会进入激活页面。

![截图：首次启动进入激活页面](screenshots/first-launch-activation.png)

### 2.3 软件激活

首次使用前，你需要完成软件激活。激活页面标题为"软件未激活"。

![截图：激活页面](screenshots/activation-page.png)

**激活步骤：**

1. 在激活页面找到"您的机器码"区域。
2. 点击机器码右侧的"复制"按钮，将机器码复制到剪贴板。

   ![截图：复制机器码](screenshots/copy-machine-code.png)

3. 将机器码发送给软件供应商：
   - **供应商**：杭州炫灿科技有限公司
   - **服务热线**：0571-86087889
4. 收到供应商返回的激活码后，在"输入激活码"框中粘贴。激活码格式为 `SPED-XXXX...`。
5. 点击"验证激活码"按钮。
6. 页面提示"激活成功！"后，系统自动跳转到登录页面。

   ![截图：激活成功提示](screenshots/activation-success.png)

**关于激活，你需要了解以下规则：**

- 激活码与当前设备绑定，不可转移到其他设备。
- 平台支持永久激活和限时激活（如 1 年、3 年）。限时激活到期后需重新获取激活码。
- 激活数据使用 RSA 数字签名加密存储，确保授权信息安全。

### 2.4 登录

激活完成后，进入登录页面。页面标题为"用户登录"，系统名称为"星愿能力发展训练系统"。

![截图：登录页面](screenshots/login-page.png)

**登录步骤：**

1. 在"用户名"输入框中输入你的账号。
2. 在"密码"输入框中输入你的密码。
3. 如果你希望下次打开时自动填充用户名，勾选"记住账号"。
4. 点击"登录系统"按钮进入系统首页。

   ![截图：填写登录信息](screenshots/login-form-filled.png)

**角色说明：**

- **管理员** — 拥有所有模块的访问权限，包括班级管理、学生分班、系统管理等。
- **教师** — 可访问教学相关模块，包括学生管理、能力评估、训练计划、游戏训练、器材训练等。

首次使用时，请向学校管理员索取你的登录账号和初始密码。

### 2.5 试用说明

平台在未激活状态下支持试用。试用期间你可以体验全部功能。

试用有以下限制：

- 试用有次数限制，超出次数后需激活才能继续使用。
- 试用期间产生的数据可能无法长期保存，正式激活后建议重新录入。

建议在试用期内完成熟悉操作流程，确定采购后尽快完成正式激活。
