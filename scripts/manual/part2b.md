# 第8章 游戏训练

## 8.1 游戏训练流程

游戏训练是平台的核心训练方式之一。每个游戏针对特定能力维度设计，训练过程中系统自动采集数据。

完整流程分为五步：

1. 选择训练入口组
2. 选择学生
3. 进入游戏大厅
4. 开始游戏
5. 查看结果

![游戏训练完整流程](screenshots/game-training-flow.png)

## 8.2 模块菜单

在侧边栏点击"游戏训练"进入游戏训练页面。页面标题下方显示副标题"选择训练入口组开始游戏训练"。

![游戏训练模块菜单](screenshots/game-module-menu.png)

页面以卡片形式展示所有训练入口组。每个入口组对应一个训练模块，卡片内容包括：

- 入口组名称与描述
- 游戏数量
- 状态标签："已激活"表示可用，"未授权"表示未购买

平台当前提供以下入口组：

| 入口组 | 图标 | 说明 |
|--------|------|------|
| 感觉统合 | 🎮 | 感觉统合训练游戏 |
| 情绪调节 | 😊 | 情绪调节训练游戏 |
| 社交沟通 | 👥 | 社交沟通训练游戏 |
| 精细运动 | 🧩 | 精细运动训练游戏 |
| 安抚辅助 | 🧸 | 安抚辅助训练游戏 |
| 生活自理 | 🏠 | 生活自理训练游戏与任务训练入口 |

实际显示的入口组取决于你购买和激活的模块。未授权的入口组显示灰色遮罩和锁定图标。点击未授权卡片会提示"未授权，请联系厂商购买"。

## 8.3 选择学生

点击已激活的入口组卡片后，进入学生选择页面。页面顶部显示当前入口组名称和"选择学生"标识。

![游戏训练选择学生](screenshots/game-select-student.png)

从学生列表中找到要训练的学生。你可以按班级筛选学生，也可以通过搜索框快速定位。

选中学生后，系统自动跳转到游戏大厅。如果你从情绪调节入口组进入且指定了子模块（如情绪场景、表达关心），会直接跳转到对应子模块页面。

## 8.4 游戏大厅

选择学生后进入游戏大厅。页面顶部显示面包屑导航和当前学生姓名，方便你确认上下文。

![游戏大厅](screenshots/game-lobby.png)

页面分为左右两栏：

- **左侧**：游戏列表。按资源分类组织，支持按类别筛选。
- **右侧**：游戏预览。显示选中游戏的名称、描述、配置参数。

点击左侧的游戏卡片，右侧会显示该游戏的详细信息。部分游戏支持配置训练参数（如网格大小、轮次、时间限制）。

页面右上角提供"切换入口"下拉框。你可以在不返回学生选择页的情况下切换到其他已激活的入口组。

### 情绪类游戏

情绪调节入口组的游戏大厅有专用布局。左侧以卡片列表展示游戏，每张卡片包含：

- 游戏名称
- 治疗目标标签
- 预估时长

选中游戏后，右侧预览区显示：

- 玩法说明
- 重复可玩提示
- 难度选择（简单 / 中等 / 困难）

部分合作类游戏（如合作造汉堡）需要选择第二位学生作为搭档。系统会在预览区显示"协作伙伴"选择框，从当前学生列表中选择一位搭档。

![情绪游戏大厅预览](screenshots/emotional-game-lobby.png)

### 开始游戏

确认游戏和参数后，点击"开始游戏"按钮。系统进入游戏播放页面。

## 8.5 游戏进行中

游戏采用全屏沉浸模式运行。屏幕顶部显示游戏标题、当前学生姓名和训练参数。

![游戏进行中](screenshots/game-playing.png)

游戏类型不同，操作方式也不同：

- **网格类游戏**：在网格中点击目标图片或听音选择
- **视觉追踪游戏**：追踪屏幕上移动的目标
- **音频辨别游戏**：听声音后选择对应图片

训练过程中，系统自动记录以下数据：

- 完成状态（已完成 / 未完成）
- 正确率
- 每次响应的时间
- 提示使用次数
- 总训练时长

游戏结束后，系统显示结果摘要页面。你可以选择：

- 返回游戏大厅继续其他游戏
- 查看本次训练的详细记录

## 8.6 IEP 报告

游戏训练完成后，系统可以生成 IEP（个别化教育计划）评估报告。

![IEP 报告](screenshots/iep-report.png)

报告内容包括：

- 学生基本信息
- 训练任务名称
- 各能力维度的表现评估
- 教学建议
- 报告生成日期

报告页面顶部提供导出按钮：

- **导出 PDF**：生成 PDF 格式文件，适合打印归档
- **导出 Word**：生成 Word 格式文件，适合二次编辑

导出的文件会保存到系统默认下载目录。

# 第9章 器材训练

## 9.1 器材训练流程

器材训练用于记录学生在实体器材上的训练表现。教师通过表单录入训练数据，系统自动归档。

完整流程分为三步：

1. 选择训练入口组
2. 选择学生
3. 快速录入数据

![器材训练完整流程](screenshots/equipment-training-flow.png)

## 9.2 器材菜单

在侧边栏点击"器材训练"进入器材训练页面。页面标题下方显示副标题"选择训练入口组开始器材训练"。

![器材训练模块菜单](screenshots/equipment-module-menu.png)

页面布局与游戏训练菜单一致。每个入口组卡片显示：

- 入口组名称与描述
- 该入口组下的器材数量
- 状态标签："已激活"或"未授权"

入口组与游戏训练共用同一套模块体系。实际显示的入口组取决于你购买的模块。

## 9.3 选择学生

点击已激活的入口组卡片后，进入学生选择页面。

![器材训练选择学生](screenshots/equipment-select-student.png)

操作方式与游戏训练一致：从列表中选择要录入数据的学生。选中后系统跳转到快速录入页面。

## 9.4 快速录入

选择学生后进入快速录入页面。页面分为左右两栏：

- **左侧**：器材选择器。按分类展示当前入口组下的所有器材，支持按类别筛选。
- **右侧**：数据录入表单。表单内容根据所选器材类型动态变化。

![器材快速录入](screenshots/equipment-quick-entry.png)

### 录入步骤

1. 从左侧选择一个器材
2. 在右侧表单中填写训练数据
3. 点击提交

表单包含以下字段（根据器材类型动态显示）：

- **评分**：本次训练的得分
- **提示等级**：学生完成时需要的辅助程度
- **训练时长**：本次训练持续时间（秒）
- **备注**：补充说明

### 提交后的操作

提交成功后，系统弹出确认对话框，提供两个选项：

- **继续为该生录入**：保留当前学生，清空器材选择，继续录入其他器材数据
- **返回学生列表**：回到学生选择页，换一位学生

你也可以使用"保存并继续"按钮快速连续录入，不弹出确认对话框。

### 从训练计划跳转

如果你从训练计划页面跳转到器材录入，系统会自动选中计划中指定的器材，并显示"来自训练计划"标签。录入完成后，点击"返回计划"回到训练计划页面。

同样，从首页日程跳转时，系统显示"来自首页日程"标签，完成后返回首页。

### 切换入口组

页面右上角提供"切换入口"下拉框。你可以在录入过程中切换到其他入口组，切换后左侧器材列表会同步更新。

## 9.5 器材训练记录

器材训练数据提交后自动保存到系统中。你可以通过以下方式查看历史记录：

1. 在侧边栏点击"训练记录"
2. 选择对应入口组
3. 切换到"器材训练记录"标签

详细操作参见第10章。

# 第10章 训练记录

## 10.1 训练记录菜单

在侧边栏点击"训练记录"进入训练记录页面。页面标题下方显示副标题"选择训练入口查看对应的游戏记录与器材记录"。

![训练记录菜单](screenshots/training-records-menu.png)

页面以卡片形式展示所有训练入口组。每个卡片包含：

- 入口组名称与描述

- 器材记录数量
- 状态标签："已激活"或"未授权"

未授权的入口组显示灰色遮罩，点击时提示未授权。

## 10.2 模块训练记录

点击已激活的入口组卡片，进入该模块的训练记录页面。页面顶部显示面包屑导航和入口组名称，右侧提供"切换入口"下拉框和"返回列表"按钮。

![模块训练记录](screenshots/module-training-records.png)

页面通过标签页切换两种记录类型：

- **游戏训练记录**：显示该模块下所有游戏训练记录
- **器材训练记录**：显示该模块下所有器材训练记录

### 游戏训练记录

游戏训练记录面板顶部显示统计概览卡片：

- 总记录数
- 平均正确率
- 平均响应时间
- 总训练时长

![游戏训练记录面板](screenshots/game-records-panel.png)

面板提供以下筛选条件：

- **学生筛选**：下拉选择特定学生
- **时间范围**：选择起止日期
- **快捷筛选**：点击"全部"、"本周"、"本月"按钮快速设定时间范围
- **刷新**：点击刷新按钮重新加载数据

筛选后，记录以表格形式展示。表格列包括：

- 学生姓名
- 游戏名称
- 正确率
- 响应时间
- 训练日期

### 器材训练记录

器材训练记录面板的布局和筛选方式与游戏训练记录类似。

![器材训练记录面板](screenshots/equipment-records-panel.png)

表格列包括：

- 学生姓名
- 器材名称
- 评分
- 提示等级
- 训练时长
- 训练日期

点击记录可以查看该次器材训练的详细信息。

# 第11章 报告中心

## 11.1 报告中心概览

在侧边栏点击"报告生成"进入报告中心。页面标题下方显示副标题"统一查看和管理评估、训练与情绪模块报告，减少跨模块查找成本。"

![报告中心概览](screenshots/report-center-overview.png)

报告中心将评估报告、训练报告、情绪模块报告统一展示在一个页面。你不需要到各个模块分别查找报告。

页面分为三个区域：

1. **筛选条件栏**：设置筛选参数
2. **报告分布概览**：按类型显示报告数量统计
3. **报告列表**：以表格展示所有报告

## 11.2 筛选报告

![报告筛选条件](screenshots/report-filters.png)

筛选条件栏提供以下选项：

- **学生**：下拉选择框，默认"全部学生"。选择特定学生后只显示该学生的报告。
- **报告类型**：下拉选择框，默认"全部类型"。选择特定类型后只显示该类型的报告。
- **时间范围**：日期范围选择器。点击后选择开始日期和结束日期。
- **快捷范围按钮**：点击"全部"、"本周"、"本月"快速设定时间范围。选中的按钮会高亮显示。
- **查询**：点击执行筛选。
- **重置**：点击清除所有筛选条件，恢复默认。

所有筛选条件可以组合使用。例如，你可以同时选择某位学生和"本周"来查看该学生本周的所有报告。

## 11.3 报告类型说明

平台支持以下报告类型：

| 报告类型 | 来源模块 | 说明 |
|---------|---------|------|

| WeeFIM 评估报告 | 能力评估 | 儿童功能独立性评估结果 |
| CSIRS 评估报告 | 能力评估 | 儿童感觉统合能力评估结果 |
| Conners PSQ 报告 | 能力评估 | 家长问卷评估结果 |
| Conners TRS 报告 | 能力评估 | 教师问卷评估结果 |
| SDQ 评估报告 | 能力评估 | 长处与困难问卷评估结果 |
| SRS-2 评估报告 | 能力评估 | 社交反应量表评估结果 |
| CBCL 评估报告 | 能力评估 | 儿童行为量表评估结果 |
| 儿心量表II评估报告 | 能力评估 | 0~6岁儿童发育量表评估结果 |
| 小肌肉功能发展评估报告 | 能力评估 | 精细运动能力评估结果 |
| GMFM-88 评估报告 | 能力评估 | 粗大运动功能评估结果 |
| TGMD-3 评估报告 | 能力评估 | 基本运动技能评估结果 |
| 情绪行为调节模块报告 | 情绪行为 | 情绪训练汇总报告 |

| 训练报告 | 训练计划 | 训练计划执行报告 |

### 报告分布概览

筛选条件下方显示两个统计面板：

- **评估报告**：按各量表类型展示报告数量，右上角显示评估报告总数
- **训练与干预报告**：展示情绪模块报告、IEP 报告、训练报告的数量

![报告分布概览](screenshots/report-distribution.png)

这些统计会随筛选条件实时更新。

## 11.4 查看与导出报告

报告列表以表格形式展示在页面底部。表格列包括：

| 列名 | 说明 |
|------|------|
| ID | 报告记录编号 |
| 报告标题 | 报告的标题文本 |
| 学生姓名 | 关联的学生 |
| 报告类型 | 以彩色标签显示报告类型 |
| 创建时间 | 报告生成的时间 |
| 操作 | 查看 / 下载 / 删除 |

![报告列表](screenshots/report-list.png)

### 操作说明

- **查看**：点击后跳转到对应报告的详情页面。评估报告跳转到评估结果页，IEP 报告跳转到游戏报告页，情绪模块报告跳转到情绪报告页。
- **下载**：点击后跳转到报告详情页，在报告页面中执行导出操作。报告支持导出为 PDF 或 Word 格式。
- **删除**：点击后弹出确认对话框。确认后删除该报告记录。删除操作不可撤销，请谨慎操作。

### 分页

表格底部提供分页控件。你可以选择每页显示 10、20、30 或 40 条记录。分页右侧显示当前筛选结果的总条数。

## 11.5 历史数据迁移

如果你从旧版本升级到新版本，部分旧数据可能没有对应的报告记录。页面右上角提供"迁移历史数据"按钮。

![迁移历史数据](screenshots/report-migration.png)

点击按钮后，系统弹出确认对话框，说明迁移不会删除已有数据。点击"开始迁移"后：

- 按钮文字变为"迁移中..."
- 系统为历史评估数据自动创建对应的报告记录
- 迁移完成后弹出提示，显示处理的记录条数
- 报告列表自动刷新

如果没有需要迁移的数据，系统提示"没有需要迁移的数据"。

# 第12章 资源中心

## 12.1 资源中心概览

在侧边栏点击"资源中心"进入资源中心页面。页面标题下方显示副标题"统一管理训练资源与教学资料，在同一入口完成浏览、维护、导入与素材目录管理。"

![资源中心概览](screenshots/resource-center-overview.png)

资源中心通过顶部标签页切换两个子模块：

- **训练资源**：管理游戏和器材资源
- **教学资料**：管理教学文件和素材

点击标签页即可切换，当前选中的标签页会高亮显示。

## 12.2 训练资源管理

点击"训练资源"标签页进入训练资源管理页面。页面分为左右两栏：左侧为筛选面板，右侧为资源列表。

![训练资源管理](screenshots/training-resources.png)

### 筛选与搜索

左侧筛选面板提供以下筛选条件：

**搜索框**：输入关键词搜索资源名称。输入后系统自动搜索，无需手动点击。

**业务分组**：单选按钮组，按训练模块分组筛选。每个选项对应一个模块（如感官训练、情绪调节、社交沟通等）。

**展示类型**：单选按钮组，按资源类型筛选。

- 全部：显示所有类型
- 游戏：只显示游戏类资源
- 器材：只显示器材类资源
- 场景：只显示场景类资源
- 自理任务：只显示生活自理任务训练资源

**状态筛选**：复选框组。

- 勾选"启用中"：显示正常使用的资源
- 勾选"已禁用"：显示已禁用的资源
- 同时勾选：显示全部资源

**底部统计**：显示当前筛选条件下的资源总数，并分别统计系统预置资源和自定义资源的数量。

### 资源列表

右侧主区域以表格形式展示资源列表。

![资源列表表格](screenshots/resource-table.png)

表格包含以下列：

| 列名 | 说明 |
|------|------|
| 封面 | 资源的封面图片或类型图标。器材类资源显示实际图片缩略图，其他类型显示对应图标 |
| 资源名称 | 资源标题，下方显示简短描述 |
| 分类 | 资源所属分类（如触觉、前庭觉、本体觉等） |
| 来源 | "系统"或"自定义"标签。系统资源旁显示锁定图标，自定义资源旁显示星形图标 |
| 状态 | 启用/禁用开关。点击开关切换资源状态 |
| 标签 | 资源关联的能力标签，最多显示3个，超出部分显示数量 |
| 操作 | 编辑 / 删除 / 恢复 |

### 状态管理

资源的启用和禁用通过状态开关控制。

- 点击开关从"启用"切换到"禁用"：该资源不再出现在训练选择列表中
- 点击开关从"禁用"切换到"启用"：该资源重新出现在训练选择列表中

### 删除与恢复

- **自定义资源**：可以删除。点击"删除"后弹出确认对话框，确认后资源被禁用（不会真正从数据库移除）。
- **系统预置资源**：不可删除。删除按钮显示为灰色，鼠标悬停时提示"系统预置资源不可删除，仅支持编辑描述和标签"。
- **已禁用资源**：操作列显示"恢复"按钮。点击后资源重新启用。

### 创建与编辑资源

点击资源列表上方的"新建资源"按钮创建自定义资源。

![编辑资源对话框](screenshots/resource-edit-dialog.png)

点击表格中的"编辑"链接修改资源信息。编辑对话框包含以下字段：

- **封面图片**：显示当前封面，自定义资源支持更换
- **资源名称**：自定义资源可修改，系统资源不可修改（显示锁定图标）
- **所属分类**：自定义资源可修改，系统资源不可修改
- **详细描述**：所有资源均可编辑
- **能力标签**：所有资源均可编辑。支持从已有标签中选择，也支持手动输入新标签

### 情绪资源编辑器

情绪类资源提供专用编辑器，提供更精细的内容编辑能力：

- **情绪场景编辑器**（EmotionSceneEditor）：编辑情绪识别训练的场景图片和选项
- **表达关心编辑器**（CareExpressionEditor）：编辑关心行为训练的场景和评价内容

![情绪场景编辑器](screenshots/emotion-scene-editor.png)

### 自理任务编辑器

生活自理任务资源使用专用的步骤编辑器。任务资源继续保存到统一训练资源主表中，资源类型为"自理任务"，授权归属为"生活自理"。

![自理任务步骤编辑器](screenshots/self-care-task-editor.png)

编辑器支持维护以下内容：

| 内容 | 说明 |
|------|------|
| 任务名称 | 显示在自理训练任务列表和训练执行页面中 |
| 任务描述 | 说明任务目标、适用场景和教学提示 |
| 封面图片 | 用于任务卡片和资源列表展示 |
| 步骤说明 | 按顺序维护每一步的操作提示 |
| 步骤图片 | 给学生展示当前步骤的视觉提示 |
| 步骤视频 | 可选，用于演示动作或流程 |
| 步骤音频 | 可选，用于播放口头提示 |

保存后，该任务会同时出现在资源中心和自理训练任务列表中。

## 12.3 资源导入导出

情绪模块资源支持打包导入导出。在训练资源页面的工具栏中找到"导入资源包"和"导出资源包"按钮。

![资源导入导出](screenshots/resource-import-export.png)

### 导出资源包

点击"导出资源包"按钮，系统将当前所有情绪资源打包为文件。导出的文件包含情绪场景数据和相关元信息。

### 导入资源包

点击"导入资源包"按钮，打开导入对话框。

![导入资源包对话框](screenshots/resource-pack-import.png)

导入步骤：

1. 点击"选择资源包"按钮，选择 JSON 或 Excel 格式的资源包文件
2. 选择重复处理策略：
   - **跳过重复**：遇到同名资源时跳过，不覆盖
   - **更新已有**：遇到同名资源时用新数据覆盖旧数据
   - **导入副本**：不论是否重复，都创建一条新记录
3. 确认后开始导入

导入完成后，系统显示导入结果统计：成功导入多少条、失败多少条。

## 12.4 教学材料管理

点击"教学资料"标签页进入教学材料管理页面。页面分为左右两栏：左侧为业务维度导航，右侧为材料列表和操作区。

![教学资料管理](screenshots/teaching-materials.png)

### 筛选与搜索

左侧导航面板按业务维度组织教学材料：

- 全部资料
- 感官训练
- 情绪调节
- 社交沟通
- 生活自理
- 精细运动
- 安抚教具

点击某个维度后，右侧只显示该维度下的材料。每个维度旁显示材料数量。

右侧工具栏提供：

- **搜索框**：输入关键词搜索教学资料
- **收藏筛选**：点击"我的收藏"按钮只显示已收藏的资料，再次点击切换回"全部资料"
- **资料类型筛选**：按资料类型（视频、图片、文档、音频）筛选

### 管理教学材料

#### 上传资料

点击"上传资料"按钮，打开上传对话框。

![上传教学资料](screenshots/teaching-material-upload.png)

填写以下信息：

1. 资料标题（必填）
2. 业务维度（必填）：选择资料所属的训练维度
3. 资料文件：选择本地文件
4. 标签：多个标签用逗号分隔
5. 描述：补充说明

点击"上传"提交。系统将文件复制到受管目录并记录到数据库。

#### 批量导入

点击"批量导入"按钮，打开批量导入对话框。

![批量导入教学资料](screenshots/teaching-material-batch-import.png)

批量导入适用于一次添加大量教学材料。操作步骤：

1. **选择素材目录**：点击"选择素材目录"按钮，选择存放原始文件的文件夹
2. **下载 CSV 模板**：点击"下载CSV模板"获取导入模板文件
3. **按模板填写 CSV**：在模板中填写每条资料的标题、维度、文件名等信息
4. **上传 CSV**：选择填写好的 CSV 文件
5. **开始导入**：点击"开始导入"

导入规则：

- 系统先校验 CSV 中列出的每个文件是否存在于素材目录中
- 文件存在的资料会被复制到受管目录并写入数据库
- 文件缺失的资料不会写入，会在结果中报告错误

导入完成后显示结果统计：成功导入数量和失败数量。如果有失败项，会列出前 20 条错误信息。

#### 收藏管理

每条教学材料右侧提供收藏按钮（星形图标）。

- 点击空心星：添加到收藏
- 点击实心星：取消收藏

点击工具栏的"我的收藏"按钮切换收藏视图。收藏视图下只显示已收藏的材料。

#### 查看与删除

每条材料提供操作按钮：

- **查看**：打开资料文件（调用系统默认程序）
- **详情**：打开详情对话框，显示完整的元信息
- **删除**：弹出确认对话框，确认后删除该资料

#### 导出 CSV

教学材料列表支持导出为 CSV 文件，用于数据备份或迁移。

#### 素材目录

首次使用批量导入前，需要选择素材目录。素材目录是存放原始文件的本地文件夹路径。系统会记住你选择的路径，下次打开时自动恢复。你可以随时通过"选择素材目录"或"更换素材目录"按钮修改路径。

# 第13章 自理训练

## 13.1 自理训练概览

自理训练用于组织生活自理和生活适应类任务。教师可以把洗手、穿衣、刷牙、餐前准备、整理书包等任务拆成标准步骤，并在训练过程中逐步记录学生完成情况。

在侧边栏点击"自理训练"，系统进入自理任务列表页面。页面标题为"自理训练"，副标题说明该模块用于通过标准化任务培养孩子生活自理与生活适应能力。

![自理训练任务列表](screenshots/self-care-task-list.png)

自理训练与资源中心共用同一套任务资源数据。你可以在资源中心创建自理任务，也可以从自理训练页面进入任务编辑。

## 13.2 任务列表

任务列表以卡片形式展示当前可用的自理任务。页面支持按任务类别筛选，常见类别包括个人卫生、穿脱整理、用餐准备、物品整理等。

每张任务卡片通常包含：

- 任务名称
- 任务说明
- 步骤数量
- 关联图片或封面
- 开始训练、编辑等操作入口

当系统中还没有自理任务时，页面显示"暂无自理任务"，可点击"创建第一条任务"开始配置。

## 13.3 新建与编辑任务

点击"新建任务"进入任务编辑页面。编辑页面与资源中心的自理任务步骤编辑器保持一致。

![新建自理任务](screenshots/self-care-task-create.png)

配置任务时，建议按真实教学流程拆分步骤。例如"洗手"任务可以拆为打开水龙头、打湿双手、涂抹洗手液、搓手、冲洗、擦干等步骤。

每个步骤可以填写：

| 字段 | 说明 |
|------|------|
| 步骤文本 | 给教师和学生看的操作提示 |
| 图片路径 | 展示当前步骤的图片 |
| 视频路径 | 可选，播放动作演示 |
| 音频路径 | 可选，播放语音提示 |

任务保存后会写入统一训练资源模型，后续可从自理训练、训练计划或资源中心复用。

## 13.4 选择学生

在任务卡片上点击"开始训练"后，系统进入学生选择页面。

![自理训练选择学生](screenshots/self-care-select-student.png)

选择学生后，系统进入该任务的沉浸式执行页面。若任务是从训练计划或其他入口启动，页面会自动带入学生与任务上下文。

## 13.5 执行训练

自理任务执行页面采用全屏工作区布局。左侧展示当前步骤图片、步骤说明和步骤导航；右侧记录学生在当前步骤的完成情况。

![自理任务执行页面](screenshots/self-care-task-execution.png)

教师需要按步骤记录以下信息：

| 记录项 | 说明 |
|--------|------|
| 完成等级 | 独立完成、口头提示、协助完成、未完成 |
| 错误等级 | 记录当前步骤是否出现错误或偏差 |
| 教师备注 | 补充记录提示方式、错误点或行为观察 |

页面底部提供"上一步"、"中断保存"和"下一步 / 完成训练"按钮。训练未完成时可以中断保存，已记录的步骤结果会保留。

## 13.6 训练记录

完成或中断保存后，系统将自理训练结果写入训练记录主链。你可以在"训练记录"中选择"生活自理"入口组查看相关记录。

![生活自理训练记录](screenshots/self-care-training-records.png)

记录详情可用于复盘学生在各步骤上的独立程度、提示需求和主要错误点，为下一次训练计划调整提供依据。
