# 第二部分 日常操作指南（上）

本部分介绍 SCGP 星愿能力发展平台的日常操作流程，帮助你完成首页看板查看、学生管理、能力评估、训练计划编排和情绪行为训练等核心工作。

---

## 第3章 系统首页

### 3.1 首页概览

登录后，系统自动进入"首页看板"。

![首页看板全貌](screenshots/dashboard-overview.png)

页面副标题为："聚焦今天要做的评估、训练与干预提醒，用真实业务数据支持一线决策。"

首页看板由以下区域组成：

- **关键指标面板**：显示学生数量等核心数据，让你快速掌握当前业务概况。
- **快捷操作区**：提供各模块的快速入口，方便一键跳转。
- **今日训练日程**：显示当前执行周期内的训练计划，可直接点击"开始训练"。
- **本周异常预警**：显示过去 7 天的训练波动，包括正确率和平均提示数据。
- **智能特教助理**：根据评估缺口提供干预建议，辅助教学决策。

![关键指标面板](screenshots/dashboard-kpi.png)

如果看板数据不是最新的，点击页面上的"刷新数据"按钮即可刷新。

![刷新数据按钮](screenshots/dashboard-refresh.png)

### 3.2 模块锁定提示

快捷操作区中，部分模块入口会显示"未授权"标签。

![未授权模块标签](screenshots/dashboard-unauthorized.png)

这些模块当前未购买授权，无法使用。将鼠标悬停在"未授权"标签上，会看到提示："该模块未授权，请联系厂商购买"。

![未授权悬停提示](screenshots/dashboard-unauthorized-tooltip.png)

带有"推荐入口"标签的模块表示已授权且正在使用中，可以正常点击进入。

## 第4章 学生管理

### 4.1 学生列表

在侧边栏点击"学生管理"，进入学生列表页面。

![学生管理入口](screenshots/student-sidebar.png)

页面副标题显示当前学生总数："管理学生档案、基本信息与评估记录 · 共 N 名学生"。

![学生列表页面](screenshots/student-list.png)

页面顶部提供多种筛选条件：

| 筛选项 | 说明 |
|--------|------|
| 搜索框 | 输入姓名、学号、诊断类型关键词进行搜索 |
| 性别标签页 | 切换查看"全部"、"男"、"女" |
| 诊断类型下拉 | 选择特定诊断类型，或查看"全部诊断" |
| 所属班级下拉 | 选择特定班级，或查看"全部班级" |

![学生筛选工具栏](screenshots/student-filters.png)

筛选栏下方显示四个统计卡片：学生总数、已分班、未分班、本月新增。

![学生统计卡片](screenshots/student-stats-cards.png)

页面主体以卡片形式展示每位学生，每张卡片显示以下信息：姓名、年龄、诊断标签、班级、创建日期。

![学生卡片](screenshots/student-card.png)

### 4.2 添加学生

#### 单个添加

点击页面上方的"添加学生"按钮，弹出添加对话框。

![添加学生按钮](screenshots/student-add-button.png)

在对话框中填写学生的基本信息，填写完成后点击"确定"保存。

![添加学生对话框](screenshots/student-add-dialog.png)

#### 批量导入

点击页面上方的"批量导入"按钮，打开批量导入对话框。

![批量导入按钮](screenshots/student-import-button.png)

操作步骤如下：

1. 在弹出的对话框中点击"下载模板"，获取 Excel 导入模板。
2. 按照模板格式填写学生信息。
3. 点击"选择文件"，上传填写好的模板文件。

![批量导入对话框](screenshots/student-import-dialog.png)

系统会自动校验模板内容，校验通过后批量创建学生档案。

### 4.3 学生详情

在学生卡片上点击"查看详情"，进入该学生的详情页面。

![查看详情按钮](screenshots/student-detail-button.png)

详情页包含以下内容：

- **个人资料卡**：显示头像、学号、诊断标签、班级分配信息。
- **基本信息**：显示性别、出生日期、联系方式等字段。
- **评估记录面板**：列出该学生的所有评估记录。
- **训练历史**：展示该学生关联的训练记录。

![学生详情页](screenshots/student-detail-page.png)

### 4.4 编辑与删除学生

在学生卡片右上角找到下拉菜单按钮（三个点图标），点击后弹出操作菜单。

![学生卡片下拉菜单](screenshots/student-card-menu.png)

- 选择"编辑"，在弹出的对话框中修改学生信息，修改完成后点击"确定"保存。
- 选择"删除"，确认后将从系统中移除该学生档案。删除操作不可撤销，请谨慎操作。

![编辑学生对话框](screenshots/student-edit-dialog.png)

## 第5章 能力评估

### 5.1 评估流程概述

SCGP 的能力评估遵循标准化工作流程：

**选择类别 → 选择量表 → 选择学生 → 施测 → 查看报告**

![评估工作流程图](screenshots/assessment-flow.png)

每个步骤都在系统引导下完成，你无需记忆量表细节，按页面提示操作即可。

### 5.2 评估量表一览

SCGP 当前提供 12 个标准化评估量表，覆盖感觉统合、情绪调节、社交沟通、精细运动、生活技能等能力维度。

| 量表名称 | 代码 | 适用年龄 | 题目数 | 所属模块 | 分类标签 |
|---------|------|---------|-------|---------|---------|
| 婴儿-初中生社会生活能力量表 (S-M) | sm | 6个月-14岁 | 132题 | 生活自理 | 生活技能 |
| 改良儿童功能独立性评估量表 (WeeFIM) | weefim | 0-18岁 | 18项 | 生活自理 | 生活技能 |
| 儿童感觉统合能力发展评定量表 (CSIRS) | csirs | 3-12岁 | 58题 | 感觉统合 | 感觉统合 |
| Conners 父母用问卷 (PSQ) | conners-psq | 3-17岁 | 48题 | 情绪调节 | 情绪调节 |
| Conners 教师用问卷 (TRS) | conners-trs | 3-17岁 | 28题 | 情绪调节 | 情绪调节 |
| 长处和困难问卷 (SDQ) | sdq | 3-16岁 | 25题 | 情绪/社交 | 情绪调节 |
| 社交反应量表第二版 (SRS-2) | srs2 | 6-18岁 | 65题 | 社交沟通 | 社交沟通 |
| Achenbach儿童行为量表 (CBCL) | cbcl | 4-16岁 | 113+题 | 情绪调节 | 情绪调节 |
| 儿童发育行为评估量表 (儿心量表 II / CNBS-R2016) | cnbsr2016 | varies | 261题 | 感觉统合 | 感觉统合 |
| 大肌肉动作发展测验 (TGMD-3) | tgmd_3 | 3-10岁 | 13项技能 | 感觉统合 | 感觉统合 |
| 粗大运动功能评定量表 (GMFM-88) | gmfm_88 | 5个月-16岁 | 88项 | 感觉统合 | 感觉统合 |
| 小肌肉功能发展评估量表 (FMDA) | fine_motor | 0-6岁 | 88项 | 感觉统合 | 精细运动 |

分类标签说明：

| 标签 | 含义 |
|------|------|
| 感觉统合 | 评估感觉统合能力与粗大/精细运动发育水平 |
| 情绪调节 | 评估情绪状态、行为问题与注意力特征 |
| 社交沟通 | 评估社交互动能力与沟通水平 |
| 精细运动 | 评估手部精细动作发育水平 |
| 生活技能 | 评估日常生活自理能力与功能独立性 |
| 安抚辅助 | 评估情绪安抚与辅助支持需求 |

![评估量表分类标签](screenshots/assessment-category-tags.png)

### 5.3 开始评估

操作步骤如下：

1. 在侧边栏点击"能力评估"，进入评估中心。

![能力评估入口](screenshots/assessment-sidebar.png)

2. 页面标题为"评估中心"，副标题为"按分类浏览量表，快速筛出当前最适合的标准化评估入口。"

![评估中心页面](screenshots/assessment-center.png)

3. 在"评估分类"区域选择一个分类标签，系统会过滤出对应分类下的量表。

![评估分类选择](screenshots/assessment-category-select.png)

4. 选择一个量表卡片，点击"开始评估"按钮。

![开始评估按钮](screenshots/assessment-start.png)

5. 在弹出的学生选择界面中，选择要评估的学生。

![选择评估学生](screenshots/assessment-select-student.png)

6. 进入施测界面，按题目逐项作答。系统会自动保存你的作答进度。

![施测界面](screenshots/assessment-testing.png)

7. 全部题目作答完成后，系统自动生成评估报告。

> 注意：评估中心页面会显示"已按授权过滤"标签，表示当前列表仅展示已授权的量表。未授权的量表不会出现在列表中。

![已按授权过滤标签](screenshots/assessment-authorized-filter.png)

### 5.4 查看评估报告

评估完成后，系统自动跳转到报告页面。

![评估报告页面](screenshots/assessment-report.png)

报告包含以下内容：

- **量表分数**：显示总分及各维度得分。
- **维度分析**：以图表形式展示各维度的评估结果。
- **结果解读**：根据量表常模提供专业解读说明。

![报告维度分析图表](screenshots/assessment-report-chart.png)

CSIRS 量表支持历史对比功能，你可以将本次评估结果与历次评估结果进行对比，观察学生的能力变化趋势。

![CSIRS 历史对比](screenshots/assessment-csirs-comparison.png)

### 5.5 评估报告导出

评估报告支持导出为以下格式：

- **Word 文档** (.docx)：适合编辑和打印。
- **PDF 文档**：适合归档和分享。

![报告导出按钮](screenshots/assessment-report-export.png)

点击报告页面上方的"导出"按钮，选择导出格式，系统会自动生成并下载文件。

![报告导出格式选择](screenshots/assessment-export-format.png)

## 第6章 训练计划（IEP）

### 6.1 训练计划概述

训练计划是 IEP（个性化教育计划）的数字化管理工具。

你可以将评估结果关联到训练计划中，编排跨模块的训练资源，设置长短期目标。每个计划绑定一名学生，覆盖一个时间周期，包含若干训练资源。

![训练计划概念图](screenshots/plan-concept.png)

### 6.2 创建训练计划

操作步骤如下：

1. 在侧边栏点击"训练计划"，进入计划管理页面。

![训练计划入口](screenshots/plan-sidebar.png)

2. 页面副标题显示："IEP 个性化教育计划管理，承接评估结果与跨模块训练资源编排 · 共 N 个计划"。

![训练计划列表页](screenshots/plan-list.png)

3. 点击"新建计划"按钮，弹出创建对话框。

![新建计划按钮](screenshots/plan-create-button.png)

4. 在"基本信息"标签页中填写以下内容：

| 字段 | 说明 |
|------|------|
| 计划名称 | 为计划起一个便于识别的名称 |
| 归属模块 | 从下拉列表中选择所属训练模块 |
| 关联学生 | 从下拉列表中选择要训练的学生 |
| 计划周期 | 设置开始日期和结束日期 |
| 计划描述 | 填写计划的补充说明（可选） |

![计划基本信息](screenshots/plan-basic-info.png)

5. 切换到"目标设定"标签页：

- 点击"添加长期目标"，填写长期目标内容（如：提高触觉敏感度）。
- 点击"添加短期目标"，填写短期目标内容（如：能独立完成大笼球游戏）。

![计划目标设定](screenshots/plan-goals.png)

6. 填写完成后，点击"确定"保存计划。

### 6.3 管理训练计划

计划列表页提供多种筛选条件：

| 筛选项 | 说明 |
|--------|------|
| 状态标签 | 按计划状态筛选（执行中、待开始、已结束等） |
| 归属模块下拉 | 按训练模块筛选 |
| 学生下拉 | 按关联学生筛选 |
| 搜索框 | 输入计划名称进行搜索 |

![计划筛选工具栏](screenshots/plan-filters.png)

筛选栏下方显示四个统计卡片：计划总数、执行中、待开始、涉及学生数。

![计划统计卡片](screenshots/plan-stats-cards.png)

每个计划以卡片形式展示，显示以下信息：

- 状态标签（执行中、待开始、草稿等）
- 关联的资源数量
- 计划进度百分比
- 日期范围

![计划卡片](screenshots/plan-card.png)

### 6.4 从计划启动训练

执行中的计划会显示"今日训练推荐"区域。

![今日训练推荐](screenshots/plan-daily-recommendation.png)

该区域列出关联的训练资源，每个资源显示以下信息：

- 建议频次
- 建议时长
- 教学提示

![训练资源详情](screenshots/plan-resource-detail.png)

点击资源即可"开始训练"，系统会进入对应的训练界面。

![从计划开始训练](screenshots/plan-start-training.png)

如果计划当前处于"草稿"状态，需要先点击"开始执行"按钮，将计划切换为执行状态，才能看到训练推荐。

![开始执行计划](screenshots/plan-activate.png)

## 第7章 情绪行为模块

### 7.1 模块概述

在侧边栏点击"情绪行为"，进入情绪行为模块。

![情绪行为入口](screenshots/emotional-sidebar.png)

页面副标题为："选择训练方向，围绕生活情境开展情绪识别、原因推理与关心表达练习。"

![情绪行为模块首页](screenshots/emotional-home.png)

模块包含三个训练方向：

1. **情绪与场景训练**：通过生活场景识别情绪、观察线索，推理原因与回应方式。
2. **表达关心训练**：学习在不同情境下表达共情与关心。
3. **情绪小游戏**：25 个互动小游戏，覆盖自我调节、情绪识别、社交合作等训练目标。

![三个训练方向卡片](screenshots/emotional-directions.png)

### 7.2 情绪场景训练

在模块首页选择"情绪与场景"卡片，进入情绪场景训练。

![情绪与场景入口](screenshots/emotional-scene-entry.png)

训练描述："通过生活场景识别情绪、观察线索，并进一步推理原因与回应方式。"

训练流程如下：

1. 在场景列表中选择一个生活场景。

![选择生活场景](screenshots/emotional-scene-select.png)

2. 进入沉浸式训练会话。

![沉浸式训练会话](screenshots/emotional-scene-session.png)

3. 训练包含多个交互步骤，按顺序逐一完成：

| 步骤 | 名称 | 说明 |
|------|------|------|
| 1 | 场景介绍 (SceneIntro) | 展示当前场景的背景信息 |
| 2 | 情绪选择 (EmotionChoice) | 根据场景选择人物的情绪 |
| 3 | 推理问答 (ReasoningQuestion) | 回答关于情绪原因的推理问题 |
| 4 | 解决方案选择 (SolutionChoice) | 选择恰当的应对或帮助方式 |
| 5 | 接收者偏好 (ReceiverPreference) | 判断场景中人物的感受和偏好 |

![场景训练步骤](screenshots/emotional-scene-steps.png)

4. 完成所有步骤后，查看本次会话的摘要总结。

![会话摘要](screenshots/emotional-scene-summary.png)

### 7.3 表达关心训练

在模块首页选择"表达关心"卡片，进入表达关心训练。

![表达关心入口](screenshots/emotional-care-entry.png)

训练描述："学习在不同情境下表达共情与关心，理解不同话语给他人的感受。"

训练流程如下：

1. 在关心场景列表中选择一个场景。

![选择关心场景](screenshots/emotional-care-scene-select.png)

2. 进入沉浸式训练界面。

![关心训练界面](screenshots/emotional-care-session.png)

3. 通过分步指导面板学习合适的表达方式。

![分步指导面板](screenshots/emotional-care-guide.png)

4. 在话语渲染器中选择你认为最合适的表达语句。

![话语渲染器选择](screenshots/emotional-care-expression.png)

### 7.4 情绪小游戏

情绪模块内置 25 个训练小游戏，按训练目标分为以下类别：

| 分类 | 游戏名称 |
|------|---------|
| 自我调节 | 深呼吸热气球、吹蒲公英、魔法沙漏、擦亮坏心情、云朵擦擦擦 |
| 情绪识别 | 我的情绪温度计、喂食情绪小怪兽、表情猜猜乐、表情能量球 |
| 社交合作 | 合作造汉堡、礼物分享派对、动物传声筒、故事接龙板 |
| 情绪感知 | 水塘波纹、刺破慢气球 |
| 感官/音乐 | 星空八音盒 |
| 音量控制 | 音量魔法森林 |
| 专注/注意 | 连线小星座 |
| 问题解决 | 轨道修补匠 |
| 生活技能 | 分拣小能手、洗手小能手、我会穿衣服、刷牙小卫士、摆桌子帮帮忙、上学包包装一装 |

![情绪小游戏列表](screenshots/emotional-games-list.png)

所有游戏采用全屏沉浸模式，学生可以专注于训练内容，减少外界干扰。

![全屏沉浸模式](screenshots/emotional-game-fullscreen.png)

在模块首页选择"情绪小游戏"卡片，即可查看并启动任意游戏。

![情绪小游戏入口](screenshots/emotional-games-entry.png)

### 7.5 情绪模块报告

情绪模块提供专项训练报告，帮助你跟踪学生的训练进展。

![情绪模块报告页面](screenshots/emotional-report.png)

报告包含以下内容：

- **学生训练汇总**：展示每位学生的训练次数、完成情况和总体表现。
- **准确率趋势图**：以折线图展示训练准确率随时间的变化趋势。
- **掌握程度雷达图**：以雷达图展示学生在各维度上的掌握程度。
- **话语偏好饼图**：以饼图展示学生在表达关心时的话语选择分布。

![准确率趋势图](screenshots/emotional-report-accuracy.png)

![掌握程度雷达图](screenshots/emotional-report-radar.png)

报告支持导出为 Word 文档，点击报告页面上方的"导出"按钮即可生成文件。

![情绪报告导出](screenshots/emotional-report-export.png)
