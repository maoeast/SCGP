## 5. 常模数据现状

- `cpep3_pg_month_norms.json`（102 行）：分能区通过数 → 发展当量月龄区间；`cpep3_gn_fz_month_norms.json`（96 行）：总通过数 → 总发展当量区间。**这是唯一随数据提供的正式换算表**（用户提供的协康会配套资料，视为已授权常模）。
- **无百分位表、无标准分表、无适应不良行为常模**。
- 结论：`getNormativeResult` 对百分位/标准分一律返回 `null`（source `not_available`）；发展当量仅发展能区可用；适应不良行为区发展年龄强制 `null`（显示「不适用」）。
- 发展当量为**区间**（如 22-29 月）：区间原文为主呈现，单一月龄为区间中值（固定标注「派生估计」）。
