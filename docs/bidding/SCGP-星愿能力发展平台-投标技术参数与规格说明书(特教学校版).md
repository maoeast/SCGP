# SCGP 星愿能力发展平台 - 投标技术参数与规格说明书（特殊教育学校版）

> **文件性质**：政府采购 / 特殊教育学校信息化与康复训练设备招标文件"技术规格与服务要求"标准编制范本  
> **适用对象**：特殊教育学校、普校随班就读资源教室、特教指导中心、残联培智康复中心  
> **编制依据**：《中华人民共和国残疾人保障法》、《特殊教育办学质量评价指南》、《随班就读资源教室建设指南》  
> **授权机制**：平台基于**七大特教专业能力包（Entitlement Packages）**实现离线验签独立授权，各能力包支持独立采购与自由组合开通  
> **软件基线**：SCGP 星愿能力发展平台 V1.1.4  
> **编制日期**：2026-10-13  
> **条款标识说明**：
> - **"★"**：核心控标条款 / 关键实质性技术指标。不满足该条款可能导致投标被拒绝或严重扣分。
> - **"▲"**：重要技术条款。特教教学与康复核心业务刚性需求，为重点评分项。
> - 无标记：通用基础技术规格。

### 5. AI 特教垂直智能体助手（教学研训重点模块）

| 序号 | 指标名称 | 详细技术参数与功能要求 | 重要性 | 佐证要求 |
|:---|:---|:---|:---:|:---|
| 5.1 | 六大特教垂直智能体矩阵 | ★ 系统须深度定制并内置不少于 **6 个**面向特教真实场景的专属智能体角色，每个角色须配备由特教专家与提示词工程师深度调优的专业指令：<br>① **「一人一策」个别化教学设计专家**：聚焦特教学生差异化教学目标制定、IEP 建议拆解与随堂调整；<br>② **「沟通有方」课堂沟通支持专家**：专为无语言/言语障碍儿童提供辅助沟通（AAC）、图片交换系统（PECS）与视觉提示支持策略；<br>③ **「成长看得见」观察与追踪助手**：协助教师开展客观行为观察记录（ABC分析）、行为频次统计与转介意见整理；<br>④ **「家校好好说」家校共育助手**：专门针对特教家长特殊敏感心理，辅助撰写得体、具同理心的微信通知、电话沟通草稿与面谈建议；<br>⑤ **「心晴陪伴」情绪行为干预专家**：针对自伤、攻击等危机行为提供前事前因预防、平复话术与校内应急支持策略；<br>⑥ **「稳健训练」康复支持专家**：提供器械训练安全防护、低风险动作替代与体能康复训练建议。 | ★ | 6个智能体角色功能演示 |
| 5.2 | 随处可达的唤起入口 | 系统首页须提供已启用智能体的卡片网格，点击直接进入对应智能体专属会话；系统全局右下角须常驻 AI 悬浮球按钮，教师在任何功能界面均可一键唤起 AI 助手，且支持快捷清空当前会话并重新选择智能体角色。 | 通用 | 页面布局截图与唤起演示 |

## 第三部分：针对招标方（特教学校）的核心控标点建议

在协助招标方编制招标文件或设定评分标准时，建议将以下 **6 大核心优势** 设定为 ★ 关键指标或高分值演示打分项，有效形成竞争壁垒：

**壁垒一：技术底座壁垒 — 纯本地离线单机运行 + 零外部数据库依赖**

要求"单机嵌入式运行、断网 100% 可用、零云端外挂服务"。通用集成商通常采用云端 Web 架构或打包 MySQL 服务端，极易因断网瘫痪或外泄特殊学生隐私，且维护成本极高；此条款直接构成硬性准入门槛。

**壁垒二：特教专业壁垒 — 基于统一量表引擎的 18 项标准化量表 + 发育年龄自动换算 + 评估质量看板**

要求系统内置不少于 18 项标准化量表，覆盖七大特教能力域，且作答完毕秒级自动换算 DQ/发育年龄，并具备管理员评估质量可视化看板；排斥市面上仅有粗糙自编问卷或量表数量不足、无常模支撑的竞品。

**壁垒三：教科研创新壁垒 — 特教垂直专属多智能体矩阵 + 学生脱敏长期记忆库 + 多模型管理**

多数竞品仅接入通用聊天机器人接口，无法与特教具体学生产生业务绑定；本系统 6 大垂直智能体经特教专业提示词工程调优，具备学生长期画像关联、本地脱敏提炼、教师人工确认、后续对话自动召回与多模型按需切换闭环，行业独有。

**壁垒四：生活自理与教学定制壁垒 — 任务分析法小步子教学 + 校本任务自主编辑扩展**

要求生活自理模块具备任务分析法小步子分解教学能力，且必须内置可视化的自理任务与步骤编辑器，支持特教教师自主新增、编辑校本自理任务与步骤配图，排斥仅提供固定僵化自理内容、无法进行校本定制扩展的竞品。

**壁垒五：架构授权壁垒 — 七大能力包（Entitlement-First）离线授权 + API Key 宿主隔离**

要求系统支持基于离线验签激活码按需激活感官统合、情绪发展、社交沟通、精细动作、安抚系统、生活自理、认知发展等七大能力包，且 API Key 备份时自动剥离防转录，完整符合特教学校分步采购、预算可控与校园信息安全等保要求。

**壁垒六：公文交付壁垒 — 双引擎原生报告导出 + 自定义校名页眉 + 免冠头像浮动排版**

绝大多数软件导出的 Word 格式粗糙、图片变形走样。本系统具备算法级浮动头像与公文页眉注入，现场打印即可直观体现公文规范质感。要求"Word 报告含校名页眉、头像排版不变形、同时支持 HTML 离线格式"可精确排除排版不规范竞品。
