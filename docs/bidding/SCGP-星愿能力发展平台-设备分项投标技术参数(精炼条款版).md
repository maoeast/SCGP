# SCGP 星愿能力发展平台 - 设备分项投标技术参数（精炼条款版）

> **使用说明**：
> 1. 本文为特殊教育学校、普校随班就读资源教室、康复中心等综合采购项目中的**单一软件设备分项**编制（如采购清单中的“特殊儿童综合能力评估与训练发展系统 1套”）。
> 2. **纯条款段落排版（无表格）**：便于招标代理或编制人员直接整体复制粘贴至总招标文件“设备技术参数与性能要求”单元格或技术规范附件中，避免出现表格嵌套排版错位问题。
> 3. **全功能上限配置**：本条款涵盖平台通用底座与七大特教专业能力包（感官统合、情绪发展、社交沟通、精细动作、安抚系统、生活自理、认知发展）全量功能。若具体项目预算有限仅采购部分能力包，可直接删减对应编号的条款。
> 4. **条款标识**：**“★”** 为实质性核心控标条款（建议设为废标项或最高打分项）；**“▲”** 为重要评分条款。

---

### 设备分项技术参数与规格要求（特殊儿童综合能力评估与训练发展系统 1套）

1. ★【运行环境与部署架构】：采用纯本地桌面优先（Local-First Desktop）运行架构，所有学生档案、测评数据、训练记录、系统日志必须保存在终端本地数据库中。在断网或无外网环境下必须保证所有教学评估、计划、训练与报告业务 100% 完整可用（外部 AI 功能为可选网络扩展，断网不影响本地业务主链正常运行），严禁依赖外置云服务器才能进入系统或保存教学数据，杜绝特殊儿童生理健康与学籍隐私外泄风险。系统须采用本地嵌入式轻量级数据库（SQL.js/SQLite 引擎）驱动，安装包须内置全部运行环境与数据引擎，不得要求学校单独部署或安装 MySQL、SQL Server 等大型第三方数据库服务端软件，实现开箱即用。

2. 【学籍档案与教务管理】：系统须提供符合特殊教育规范的电子学生成长档案，包含学号、姓名、性别、出生日期（自动换算生理月龄用于量表适用性判断）、诊断类型（支持孤独症谱系、智力障碍、言语语言障碍、听力障碍、视力障碍、肢体障碍、多重障碍、注意力缺陷等）及自定义特教成长标签库；免冠登记照支持系统预设头像、上传图片及电脑摄像头现场拍照三种采集方式；系统须支持多学年划分、特教班级动态管理、带教教师指派与学生批量分班升班操作；支持标准 Excel（.xlsx/.xls）名单批量导入与逐行合规校验。

3. ★【特教权威标准化量表体系】：系统须完整内置不少于 18 项特教与儿童康复领域公认的标准化评估量表，严禁以无常模依据的自编简易问卷替代；覆盖感官统合、情绪调节、情绪安抚、社交沟通、精细动作、生活自理和认知发展全七大能力域，包含：① S-M 婴儿-初中生社会生活能力量表（6个月-14岁，132题）；② WeeFIM 改良儿童功能独立性评估量表（0-18岁，18项）；③ CSIRS 儿童感觉统合能力评定量表（3-12岁，58题）；④ Conners PSQ 父母用问卷（3-17岁，48题）；⑤ Conners TRS 教师用问卷（3-17岁，28题）；⑥ SDQ 长处和困难问卷（父母版，3-16岁，25题）；⑦ SRS-2 社交反应量表学龄版（6-18岁，65题）；⑧ CBCL 儿童行为量表家长版（4-16岁，113题）；⑨ 儿心量表Ⅱ（CNBS-R2016）（0-84个月，261题）；⑩ TGMD-3 大肌肉动作发展测验（3-10岁11个月，13项动作）；⑪ GMFM-88 粗大运动功能评估（5月-16岁，88项）；⑫ FMDA 小肌肉功能发展评估量表（0-6岁，88项）；⑬ ABC 孤独症行为评定量表（3岁以上，57题）；⑭ ATEC 孤独症治疗疗效评估量表（2岁以上，77题）；⑮ PEP-3 心理教育量表中文修订版（2-7岁，139题）；⑯ BRIEF 儿童执行功能评估量表（2-18岁）；⑰ CRT 瑞文图形推理测验（5.5-16.5岁，60题）；⑱ 综合认知图形匹配测验（16题）。

4. ★【常模算法与发育年龄自动折算】：系统须具备自动化常模计算功能，作答完成后无需人工查表，系统自动依据学生评定时的生理月龄秒级换算粗分、百分位数（P值）、发展商数（DQ）、发育年龄（折算月龄及岁数），并自动判定发展延迟程度与等级；系统须在评估前自动根据学生出生日期与评估日期计算月龄，所选量表超出年龄范围时具备系统级超龄拦截提示；支持根据量表维度自动渲染多维发展雷达图与常模剖面图；支持针对同一名学生提取多次测评数据生成纵向发展对比曲线。

5. 【评估用时与质量监控看板】：评估过程自动记录总用时与平均每题用时；针对儿童自答类测验（如瑞文测验）具备疑似随机作答内部识别能力；系统须在管理员端提供专属“评估质量看板”，按量表类型汇总已评估数、极快（平均每题<3秒）、偏快（平均每题<5秒）及疑似随机作答异常计数，支持一键跳转对应报告核验追溯。

6. ★【IEP 个别化计划评训一体化闭环】：系统须实现“评-训一体化”业务闭环：评估提交完成后，系统自动依据学生各维度缺陷打开能力巩固与器材/游戏推荐抽屉，识别薄弱项目；教师勾选后可一键生成阶段教学计划（IEP）草稿；草稿须经过教师复核并显式确认后方可正式启用生效，防止系统盲目派单；处于进行中的计划，其关联的学生与训练项自动派发至首页“今日工作”日程卡片，教师点击即可一键直达训练界面。

7. ★【AI 特教垂直专家智能体矩阵】：系统须深度定制并内置不少于 6 个面向特教真实场景的专属智能体（「一人一策」个别化教学设计专家、「沟通有方」课堂沟通支持专家、「成长看得见」观察与追踪助手、「家校好好说」家校共育助手、「心晴陪伴」情绪行为干预专家、「稳健训练」康复支持专家）；教师进入会话后选择学生，系统自动将该学生脱敏基础信息（姓名脱敏、性别、年龄、障碍类别）作为结构化背景注入对话提示词；系统具备学生脱敏“长期记忆库”提取与沉淀闭环，对话中 AI 自动提炼特质偏好，教师人工审核确认后永久存入学生专属记忆库，后续对话自动召回；支持本地离线拖拽上传学生既往病历与教案（PDF/DOCX/XLSX/图片），客户端静默完成文本解析，严禁将原排版文件上传云端；支持 AI 教学方案一键导出为排版规范的 Word 文档。

8. ▲【AI 校园安全与用量风控管理】：系统第三方大模型 API Key 必须由宿主主进程加密存储，页面端无法获取明文 Key，且全量数据备份时 Key 自动剥离防泄露；系统须提供月度 Token 额度熔断配置及一键“AI 总开关”；教师首次发送前强制弹出隐私知情同意书，确认后方可交互；内置心理危机干预红线，遇学生自伤、严重攻击时主动提示启动线下校园应急预案；管理员端须提供全校“AI 会话记录”全局审计大屏，保障教学合规与校园意识形态安全。

9. ★【实体感统器材实训联动】：系统须内置实体感统器材与教具库（平衡木、触觉球、羊角球、彩虹隧道、大陀螺等）；支持快速绑定器材，随堂记录学生器材实训表现得分（1~5分）、五级辅助等级（独立完成/口头提示/视觉提示/手触引导/身体辅助）、训练时长与教师备注；支持从器材训练记录自动生成 IEP 训练评语与阶段建议（支持 Word 导出），实现实体教具与数字化训练一体化规范管理。

10. ★【大规模特教互动训练游戏库】：系统须内置互动训练游戏不少于 42 款，包含感官统合基础游戏 11 款，并跨情绪发展、精细动作、社交沟通、安抚系统、生活自理、认知发展等能力域额外提供不少于 31 款专项游戏；覆盖视觉追踪、听觉辨析、节奏模仿、手眼协调、注意力持续、情绪识别、社交合作等多元训练目标；游戏具备可配置的阶梯式难度调节（刺激物数量、移动速度、干扰项比例等）；采用沉浸式全屏防干扰运行；后台毫秒级自动采录反应时、正确率与失误类型，训练结束即刻生成当次成绩单与 IEP 报告。

11. ▲【同伴合作与感知硬件多模态交互】：系统游戏须支持双人同屏合作模式（如双人合作造汉堡），双方需协同分工、互相等待并同步完成操作方可通过关卡，培养同伴轮流、合作与社交参照意识；支持摄像头视觉交互与麦克风声控交互（如深呼吸热气球、音量魔法森林训练语调与音量自控）；游戏前系统须自动检测音视频权限，异常时提供明确的系统设置修复引导。

12. ▲【情绪发展专项训练链路】：系统须提供两条专业情绪训练主链：①“情绪与场景”：在真实校园情境中识别面部表情与肢体语言、推理情绪原因并练习恰当回应；②“表达关心”：在同伴摔倒、哭泣等真实情境中练习共情与关心表达。训练采用沉浸式全屏设计，提供教师随堂荧光笔圈画标注工具，支持在屏幕上实时圈画引导学生关注情绪线索（如眼泪、皱眉）；系统自动汇聚训练数据生成专项情绪进步报告（支持一键导出 Word）。

13. ★【生活自理技能分解教学（独立能力包）】：系统须紧扣生活适应课程标准，支持以“任务分析法（Task Analysis）”组织自理训练，将复杂技能拆解为有序小步骤（如洗手精细拆解）；每个步骤配有清晰动作图解说明与动作图片，以纯净图文形式呈现，无音频与视频的过度感官刺激干扰，降低学生认知负荷；系统须内置可视化自理任务与步骤编辑器，支持特教教师结合校本课程自由新增、编辑自理任务与分解步骤；支持四级辅助水平量化评分与弹性中断保存，成绩全息归档。

14. ▲【精细动作功能训练】：系统内置专为儿童精细动作发展的 FMDA 小肌肉功能发展评估量表（88项技能），自动换算发育商与发育年龄；配套空气木琴、打泡泡等手眼协调与手指灵巧度进阶游戏，反应时与失误类型自动归档记入学生档案，针对性锻炼特殊儿童握笔前准备、手指分化与手部肌力协调控制能力。

15. 【日常工作日程与双重智能预警】：系统首页提供“今日工作”大屏，清晰呈现当天排班日程、待训练学生、待评估任务，点击直达教学；提供近 7/30 天训练进度多维趋势下钻；内置两大特教教学质量预警模型：① 训练异常警示（连续缺训、成绩骤降或频繁中断主动亮灯提醒）；② 复评超期提醒（自动跟踪评估周期，逾期提示复评）；学生详情页以时间轴倒序汇聚成长脚印，形成全息成长轨迹。

16. ★【公文级原生报告导出与排版防变形】：所有评估量表报告、情绪训练报告、器材 IEP 评语均支持一键导出为 Microsoft Word (.docx) 与单文件 HTML 网页双格式；管理员可配置学校官方名称，导出的 Word 报告自动注入公文页眉；系统须具备学生免冠登记照自适应浮动排版算法，照片精准锚定在基本信息表右上角，彻底解决表格被图片撑爆变形撕裂的排版顽疾；15 项主力量表报告提供 AI 解读直达入口。

17. ★【能力包级离线许可与数据备份安全】：系统须具备现代化能力包级离线许可（Entitlement Licensing）架构，基于离线验签激活码按需激活开通感官统合、情绪发展、社交沟通、精细动作、安抚系统、生活自理、认知发展七大专业能力包，菜单与资源按授权动态隔离过滤；系统须提供一键全量数据加密备份功能（不少于12位口令），打包数据库与本地多媒体资源为独立 .dat 文件，具备无损原子恢复保障，杜绝数据坏块。
