# 情绪场景补图 Brief

适用对象：
- `scene-81` 在医院探望生病的爷爷
- `care-scene-65` 好朋友期中考试数学没考好

目的：
- 补齐这两条新数据对应的正式图片命名
- 给资源图制作提供统一口径，避免后续图片风格、人物关系、情绪强度偏掉

## 1. 文件命名与落点

### emotion_scene
- 场景编码：`scene-81`
- 标题：`在医院探望生病的爷爷`
- 数据路径：`images/emotional-scenes/scene81_hospital_visit_grandpa.png`
- 资源源目录建议：`/assets/scenes/scene81_hospital_visit_grandpa.png`

### care_scene
- 场景编码：`care-scene-65`
- 标题：`好朋友期中考试数学没考好`
- 数据路径：`images/care-scenes/care-scene-65_math_midterm_failed.png`
- 资源源目录建议：`/assets/care_scenes/care-scene-65_math_midterm_failed.png`

命名规则补充：
- `emotion_scene`：`scene{编号}_{英文短语}.png`
- `care_scene`：`care-scene-{编号}_{英文短语}.png`
- 英文短语只保留核心事件，不要塞情绪词堆砌，不要出现空格

## 2. 统一视觉口径

- 风格：写实摄影感，非插画、非卡通、非海报
- 人物：全部为中国人，儿童服装、医院/校园环境符合中国日常经验
- 画面：中景优先，人物表情和动作要一眼能读懂
- 光线：自然柔和，不做夸张戏剧光
- 背景：保留必要环境线索，但不要过杂
- 禁止项：水印、文字、校名、医院名、试卷分数大字、畸形手指、夸张表情、悬浮物、动漫脸

## 3. 场景 81 资源图方案

### 核心目标
- 让儿童一眼看出“爷爷生病住院了”
- 同时能读出“孩子心疼、难过、担心，但没有崩溃大哭”
- 重点不是医院器械，而是祖孙之间安静的关心关系

### 画面内容
- 地点：中国医院普通病房
- 人物：
  - 7-10 岁左右中国小学生
  - 一位住院的中国爷爷，状态虚弱但清醒
- 关键道具：
  - 病床
  - 输液贴或输液管
  - 保温桶或水果袋
- 关键动作：
  - 孩子站在床边，轻轻拉着爷爷的手
  - 或孩子安静把带来的东西放在床头
- 关键表情：
  - 孩子眼圈微红、抿嘴、担心
  - 爷爷表情疲惫但温和

### 构图建议
- 中景偏近景
- 爷爷在床上，孩子站在床边偏前景
- 画面重心放在手部接触和眼神关系上

### 不要画成
- 孩子大哭失控
- 病房里全是夸张医疗设备
- 爷爷像重症抢救
- 画面只剩病床没有陪伴关系

### 建议 prompt
```text
写实摄影风格，用于儿童情绪训练软件的单张场景图片。场景主题：在医院探望生病的爷爷。地点要求：中国医院普通病房，场景符合中国日常生活经验。人物要求：全部人物为中国人，一个7到10岁左右的小学生站在病床边，一位生病住院的爷爷躺在床上，手背有输液贴或输液管，状态虚弱但清醒。画面重点表现孩子心疼、难过、担心的情绪，孩子轻轻拉着爷爷的手，床边放着保温桶或水果袋。温暖自然光，中景构图，表情和动作一眼能看懂，背景不要杂乱。禁止文字、水印、海报感、动漫风、夸张表情、畸形手部。
```

## 4. 场景 65 资源图方案

### 核心目标
- 让儿童一眼看出“数学考试没考好”
- 同时读出“失落、泄气、自我怀疑”，不是愤怒也不是社交羞耻爆发
- 重点是同伴支持入口，所以画面最好同时出现失利者和准备靠近安慰的朋友

### 画面内容
- 地点：中国小学或初小年级教室
- 人物：
  - 7-12 岁左右中国女孩或中性学生形象作为小雨
  - 一位同龄好朋友坐在旁边或正准备靠近
- 关键道具：
  - 数学试卷
  - 书包
  - 水杯
- 关键动作：
  - 小雨低头看着卷子，眼圈红红，把试卷往书包里收
  - 好朋友轻轻坐到旁边或递水杯
- 关键表情：
  - 小雨明显失落泄气，不是嚎啕大哭
  - 朋友表情温和、关心、克制

### 构图建议
- 中景，课桌占画面下半部
- 卷子可见“数学试卷”语义，但不要出现巨大分数文字
- 尽量保留“准备支持”的互动感，而不是只有一个人闷着

### 不要画成
- 老师在旁边批评
- 周围同学围观嘲笑
- 夸张大红分数占满画面
- 朋友直接抢卷子或激烈安慰

### 建议 prompt
```text
写实摄影风格，用于儿童表达关心训练软件的单张场景图片。场景主题：好朋友期中考试数学没考好。地点要求：中国小学教室或普通校园教室。人物要求：全部人物为中国人，一个7到12岁左右的小学生坐在课桌前，盯着数学试卷，眼圈发红，神情失落泄气，正把试卷慢慢收进书包。旁边一位同龄好朋友轻轻坐到她旁边或递来水杯，表情温和关心。画面重点表现考试失利后的难过、自我怀疑，以及朋友准备安慰支持的关系。自然柔和光线，中景构图，背景有教室线索但不杂乱。不要文字水印，不要夸张分数，不要动漫风，不要围观嘲笑。
```

## 5. 执行建议

- 如果先不出正式图，当前两个文件名已经可以作为稳定占位路径
- 真正落图时优先输出 `png`
- 若同一场景需要多候选图，建议先出 3 张：
  - 关系更明显版
  - 环境线索更明显版
  - 人物表情更近版
- 最终选图标准：
  - 低龄学生一眼能看懂发生了什么
  - 情绪强度准确
  - 没有多余故事线
  - 关心关系能被看出来
