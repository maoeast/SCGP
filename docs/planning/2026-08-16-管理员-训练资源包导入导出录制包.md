# 《管理员：训练资源包导入导出》人工录制包

> **状态**：当前有效，待按本包录制与验收
> **产品**：SCGP / 星愿能力发展平台
> **受众**：首次使用系统的学校管理员
> **成片目标**：2–3 分钟、16:9；先无声录屏，再配 AI 旁白和字幕
> **范围**：在资源管理的情绪业务分组下导出情绪资源包，再以“导入副本”策略导入该包并回查
> **系列**：本片为第十九支，承接《管理员：训练资源维护》（第八支演示资源维护，本片演示资源包迁移）；业务数据已就绪。
> **不作为事实来源**：`output/videos/管理员：班级与学生管理.mp4`、`scripts/video/` 及其旧分镜仅为历史参考，不能复用其时长、分辨率、样例数据、旁白、选择器或语音配置。

## 1. 本片要解决什么

本片演示管理员在“资源管理 → 训练资源”的情绪业务分组下完成资源包导出与导入：导出当前范围内的情绪资源为 JSON 资源包，再以“导入副本”策略导入该包，系统解析校验后完成导入并在列表回查。

训练资源包用于情绪训练资源（情绪场景/表达关心）的备份与迁移，导入前会执行契约归一化与校验，支持跳过重复、更新已有、导入副本三种策略。本片只说明这一业务结果，不承诺替代学校既有的资源版权或采购流程。

### 角色与范围边界

- 录制账户为**管理员**，旁白以“管理员”指代操作者（导入/导出按钮仅管理员且仅情绪业务分组可见）；不得把操作表述为教师、学生或其他角色。账号信息不出现在画面中。
- 演示页面：资源管理 → 训练资源 Tab（情绪业务分组）→ 导出情绪资源包 / 导入情绪资源包 对话框。
- 导出产物为 JSON 资源包（默认格式），文件名含日期；导入复用该包，选择“导入副本”策略。
- 不演示：Excel 工作簿格式、下载 Excel 模板、跳过重复/更新已有策略、冲突“阻塞”场景、导入校验失败的错误画面、coverImage/imageUrl 中的绝对路径内容。
- 不演示导入、数据库替换、数据抽取、演示 ZIP 修改或产品数据目录写入。`docs/guides/seed-demo-data.md` 仅可作为历史参考，不是本片的执行路径。

## 2. 录制前置条件与安全检查

在打开录制软件前，由执行人逐项确认。任一项不满足时，停止录制并先修正环境，不用剪辑掩盖问题。

| 检查项 | 必须满足的条件 |
| --- | --- |
| 账户与页面 | 已使用管理员账户登录；左侧菜单“资源管理”可见可进入。 |
| 数据环境 | 使用可丢弃、可完整恢复的录制数据库；情绪业务分组下存在若干情绪资源（情绪场景/表达关心，非空）；绝不连接生产库或含真实人员信息的库。 |
| 资源包文件 | 导出产物保存到临时/默认目录；录制结束后随环境一并清理；文件选择对话框不聚焦完整路径。 |
| 资源内容 | 情绪资源的 coverImage/imageUrl 等字段不含绝对路径或敏感信息（导出与导入预览均不展示这些字段值）；如含，先清理或更换演示资源。 |
| 运行状态 | 页面加载完成、无报错提示、浏览器/系统通知关闭，缩放和字体在 16:9 画面中清楚可读。 |
| 回滚 | 已明确录制结束后的恢复方式：还原该可丢弃数据库（含导入的副本资源）或按既有安全流程清理；删除资源包文件；不得对真实库做清理。 |

运行时只使用以下占位符替换为已核验的实际值：

- `[资源包文件]`（导出产物，用于随后导入）

### 2.1 录制效率提示

- **批次**：E-3（依赖情绪资源非空，可与第 8 支同库）。
- **预置**：情绪分组下资源非空；导出产物路径可再次选择。
- **一次通过要点**：①按钮仅"情绪"业务分组 + 管理员可见；②产物为 JSON 包（非 zip）；③"当前素材目录"路径禁入画面；④导入选"导入副本"策略（结果可见新建，回查有对比）。
- **净录制预估**：约 30 分钟/遍。


## 3. 画面、操作与后期总规则

### 3.1 画面规格

- 成片画布为 **16:9**，建议交付 `1920 × 1080`；若源窗口比例不同，应在录制前调整可见区域或后期裁切，不能拉伸界面。
- 录制原始画面时关闭系统声音、应用提示音和通知；录屏只保留清晰的界面操作，AI 旁白在后期单独合成。
- 每个镜头只表达一个意图。页面、下拉菜单和对话框完全稳定后再开始操作；不录入加载抖动、无关菜单或鼠标试探。
- 需要突出字段时仅做克制的局部放大，放大前后保留页面方向感；不使用快速摇镜、夸张缩放或遮挡主要操作区的特效。

### 3.2 鼠标与停留规则

- 鼠标沿短路径移动，点击后离开关键文字；不要绕圈、反复悬停或用光标代替旁白。
- 打开页面、对话框或预览表后停留约 **1 秒**，让观看者看清标题和内容。
- 文件选择对话框出现后直接选择预检文件，不聚焦路径；文件名仅展示 basename。
- 成功提示（“资源包导出成功”“导入完成：…”）保留 **0.8–1.5 秒**，随后再切换下一步。
- 出现任何可见错误、重复校验、错误数据、误点击或个人信息时，**从该镜头开头重录**；不要以裁切、马赛克或加速掩盖操作错误。

### 3.3 旁白与字幕规则

- 旁白使用经试听通过的中文 AI 声音；本包不指定具体供应商、声音名称或固定语速。
- 旁白应说明“为什么做”和“操作结果”，不逐字念出每次鼠标点击；画面中的按钮和字段由字幕辅助定位。
- 字幕与旁白同义、逐镜头校时。每条最多两行，避免遮挡预览表、摘要标签、策略选项、按钮及成功提示。
- 术语以实时构建为准：如录制构建调整了文案，可替换字幕中的对应词，但不得改变“导出 → 导入 → 校验预览 → 选择策略 → 回查”的业务顺序。

## 5. 录制执行清单

1. 按第 2 节完成可恢复环境检查：确认情绪资源非空、资源内容无绝对路径、导出目录与文件就绪；记录全部运行时占位符的实际值。
2. 先静音录一遍完整画面；仅检查流程、隐私、光标和停留，不在此阶段生成旁白。
3. 回看原始录屏：任何数据泄露、加载异常、错误提示、误选“更新已有”策略、文件路径进入画面、预览表出现绝对路径、或未能回查副本资源，都从受影响镜头开头重录。
4. 依据第 4 节生成 AI 旁白，先输出可试听音频，再与已确认的画面匹配；不要直接把未经试听的 TTS 音频导出为成片。
5. 依据字幕列制作字幕，逐句检查进入和离开时间；字幕出现应略早于或与对应动作同时，不应滞后到下一步。
6. 完成合成后，从头无中断观看一次；验收通过才导出交付版。录制结束后立即按预先确认的可恢复流程恢复环境并删除资源包文件。

## 6. 音频、剪辑与导出门禁

### 6.1 音频试听门禁

在最终合成前，至少由录制者完整试听一次 AI 旁白，并逐项通过：

- 声音自然、适合面向学校管理员的说明语气；
- 语速能让观看者同时看清预览表、策略和操作，关键停顿自然；
- 音量在全片一致，未被系统声、背景音乐或提示音覆盖；
- “业务分组”“导出资源包”“导入资源包”“情绪场景”“表达关心”“JSON 包”“选择资源包”“导入副本”“开始导入”“导入完成”等中文术语发音正确；
- 无漏读、重读、截断、机械连读或难以辨识的词句。

任一项不通过时，只重生成或重校该段音频并复听；不要通过过度加速、压缩静音或堆叠背景音乐掩盖问题。

### 6.2 画面与字幕门禁

- 每个镜头都可独立看懂一个意图，转场不打断一次导出、导入或回查动作。
- 关键页面标题、按钮“导出资源包”“选择资源包”“开始导入”、摘要标签、策略选项和成功提示在 16:9 画面中可读。
- 字幕不遮挡预览表、摘要标签、策略选项、按钮或成功提示；无错别字、占位符、旧产品名称或历史样例数据。
- 成片不得出现真实个人数据、管理员账号、令牌、**文件路径（含文件选择对话框的完整路径与资源字段中的绝对路径）**、通知横幅、调试窗、密码管理器或录制工具控件。
- 导出为可播放的 16:9 MP4（H.264 视频与 AAC 音频为推荐兼容组合）；导出后使用独立播放器从头试听、查看字幕和核验总时长。
