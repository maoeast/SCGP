# 《教师：完成一次量表评估》人工录制包

> **状态**：当前有效，待按本包录制与验收
> **产品**：SCGP / 星愿能力发展平台
> **受众**：首次使用系统的学校教师（管理员可代为录制）
> **成片目标**：2–3 分钟、16:9；先无声录屏，再配 AI 旁白和字幕
> **范围**：为一名虚构学生完成一次 SDQ 量表评估（选题、选人、作答、完成、查看报告）
> **系列**：本片为第三支，承接《管理员：班级与学生管理》《管理员：批量分班与学年升级》；学生档案与班级已就绪，本片不重复建档、建班或分班。
> **不作为事实来源**：`output/videos/管理员：班级与学生管理.mp4`、`scripts/video/` 及其旧分镜仅为历史参考，不能复用其时长、分辨率、样例数据、旁白、选择器或语音配置。

## 1. 本片要解决什么

本片演示教师如何在“能力评估”中为一名虚构学生完成一次标准量表评估：在评估中心选择量表、选择评估学生、阅读评估说明、逐题作答，最后查看评估报告。

量表评估是评估主链（`AssessmentContainer` + `ScaleDriver`）的统一入口，评估结果持久化后由报告页呈现，供教师结合日常观察制定支持计划。本片固定演示 **SDQ 长处和困难问卷（父母版）**：25 道题、三档选项，题量在问卷式量表中最少、报告结构最典型。本片只说明这一业务结果，不承诺替代学校既有的评估、诊断或审批流程。

### 角色与范围边界

- 录制账户为**教师或管理员**，旁白以“教师”指代操作者（量表评估是教师职责，相关路由对教师开放）；不得把操作表述为学生、家长或其他无关角色。账号信息不出现在画面中。
- 演示页面依次为：能力评估（评估中心）→ 选择评估学生 → 评估说明 → 评估作答 → 评估完成 → 评估报告。
- 仅使用一名虚构学生，年龄须在 SDQ 适用范围（3–16 岁）内；不展示真实姓名、学号、照片、诊断、联系方式、评估结果或训练记录。
- 不演示：绩效题量表（如认知自我、精细动作）、CBCL 社会能力表单、进度恢复弹窗、选人页“添加新学生”、报告页“导出 Word”“查看历史”、报告中心与趋势页。
- 若录制环境的授权不含 SDQ（需 `emotional` 或 `social_communication` 能力包其一），可换用另一份已授权、问卷式、条数较少的量表，并按第 3.3 节规则同步替换本包内的量表文案与题数；不得改变“选题 → 选人 → 说明 → 作答 → 完成 → 报告”的业务顺序。
- 不演示导入、数据库替换、数据抽取、演示 ZIP 修改或产品数据目录写入。`docs/guides/seed-demo-data.md` 仅可作为历史参考，不是本片的执行路径。

在打开录制软件前，由执行人逐项确认。任一项不满足时，停止录制并先修正环境，不用剪辑掩盖问题。

| 检查项 | 必须满足的条件 |
| --- | --- |
| 账户与页面 | 已使用教师或管理员账户登录；左侧菜单“能力评估”可见可进入。 |
| 数据环境 | 使用可丢弃、可完整恢复的录制数据库；绝不连接生产库或含真实人员信息的库。 |
| 虚构学生 | 一名虚构学生 `[虚构学生姓名]` 已建档、年龄 3–16 岁（SDQ 适用范围），且对录制账户可见（教师账户受数据范围限制时，改用管理员账户录制）。 |
| 量表授权 | `[已选定量表]`（推荐 SDQ 长处和困难问卷）在评估中心的“已按授权过滤”卡片列表中可见；不可见时先补齐授权或按第 1 节换表。 |

| 回滚 | 已明确录制结束后的恢复方式：还原该可丢弃数据库或按既有安全流程清理本次虚构学生与本次评估记录；不得对真实库做清理。 |

运行时只使用以下占位符替换为已核验的实际值，不在脚本中预设具体学生名：

- `[虚构学生姓名]`
- `[已选定量表]`（推荐 SDQ；本包其余文案按 SDQ 编写）

### 2.1 录制效率提示

- **批次**：B-1（先行，总纲 §2）。本支产出 SDQ 报告，供第 9、14、20 支复用。
- **预置**：学生年龄 3–16 岁；SDQ 在评估中心可见；录制前清 localStorage 评估进度快照。
- **一次通过要点**：①有未完成进度会弹"恢复评估进度"——必须先清；②答最后一题自动进入完成流程（无需点"完成评估"）；③答题中间可跳剪，但首题与末题保持自然节奏。
- **净录制预估**：约 40 分钟/遍（含 25 题作答）。


## 3. 画面、操作与后期总规则

### 3.1 画面规格

- 成片画布为 **16:9**，建议交付 `1920 × 1080`；若源窗口比例不同，应在录制前调整可见区域或后期裁切，不能拉伸界面。
- 录制原始画面时关闭系统声音、应用提示音和通知；录屏只保留清晰的界面操作，AI 旁白在后期单独合成。
- 每个镜头只表达一个意图。页面、下拉菜单和对话框完全稳定后再开始操作；不录入加载抖动、无关菜单或鼠标试探。
- 需要突出字段时仅做克制的局部放大，放大前后保留页面方向感；不使用快速摇镜、夸张缩放或遮挡主要操作区的特效。

### 3.2 鼠标与停留规则

- 鼠标沿短路径移动，点击后离开关键文字；不要绕圈、反复悬停或用光标代替旁白。
- 打开页面、卡片或对话框后停留约 **1 秒**，让观看者看清标题和内容。
- 选项点击后系统约 0.3 秒自动进入下一题；镜头 5 的连续作答按此节奏录制，不要抢点。
- 完成后的“评估已完成”提示与完成弹窗保留 **0.8–1.5 秒**，随后再切换下一步。
- 出现任何可见错误、重复校验、错误数据、误点击或个人信息时，**从该镜头开头重录**；不要以裁切、马赛克或加速掩盖操作错误。

### 3.3 旁白与字幕规则

- 旁白使用经试听通过的中文 AI 声音；本包不指定具体供应商、声音名称或固定语速。
- 旁白应说明“为什么做”和“操作结果”，不逐字念出每次鼠标点击；画面中的按钮和字段由字幕辅助定位。
- 字幕与旁白同义、逐镜头校时。每条最多两行，避免遮挡答题选项、进度条、对话框底部按钮及成功提示。
- 术语以实时构建为准：如录制构建调整了文案（含更换量表），可替换字幕中的对应词，但不得改变“选题 → 选人 → 说明 → 作答 → 完成 → 报告”的业务顺序。

## 5. 录制执行清单

1. 按第 2 节完成可恢复环境检查，记录全部运行时占位符的实际值。
2. 先静音录一遍完整画面；仅检查流程、隐私、光标和停留，不在此阶段生成旁白。
3. 回看原始录屏：任何数据泄露、加载异常、错误提示、误点“添加新学生”或“导出 Word”、误入绩效题量表、出现进度恢复弹窗或未能查看报告，都从受影响镜头开头重录。
4. 依据第 4 节生成 AI 旁白，先输出可试听音频，再与已确认的画面匹配；不要直接把未经试听的 TTS 音频导出为成片。
5. 依据字幕列制作字幕，逐句检查进入和离开时间；字幕出现应略早于或与对应动作同时，不应滞后到下一步。
6. 完成合成后，从头无中断观看一次；验收通过才导出交付版。录制结束后立即按预先确认的可恢复流程恢复环境。

## 6. 音频、剪辑与导出门禁

### 6.1 音频试听门禁

在最终合成前，至少由录制者完整试听一次 AI 旁白，并逐项通过：

- 声音自然、适合面向学校教师的说明语气；
- 语速能让观看者同时看清题目、选项和操作，关键停顿自然；
- 音量在全片一致，未被系统声、背景音乐或提示音覆盖；
- “能力评估”“评估中心”“选择评估学生”“评估说明”“我已了解，开始评估”“完成评估”“评估完成”“查看报告”“SDQ 长处和困难问卷”等中文术语发音正确；
- 无漏读、重读、截断、机械连读或难以辨识的词句。

任一项不通过时，只重生成或重校该段音频并复听；不要通过过度加速、压缩静音或堆叠背景音乐掩盖问题。

### 6.2 画面与字幕门禁

- 每个镜头都可独立看懂一个意图，转场不打断一次作答、完成或报告动作。
- 关键页面标题、量表卡片、选项文字、按钮“我已了解，开始评估”“完成评估”、提示“评估已完成”和最终报告在 16:9 画面中可读。
- 字幕不遮挡题干、答题选项、进度条、对话框底部按钮或成功提示；无错别字、占位符、旧产品名称或历史样例数据。
- 成片不得出现真实个人数据、教师/管理员账号、令牌、文件路径、通知横幅、调试窗、密码管理器或录制工具控件。
- 导出为可播放的 16:9 MP4（H.264 视频与 AAC 音频为推荐兼容组合）；导出后使用独立播放器从头试听、查看字幕和核验总时长。
