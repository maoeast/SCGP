# 首页看板下半部布局重排（今日训练日程 / 本周异常预警 / 智能特教助理）

> 状态：已实现（2026-09-21）。本文是首页看板下半部**三面板布局与容器行为**的唯一真源。
> 三个面板的**判定口径**不在本文：异常预警见《2026-09-21-首页本周异常预警-判定口径.md》，智能特教助理见《2026-09-21-首页智能特教助理-评估缺口与干预建议.md》；改布局不得动口径。

## 1. 动机

下半部三面板的观感问题（2026-09-21，用户两轮提出）：

1. 今日训练日程卡片横向过度拉伸、卡片中部留白；面板内容少时整块空白（网格行高由更高的一栏决定，短的一栏被拉出大片死区）。
2. 本周异常预警空态占固定大高度，纵向空间被白占。
3. 右栏两面板挤在窄宽度里，文字换行、高度不可控；页面高度随数据量变化。

目标：三面板同一行（≈ 1.15 : 0.95 : 0.95）、**统一固定高度**、条目超出时面板内滚动；条目收敛为一行摘要，完整信息交给既有「查看全部」弹层与学生详情页。

## 2. 布局结构（规范面 = 现状）

- **看板** `.dashboard-board`：`grid-template-columns: minmax(0, 1.15fr) minmax(0, 0.95fr) minmax(0, 0.95fr)`、`gap: 16px`、`align-items: stretch`。宿主 `.dashboard-board-host` 设 `container-type: inline-size; container-name: dashboard-board`（降级阶梯按看板自身宽度判定）。
- **统一固定高度** `.board-panel`：`display: flex; flex-direction: column; height: 520px; overflow: hidden`。面板 = 头部 + `.board-panel__body`（滚动区）+ 可选 `.board-panel__foot`。**页面高度不随数据量变化**。
- **滚动区** `.board-panel__body`：`flex: 1 1 auto; min-height: 0; overflow-y: auto; overscroll-behavior: contain`，并以 `padding-right: 6px; margin-right: -6px` 给滚动条留位。
- **空态** `.board-panel__empty`：`display: flex; flex: 1 1 auto; flex-direction: column; align-items: center; justify-content: center` —— 空态撑满滚动区并在固定高度内垂直居中，不出现「顶部一条 + 下方大片空白」。用 flex 撑满而非百分比 `min-height`：父级高度未定时百分比会塔成零高（空态在真实环境会不可见）。
- **面板头部**：仅标题 + 角标（异常 / 助理面板另有「查看全部」），**不带说明文字**——标题与角标已表达关键信息，去掉说明行让内容区多露出约小半行、滚动更少。
- **条目形态**（三面板统一：`StudentAvatar size="sm"` + 主信息 + 行尾信息）：
  - 今日训练日程 `.schedule-item`：`.schedule-item__main` 两行 —— 行一 `.schedule-item__line`（姓名 + 模块标签 + 计划名，计划名 `flex: 1` 省略）；行二 `.schedule-item__line--meta`（周期 / 资源 / 首项，12px `--scgp-subtle`）。行尾 `.schedule-item__actions` 为「开始训练」按钮（`:deep(.el-button)` `white-space: nowrap`）。
  - 本周异常预警 `.alert-item--danger`：`alert-item__body` = 姓名 + `reason`（一句话结论，超长省略）；行尾 `.alert-item__metric` 一个关键指标——按语义家族降级取第一个可用项（`accuracyRate` → 「正确率 X%」、`promptLevel` → 「提示 N 级 高辅助」、`hintRatio` → 「每题提示 N.NN 次」），家族均不适用时退回 `sessionLabel`。模块 / 会话 / 时间进 `title` 悬浮提示。
  - 智能特教助理 `.alert-item--warning`：姓名 + `suggestion`（一句话建议，超长省略）+ `.alert-item__metric`（`daysSinceLastAssessment === null` → 「尚无评估记录」；带 `overdue` 标签 → 「超期 N 天」；其余 → 「最近评估 N 天前」）。病种名与能力标签进 `title` 悬浮提示与「查看全部」弹层。
  - 三个面板的**判定口径与取数不变**；面板内不再平铺标签明细与全部统计（明细在弹层）。
- **显示条数**：**不截断**——`snapshot.schedule` / `snapshot.anomalies` / `snapshot.assessmentInsights` 全量渲染，由固定高度 + 内部滚动承载；「查看全部」弹层保留为完整信息入口（标签明细、全部指标、建议句），条件为「该面板有条目」。
- **今日训练进度**（日程面板底部 `.board-panel__foot`）：左「今日已完成训练 X 次」、右「计划 Y 项」，下方 `.schedule-progress__track` + `.schedule-progress__fill`，`fill = min(X / Y, 1)`。
  - X = `snapshot.trainingProgress.summary.todayCount`（今日会话数，与卡片「训练进度概览」同源）。
  - Y = `snapshot.overview.todayTaskCount`（= 今日计划数，与 hero 指标卡同源）。
  - **分子是训练次数、分母是计划项数，单位不同**：故只用进度条表达比例，两个数字分列展示，不写成「X / Y」分式以免误读为「已完成 X 个计划」。
- **异常预警空态** `.alert-empty`：紧凑横幅（`min-height: 88px`），内容仅 `.alert-empty__badge`（42×42 圆角块 + `CircleCheck`）与 `.alert-empty__text`「本周干预数据平稳」。

## 3. 响应式降级（容器查询阶梯）

```css
.dashboard-board-host { container-type: inline-size; container-name: dashboard-board; }
.dashboard-board { grid-template-columns: minmax(0, 1.15fr) minmax(0, 0.95fr) minmax(0, 0.95fr); }

/* 看板 800–1139px：日程独占整行，预警 / 助理并排 */
@container dashboard-board (max-width: 1139px) {
  .dashboard-board { grid-template-columns: repeat(2, minmax(0, 1fr)); }
  .board-panel--schedule { grid-column: 1 / -1; }
}

/* 看板 < 800px：三面板单列堆叠 */
@container dashboard-board (max-width: 799px) {
  .dashboard-board { grid-template-columns: minmax(0, 1fr); }
}
```

按**看板自身宽度**判定而非视口：看板宽 = 视口 − 侧边栏 − 页内边距，且侧边栏在窄视口下会收敛，媒体查询会把不同情形判错。

日程行内部再按**面板宽度**切换单行 / 两行：

```css
.schedule-panel { container-type: inline-size; container-name: schedule-panel; }
@container schedule-panel (min-width: 820px) {
  .schedule-item__main { flex-direction: row; align-items: center; }
}
```

Chromium 实测（252px 侧边栏 + 24px 页内边距的壳）：

| 视口 | 看板宽 | 档位 | 三面板宽 |
|---|---|---|---|
| 1920 | 1620 | 三栏 | 599 / 495 / 495（日程行为两行） |
| 1600 | 1300 | 三栏 | 478 / 395 / 395 |
| 1440 | 1140 | 三栏（临界） | 418 / 345 / 345 |
| 1366 | 1066 | 日程整行 + 两面板并排 | 1066；525 / 525（日程行合一为单行） |
| 1000 | 700 | 单列堆叠 | 700 × 3 |

## 4. 边界与取舍

- **固定高度 520px** 为三面板统一值：页面高度恒定、数据量不影响版式；代价是条目多时须在面板内滚动——这是本方案明确选择的形态。
- 面板滚动条只在内容真正超出时出现；条目少或空态时面板留白由垂直居中吸收。
- 日程行在 599px 宽（1920 三栏）下为「主信息行 + 次要信息行」两行形态：「头像 + 姓名 + 标签 + 计划名 + 周期/资源/首项 + 按钮」物理上排不进一整行（实测需 ≥820px 面板宽），因此宽面板（日程独占整行的档位）才合并为真正的单行。
- 面板内的行高：预警 / 助理一行摘要约 48px；日程两行形态更高一档。

## 5. 不做什么

- 不动三个面板的判定口径与取数接口（`dashboard-api.ts`）、标题与角标文案。
- 不动看板上半部分（`.dashboard-hero`、指标卡、AI 助手区、最近添加的学生、训练进度概览）。
- 不引入 CSS 框架 / Mock 数据组件：改动落在真实 `src/views/Dashboard.vue`。
