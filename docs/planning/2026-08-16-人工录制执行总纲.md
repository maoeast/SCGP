# 《SCGP 人工录制执行总纲》（技术同事录制手册）

> **状态**：当前有效，配套 22 支录制包（`docs/planning/2026-08-15/16-*.md`，索引见 `docs/INDEX.md`）
> **用途**：让执行人按最高效的顺序完成 22 支人工录制。本纲只讲"怎么准备、按什么顺序、怎么避免返工"；每个镜头的画面、旁白、字幕以各支包的第 4 节分镜为准，本纲不替代分镜。
> **一句话**：先定共享占位符 → 一次性搭好录制环境 → 按批次顺序录制 → 每包录完立即回滚 → 后期统一走工具链 + 人工门禁。

## 1. 录制前一次性准备（约 60–90 分钟，只做一次）

### 1.1 共享占位符总表（先定值，全系列复用）

| 共享值 | 建议取值 | 使用包 |
| --- | --- | --- |
| 虚构学生甲 | `演示生甲` | 1、2、3、5、6、7、10、12、14、20 |
| 虚构学生乙 | `演示生乙` | 1、2（批量分班三人组） |
| 虚构学生丙 | `演示生丙` | 1、2（批量分班三人组） |

| 上传文件 | 演示 PDF/图片 | 21 |

### 1.2 环境准备清单

1. 构建可丢弃录制库：初始化即自动预置当前+下一学年、量表（含 SDQ）、模型服务商（DeepSeek/火山方舟）。
2. 载入演示数据（`output/SCGP演示数据包-20260806.zip` 或 seed 脚本）：教学资料+素材目录、情绪场景/关心情境、器材与游戏资源。
3. 创建虚构学生 3 名（供批次 A 起步；姓名与 1.1 总表一致）。
4. 系统设置：系统静音、通知全部关闭、鼠标指针可见、桌面无干扰元素。
5. 录屏工具：固定区域录制（16:9 窗口 1920×1080 或 1280×720，不缩放 UI）、关闭水印、关闭录制工具自身 OSD。
6. 建立"占位符 → 实际值"映射表：每支包 §2 的占位符填值后随包存档，供旁白/字幕阶段取用。

### 1.3 每支包开始前 60 秒

1. 打开该包文档，把 §2 占位符对照 1.1 总表填值。
2. 逐项执行 §2 前置条件打勾（重点：数据唯一性、进度快照清理、口令、授权可见、文件预置）。
3. 把应用窗口调整到该包镜头 1 的初始状态。
4. 确认系统静音后开始录制。

## 2. 批次与录制顺序（最高效路径）

同批次共享同一录制库与预置状态，**先录的包为后录的包生产数据**；每包录完立即回滚（见 §5），但同批次内可连续录制后统一回滚。

| 批次 | 包含支 | 共享环境 | 顺序与理由 |
| --- | --- | --- | --- |
| A 数据基础 | 1、2、11 | 学生、班级、学年 | 1 建 3 名学生与班级 → 2 批量分班/学年升级复用 → 11 用户与学年（新增学年与 2 的 `[新学年]` 呼应） |
| B 评估链 | 3、9、14、20 | 评估报告 | 3 完成 SDQ 评估（产出报告）→ 9 报告中心回查该报告；14 需批次 C 的训练记录，20 需在评估环境再做一次评估并停在完成弹窗 |
| C 训练链 | 5、6、7 | 计划、器材、游戏 | 5 建计划+器材录入 → 6 器材连续录入 → 7 游戏训练（独立于 5/6，仅需学生） |
| D 情绪链 | 10、12 | 情绪场景/关心情境 | 10 情绪场景训练 → 12 表达关心训练（同构，一次熟悉两次快） |
| E 资源链 | 4、8、19、21 | 资源库、素材目录、CSV | 4 教学资料浏览/收藏 → 8 训练资源维护 → 19 情绪资源包导入导出 → 21 教学资料上传/批量导入（依赖素材目录+预填 CSV） |
| F 系统链 | 13、16、18、17、22 | 口令、备份文件、AI 配置 | 13 备份 → 16 AI 配置（18 依赖其成果）→ 18 AI 对话 → 17 恢复（13 的流程做预检）→ 22 备份恢复演练（最后，综合） |
| G 看板 | 15 | 任意库 | 数据最全时最后顺带录制 |

**建议总顺序**：A → B(3、9) → C → B(14、20) → D → E → F → G。

## 3. 单镜头通用 SOP

1. **稳定**：等待页面、下拉、对话框完全渲染（无 loading、无抖动）再操作。
2. **动作**：鼠标短路径移动，点击后离开关键文字；不绕圈、不悬停当旁白。
3. **停留**：下拉/对话框约 1 秒；成功提示 0.8–1.5 秒；分镜另有规定的按分镜。
4. **校验**：肉眼确认无错误提示、无个人信息、无文件路径入画。
5. **出错即整镜重录**：不做裁切、马赛克或加速补救。

## 4. 后期合成 SOP（沿用 `scripts/video/` 工具链）

1. 按各包第 4 节旁白列分段生成 AI 旁白（`msedge-tts`）→ 完整试听一遍（§6.1 门禁逐项）。
2. 字幕逐句对时（进入不晚于对应动作；每条 ≤2 行，不遮挡操作区）。
3. `ffmpeg` 合成：16:9、H.264 + AAC。
4. 从头无中断观看一遍 + 各包 §7 验收清单逐条打勾 + 独立播放器核验流参数与总时长。

## 5. 跨包复用与回滚

- 每支包录完立即按该包 §2"回滚"要求还原录制库/清理增量（占位符值、备份文件、资源包、会话等），避免污染下一支的初始状态。
- 同批次内连续录制的包可先录完再统一回滚（如 10/12、3/9）。
- 回滚方式：还原录制库快照，或按既有安全流程清理本次增量。

## 6. 常见返工原因 Top 10（录制前逐项自查）

1. **文件路径入画**：4/13/17/19/21（素材目录、保存/选择对话框、详情"受管路径"——取景或跳剪规避）。
2. **口令不一致**：13/17/22（两段式输入必须一致）。
3. **进度快照弹窗**：3（录制前清 localStorage `assessment_progress`）。
4. **授权未激活导致空态**：3/7/10/12/19/20（先确认能力包授权与资源可见）。
5. **回复内容不可控**：18（通用问题；异常/含个人信息必须重录或换问题）。
6. **素材/文件未预置**：4/21（素材目录、上传文件、预填 CSV 先就绪）。
7. **toast 文案与分镜不符**：以实际构建为准；若属产品文案变更，改分镜备注而非强行重录（若是操作错误则整镜重录）。
8. **学生/资源重名**：1/8/11（名称唯一性前置）。
9. **状态残留**：4（收藏状态）、18（隐私确认状态）、22（演练学生残留）。
10. **摄像头类游戏**：7（必须选"颜色配对"等非摄像头游戏）。
