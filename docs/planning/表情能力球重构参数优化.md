## 任务背景

表情能量球小游戏（吹走乌云关卡）是为特殊儿童设计的表情训练游戏，通过摄像头实时识别面部表情（开心、惊讶、放松等），引导孩子完成关卡。
当前版本存在以下问题需要修复：
1. 27寸横屏布局严重不均衡，右半屏大片空白
2. 能量球视觉太小，缺乏儿童吸引力
3. 表情反馈用数字条形图，孩子看不懂
4. 表情识别门槛过高，持续时间要求过长，会挫败孩子积极性

---

## 一、UI 布局重构（三栏等宽布局）

### 总体结构
将游戏区域分为三栏（flex row，每栏约 30% / 40% / 30%）：

**左栏 — 摄像头镜像区**
- 保留摄像头实时画面
- 在摄像头画面上叠加一个"示范表情"小卡片（右下角），显示本关要做的表情图示（emoji 或插画）
- 摄像头边框：圆角 24px，有淡色 glow 动效表示"检测中"

**中栏 — 主能量球区（核心视觉）**
- 能量球直径放大至约 220px（原来约 80px），放在中栏垂直居中
- 能量球使用 CSS radial-gradient 或 SVG 渐变营造"光球"感，根据当前表情能量值动态改变颜色饱和度和大小（pulse 动效）
- 能量球正上方：大字任务引导文字，例如"😄 张大嘴巴，吹走乌云！"，字号 26px，粗体
- 能量球正下方：当前能量百分比，用彩色数字显示（如 "⚡ 87%"），字号 22px
- 进度条放在能量球底部，宽度 200px，高度 12px，圆角，渐变填充（蓝→黄→橙）
- "太棒了！"反馈动效：当能量达到100%时，触发彩带粒子爆炸动效（canvas confetti 或 CSS keyframe），持续 2 秒

**右栏 — 表情状态面板**
- 移除原有的数字条形图
- 改为 2×2 表情图标卡片网格，每个卡片包含：
  - 表情大图标（emoji，字号 36px）
  - 表情名称（字号 14px）
  - 圆形进度环（SVG circle stroke-dashoffset，直径 60px）
  - 进度环内显示当前检测值（如 "41"）
- 当某个表情被检测到时，对应卡片触发"弹跳+发光"动效（CSS animation）
- 四个表情：😄 开心 / 😲 惊讶 / 😠 生气 / 😌 平静

### 底部导航
- "上一关" / "下一关" 按钮移至页面底部**水平居中**
- 按钮高度 56px，宽度 140px，圆角 28px（胶囊按钮）
- 当前激活的导航按钮背景色 #4FC3F7，文字白色，字号 18px

## 二、表情识别参数调整

### 当前问题
表情持续时间阈值过长（推测约 800–1000ms），置信度阈值过高，导致特殊儿童因表情控制能力弱而无法触发，严重挫败积极性。

### 修改要求
找到表情识别相关配置或逻辑（可能在 config、constants 或 gameLogic 文件中），进行以下调整：

```javascript
// 修改前（推测值）
const EMOTION_HOLD_DURATION = 800;   // ms
const EMOTION_CONFIDENCE_THRESHOLD = 0.7;

// 修改后
const EMOTION_HOLD_DURATION = 300;          // ms，降低持续时间要求
const EMOTION_CONFIDENCE_THRESHOLD = 0.45;  // 降低置信度阈值
const EMOTION_SMOOTH_FRAMES = 5;            // 新增：5帧滚动平均，减少抖动误判
```

**滚动平均实现：**
维护一个长度为 5 的滑动窗口数组，每帧将最新置信度 push 进去，取平均值作为实际使用的置信度，代替直接使用原始帧值。

**分级反馈机制（新增）：**
- 检测值 ≥ 30%：显示"继续！加油！"文字动效（淡入淡出，不打断游戏）
- 检测值 ≥ 60%：能量球开始 pulse 发光，音效提示（如有）
- 检测值 ≥ 100%：触发完成庆祝动效

## 三、视觉风格要求

- 整体保留现有的天蓝色渐变背景（#E3F4FF → #FFF8E1），不改变
- 字体：系统默认 sans-serif，中文优先
- 动效：优先使用 CSS animation / transition，避免重型动画库
- 触摸目标：所有可交互元素最小 80×80px（适配触摸屏）
- 不要改动摄像头接入逻辑、表情识别模型调用、分数计算逻辑等核心功能代码
- 不要修改未涉及的关卡文件
