# 《管理员：教学资料上传与批量导入》人工录制包

> **状态**：当前有效，待按本包录制与验收
> **产品**：SCGP / 星愿能力发展平台
> **受众**：首次使用系统的学校管理员
> **成片目标**：2–3 分钟、16:9；先无声录屏，再配 AI 旁白和字幕
> **范围**：在资源管理页的教学资料 Tab 上传一份教学资料，并演示 CSV 模板下载与批量导入
> **系列**：本片为第二十一支，承接《管理员：教学资料管理》（第四支为浏览，本片为上传与批量导入）；教学资料数据与素材目录已就绪。
> **不作为事实来源**：`output/videos/管理员：班级与学生管理.mp4`、`scripts/video/` 及其旧分镜仅为历史参考，不能复用其时长、分辨率、样例数据、旁白、选择器或语音配置。

## 1. 本片要解决什么

本片演示管理员如何向教学资料库添加资料：单个上传一份教学资料（填写标题、业务维度、文件与标签），并演示批量导入的完整流程（选择素材目录、下载 CSV 模板、上传描述清单、校验后落库）。

批量导入规则：先选择客户交付的素材目录，再上传描述文件清单的 CSV，系统先校验文件存在，再复制到受管目录并落库，缺失文件不会写入数据库。本片只说明这一业务结果，不承诺替代学校既有的素材版权或采购流程。

### 角色与范围边界

- 录制账户为**管理员**，旁白以“管理员”指代操作者（上传/批量导入按钮仅管理员可见，教师为只读）；不得把操作表述为教师、学生或其他角色。账号信息不出现在画面中。
- 演示页面：资源管理 → 教学资料 Tab（上传教学资料对话框、批量导入教学资料对话框）与资料列表回查。
- 上传与导入均为演示数据（虚构标题与演示文件）；CSV 由录制前按模板预填，包含 1–2 条演示记录。
- 不演示：选择/更换素材目录的文件夹选择对话框细节、素材目录路径展示、CSV 模板的表格内容细节、导入错误列表展开、删除/编辑资料。
- 不演示导入、数据库替换、数据抽取、演示 ZIP 修改或产品数据目录写入。`docs/guides/seed-demo-data.md` 仅可作为历史参考，不是本片的执行路径。

## 2. 录制前置条件与安全检查

在打开录制软件前，由执行人逐项确认。任一项不满足时，停止录制并先修正环境，不用剪辑掩盖问题。

| 检查项 | 必须满足的条件 |
| --- | --- |
| 账户与页面 | 已使用管理员账户登录；左侧菜单“资源管理”可见可进入，教学资料 Tab 展示维护按钮。 |
| 数据环境 | 使用可丢弃、可完整恢复的录制数据库；教学资料文件与素材目录已就绪；绝不连接生产库或含真实人员信息的库。 |
| 上传文件 | 准备一个演示资料文件 `[上传文件]`（如演示 PDF/图片），内容不含个人信息。 |
| 批量导入 | 录制前按 CSV 模板预填 `[预填 CSV 文件]`（1–2 条演示记录，对应素材目录中的演示文件）；素材目录为演示目录；批量导入结果区“成功导入/失败数量”以实际为准（期望失败为 0）。 |
| 路径规则 | 批量导入对话框中的“当前素材目录”会展示目录路径：**取景不得让该路径行进入画面**（必要时跳剪或局部取景）；文件夹选择对话框不聚焦路径。 |
| 运行状态 | 页面加载完成、无报错提示、浏览器/系统通知关闭，缩放和字体在 16:9 画面中清楚可读。 |
| 回滚 | 已明确录制结束后的恢复方式：还原该可丢弃数据库（含本次上传与导入的资料）或按既有安全流程清理；不得对真实库做清理。 |

运行时只使用以下占位符替换为已核验的实际值：

- `[上传文件]`（演示文件，含文件名与大小展示）
- `[资料标题]`（演示标题）
- `[业务维度]`（如“感官训练”）
- `[预填 CSV 文件]`

### 2.1 录制效率提示

- **批次**：E-4（依赖素材目录；与第 4 支同库）。
- **预置**：`[上传文件]` 与按模板预填的 `[预填 CSV 文件]` 就绪；素材目录可访问。
- **一次通过要点**：①批量导入需先选素材目录再选 CSV；②"当前素材目录"路径行禁入画面（取景或跳剪）；③导入结果"成功导入/失败数量"以实际为准（期望失败 0，非 0 先查素材与 CSV）。
- **净录制预估**：约 30 分钟/遍。


## 3. 画面、操作与后期总规则

### 3.1 画面规格

- 成片画布为 **16:9**，建议交付 `1920 × 1080`；若源窗口比例不同，应在录制前调整可见区域或后期裁切，不能拉伸界面。
- 录制原始画面时关闭系统声音、应用提示音和通知；录屏只保留清晰的界面操作，AI 旁白在后期单独合成。
- 每个镜头只表达一个意图。页面、下拉菜单和对话框完全稳定后再开始操作；不录入加载抖动、无关菜单或鼠标试探。
- 需要突出字段时仅做克制的局部放大，放大前后保留页面方向感；不使用快速摇镜、夸张缩放或遮挡主要操作区的特效。

### 3.2 鼠标与停留规则

- 鼠标沿短路径移动，点击后离开关键文字；不要绕圈、反复悬停或用光标代替旁白。
- 打开页面、对话框或下拉列表后停留约 **1 秒**，让观看者看清标题和内容。
- 文件选择对话框出现后直接选择预检文件，不聚焦路径；“当前素材目录”路径行不得进入画面。
- 成功提示（“教学资料上传成功”）与导入结果区保留 **0.8–1.5 秒**，随后再切换下一步。
- 出现任何可见错误、重复校验、错误数据、误点击或个人信息时，**从该镜头开头重录**；不要以裁切、马赛克或加速掩盖操作错误。

### 3.3 旁白与字幕规则

- 旁白使用经试听通过的中文 AI 声音；本包不指定具体供应商、声音名称或固定语速。
- 旁白应说明“为什么做”和“操作结果”，不逐字念出每次鼠标点击；画面中的按钮和字段由字幕辅助定位。
- 字幕与旁白同义、逐镜头校时。每条最多两行，避免遮挡上传表单、导入规则、导入结果区、按钮及成功提示。
- 术语以实时构建为准：如录制构建调整了文案，可替换字幕中的对应词，但不得改变“上传 → 回查 → 批量导入 → 回查”的业务顺序。

## 5. 录制执行清单

1. 按第 2 节完成可恢复环境检查：确认上传文件与预填 CSV 就绪、素材目录可访问、批量导入结果预期（失败为 0）；记录全部运行时占位符的实际值。
2. 先静音录一遍完整画面；仅检查流程、隐私、光标和停留，不在此阶段生成旁白。
3. 回看原始录屏：任何数据泄露、加载异常、错误提示、素材目录路径进入画面、误点删除/编辑、导入失败数量非预期、或未能回查新资料，都从受影响镜头开头重录。
4. 依据第 4 节生成 AI 旁白，先输出可试听音频，再与已确认的画面匹配；不要直接把未经试听的 TTS 音频导出为成片。
5. 依据字幕列制作字幕，逐句检查进入和离开时间；字幕出现应略早于或与对应动作同时，不应滞后到下一步。
6. 完成合成后，从头无中断观看一次；验收通过才导出交付版。录制结束后立即按预先确认的可恢复流程恢复环境（含本次上传与导入的资料）。

## 6. 音频、剪辑与导出门禁

### 6.1 音频试听门禁

在最终合成前，至少由录制者完整试听一次 AI 旁白，并逐项通过：

- 声音自然、适合面向学校管理员的说明语气；
- 语速能让观看者同时看清表单、导入规则和操作，关键停顿自然；
- 音量在全片一致，未被系统声、背景音乐或提示音覆盖；
- “教学资料”“上传教学资料”“资料标题”“业务维度”“资料文件”“批量导入教学资料”“下载CSV模板”“选择素材目录”“开始导入”“导入结果”等中文术语发音正确；
- 无漏读、重读、截断、机械连读或难以辨识的词句。

任一项不通过时，只重生成或重校该段音频并复听；不要通过过度加速、压缩静音或堆叠背景音乐掩盖问题。

### 6.2 画面与字幕门禁

- 每个镜头都可独立看懂一个意图，转场不打断一次上传、导入或回查动作。
- 关键页面标题、上传表单、导入规则、导入结果区、按钮“上传”“开始导入”和资料列表在 16:9 画面中可读。
- 字幕不遮挡上传表单、导入规则、导入结果区、按钮或成功提示；无错别字、占位符、旧产品名称或历史样例数据。
- 成片不得出现真实个人数据、管理员账号、令牌、**文件路径（含素材目录路径与文件选择对话框路径）**、通知横幅、调试窗、密码管理器或录制工具控件。
- 导出为可播放的 16:9 MP4（H.264 视频与 AAC 音频为推荐兼容组合）；导出后使用独立播放器从头试听、查看字幕和核验总时长。
