# MediaPipe 手游创意点子

> 来源：Gemini Chat 导出整理
> 日期：2026-05-25
> 用途：为 SCGP 后续基于 MediaPipe Hands / Three.js 的感官统合小游戏提供创意池，不代表已进入实现范围。

## MediaPipe Hands 2D 互动方向

### 1. 虚拟木块拼图与磁贴收集

- 核心玩法：屏幕上呈现镂空的木质小动物或几何阴影，儿童用空中“捏取”动作抓住散落木块，移动到对应阴影槽中后松开。
- 技术实现：用拇指尖与食指尖距离判断 pinch / release，食指尖位置作为虚拟光标。
- 反馈设计：木块使用木纹和浮雕效果，放入正确位置时触发磁吸贴合、清脆木块声和短暂粒子发光。

### 2. 魔法色彩调和坊

- 核心玩法：两侧放置基础颜料缸，中间是调色盘。儿童用左右手分别控制勺子，把不同颜色倒入调色盘，混合出新颜色。
- 技术实现：追踪左右手掌中心或手腕点位，通过双手在特定区域停留或靠拢触发倒入、融合。
- 反馈设计：颜色融合时展示水彩晕染和渐变动画，配合滴水声与魔法提示音。

### 3. 空气木琴与节奏敲击

- 核心玩法：屏幕下半部分排列五彩虚拟木琴条，儿童把双手当成鼓槌，向下挥动时触发对应音符。
- 技术实现：追踪双手食指尖 / 中指尖，检测 Y 轴向下速度和穿越目标线，不只依赖静态坐标碰撞。
- 反馈设计：木琴条被击中后下沉回弹，扩散彩色涟漪，播放清晰木琴音色。

### 4. 森林手势魔法屋

- 核心玩法：儿童切换握拳、张手、平移等手势，让种子经历落地、发芽、开花、引来蝴蝶等阶段。
- 技术实现：用手掌展开程度、握拳分类、掌心方向和稳定时长判断当前手势。
- 反馈设计：使用温暖绘本风格，配合泥土松动、细雨、花开等自然音效。

### 5. 小燕子风筝涂鸦飞行

- 核心玩法：儿童挥动手臂时，指尖轨迹生成彩虹线。轨迹闭合后生成风筝，再用双手左右摆动或身体倾斜控制飞行。
- 技术实现：用食指尖绘制 SVG 路径；用左右手掌高度差或双手间距映射风筝转向和升降。
- 反馈设计：风筝飞行伴随风声，穿过阳光或彩虹桥时触发得分音效。

## MediaPipe Hands + Three.js 3D 方向

### 1. 3D 物理木质积木挑战

- 核心玩法：3D 舞台中有悬浮托盘，儿童伸手在空间中抓取几何积木并堆叠。重心不稳时积木会滑落或倒塌。
- 技术实现：用 Three.js `MeshStandardMaterial` 表现木纹质感；可结合 Cannon.js / Ammo.js 做质量、摩擦和重力；用 MediaPipe 的 Z 轴估算前后深度。
- 训练价值：空间定位、手眼协调、精细动作控制。

### 2. 空间控板立体音乐滚球迷宫

- 核心玩法：屏幕中是 3D 迷宫盘，儿童双手平摆控制迷宫倾斜，小钢珠滚动并撞击彩色琴键发声。
- 技术实现：通过手掌关键点计算平面法向量，将法向量映射到迷宫模型 `rotation`；钢珠碰撞琴键时触发音符和粒子。
- 训练价值：双手协同、方向感、节奏与因果反馈。

### 3. 3D 魔法黏土与色彩挤压机

- 核心玩法：舞台中央悬浮一团 3D 黏土球，儿童用手势“按压”“拉伸”“喷色”，黏土随手势变形并混色。
- 技术实现：根据手指点与 3D 球体顶点距离修改 `geometry.attributes.position`；用顶点颜色实现局部染色扩散。
- 训练价值：触觉想象、双手协作、创造性表达。

### 4. 光影手艺人 3D 皮影戏

- 核心玩法：儿童做出孔雀、狼头、小鸟等手势，Three.js 场景中的虚拟聚光灯把手势投影到墙面，稳定后影子变成 3D 生物动画。
- 技术实现：使用 Three.js shadow maps 和手势分类；识别稳定手势后切换到对应 `SkinnedMesh` 动画。
- 训练价值：手势计划、模仿能力、视觉注意。

### 5. 3D 磁吸字母 / 拼音贴

- 核心玩法：左侧为 3D 磁吸白板，右侧排列带厚度的拼音字母。儿童捏取字母拖到白板，拼出正确读音后字母弹跳并播放语音。
- 技术实现：用 `THREE.Raycaster` 将 2D 指尖坐标转为 3D 拾取射线；靠近白板时做吸附阈值和回弹动画。
- 训练价值：认知匹配、拼音启蒙、空间拖拽。

## 设计注意事项

- 优先保证低挫败：目标尺寸要大，容错范围要宽，失败反馈不刺耳。
- 摄像头交互要提供降级：MediaPipe 不可用时至少保留鼠标 / 触摸模式。
- 3D 深度交互需要视觉线索：例如手部投影、目标高亮、靠近时放大或变亮。
- 训练记录不要只存得分，应记录稳定时长、尝试次数、双手协同情况等行为指标。
