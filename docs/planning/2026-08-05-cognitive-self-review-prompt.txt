## 1. 理论基础

### 1.1 测验范式与构念边界

Match-to-Sample（样本匹配）：呈现目标刺激，要求被试在干扰项中识别出与目标完全相同的刺激。认知负荷来自：

1. **辨别编码**：对目标刺激属性（形状、颜色、方向、大小、内部特征）进行特征编码与内部表征；
2. **比较决策**：将各选项与目标表征逐一比对，在相似干扰下抑制"近似即相同"的误判。

**构念边界**：
- 目标图在整道题作答期间持续显示（不测工作记忆）；
- RT 包含视觉搜索、决策与操作成分，不单独解释为"加工速度"；
- 数量类题目不纳入；单次颜色类错误不得推断色觉问题；
- **目标与正确选项的图元基准尺寸必须一致**（不引入大小恒常性要求，§3.4）。

### 1.2 与 CRT 的区别

| | CRT | 本任务 |
|---|---|---|
| 任务 | 矩阵规律补全（推理） | 目标匹配（找相同） |
| 核心构念 | 归纳推理 | 视觉图形匹配表现 |
| 难度来源 | 规律复杂度 | 干扰近似度（属性显著性 × 差异幅度） |

### 1.3 难度分层的目的

- 低龄/低能力儿童在前几级即可完成部分任务，避免地板效应；
- 通过各级正确率与 RT 对比，描述性定位本次表现较弱的题型（不推断认知缺陷）。

## 3. 新方案：4 级难度曲线模型

### 3.1 难度轴定义

**难度 = 需同时核对的属性数 × 属性差幅度 × 图形对称性影响**

> 分层为试测假设，最终以试测正确率、修正后项目总分相关与 RT 分布校准（§5.4）。

| 级别 | 需核对属性 | 差异幅度 | 认知负荷描述 |
|---|---|---|---|
| **L1 基础匹配** | 1–2 | 大（异形 / 异色） | 整体形状、颜色辨别（地板锚题） |
| **L2 精细辨别** | 2 | 方向 30–45° / 大小 ±8–10% | 方向、大小的细微差异 |
| **L3 双属性交叉** | 3 | 方向差 30° / 大小差 ±8% / 近色对 / 内部点 | 多属性同步锁定与干扰抑制 |
| **L4 高相似逼近** | 3–4 | 方向差 15° / 大小差 ±6% / 手性镜像 / 缺口 / 内部点 / 布局（无颜色干扰） | 最高辨别负荷（天花板探测） |

### 3.2 呈现顺序与平行版本

- 分块递进 L1→L4；每级内部题序随机；
- A/B 顺序版本（仅题序不同，不是平行题本；重测报告提示记忆/熟练效应）；
- 正解位置程序化约束：16 题 0/1/2/3 各 4 次、同一位置连续不超 2 次（构建测试验证）；
- 2 道不计分练习题（与正式题不复用任何 target/选项组合，含完整选项集合去重检查），连续两题通过方可进入正式题；第一次失败按统一指导语重复一次，第二次仍失败 → 结果标记"规则理解不足，不可判读"。

### 3.3 图元能力（v4 渲染器扩展）

`CrtCellSpec` 扩展（纯 SVG 变换/组合，无外部依赖）：

| 属性 | 类型 | 说明 |
|---|---|---|
| `shape` 新增 `'flag'` | — | **手性（非对称）旗形**：镜像后不与任何旋转等价，使 mirrorX 成为独立结构属性（v4 新增，修复 arrow 镜像≡旋转问题） |
| `mirrorX` / `mirrorY` | boolean | 水平/垂直镜像（仅对非对称图形生效，见对称等价表） |
| `gapPosition` | number（钟面 0–11） | 缺口圆环的缺口方位 |
| `internalMarkPosition` | number（钟面 0–11） | 图形内部标记点（小圆点）的方位 |
| `layout` | 'diagonal_down' \| 'diagonal_up' \| 'swapped_diagonal_down' | 双图元排列（显式坐标，v4 闭合枚举） |

**变换顺序（固定，v4）**：

```text
局部图元生成 → internalMark 定位 → scale → rotate → 单图元 mirror → layout 定位
```

不同顺序可能产生不同画面，全题库统一按此顺序。

**色板（全库统一，色盲安全）**：蓝 `#0072B2`、青 `#009E73`、橙 `#E69F00`、黄 `#F0E442`、中灰 `#7A7A7A`。
- 蓝/青为类别色（可用作 L1/L3 中差异干扰），不得用作 L4 高相似干扰；
- L4 不使用任何颜色近似干扰。

### 3.4 渲染规格（v4 修订：统一基准尺寸）

**目标与正确选项的图元基准尺寸必须完全一致**（容器可以不同，图形不得因区域不同自动缩放）：

| 参数 | 固定值 |
|---|---:|
| 目标与选项图元基准外径（统一） | **88 CSS px** |
| 目标容器 | 112 × 112 CSS px |
| 选项容器 | 112 × 112 CSS px |
| L2/L3 大小题最小实际边界差 | ≥ 7 CSS px |
| L4 大小题最小实际边界差 | ≥ 5 CSS px |
| 缺口圆环线宽 | 7 CSS px |
| 缺口角宽 | 24° |
| 缺口钟点间隔 | 30°（零点 = 12 点方向，顺时针递增） |
| 内部标记点直径 | 8–10 CSS px |
| 内部点定位半径 | 图元外径的 25%–30% |
| 内部点距轮廓最小间距 | ≥ 6 CSS px |
| 内部点与底色对比度 | ≥ 4.5:1 |
| 内部点相邻钟点中心间距 | 30°；点位坐标相对图元局部坐标，**随 rotate 共同旋转** |
| SVG viewBox | 全题库统一 |
| 高 DPI | 按 devicePixelRatio 等比缩放，尺寸差保持 CSS px 口径 |
| 渲染基准 | 施测前在目标设备上完成正常视觉 / 灰阶 / 色觉模拟截图检查 |

|---|---|
| 总正确数 | 0–16，等权（每级 4 题 × 1 分） |
| 各层正确数 | L1–L4 各 0–4（**漏答在正确数中记 0，同时单列漏答数**；层级报告显示"正确数/已呈现题数"与漏答数） |
| 正确题中位 RT | 按层分别计算；**每层 ≥ 2 道有效正确题才显示**，不足显示"有效正确 RT 不足，不解释" |
| 错误类型分布 | shape / color / rotation / scale / mirror / gap / internal_mark / layout / anticipatory_candidate / unclassified / interrupted / omitted（§5.5） |
| 结果状态 | DRAFT 描述性结果，不提供百分位 / IQ / 标准分 |

### 5.2 明确不做

- ❌ 分层加权总分；❌ 占位常模 → 百分位 → IQ；❌ 月龄加分。
- 恢复标准分换算的前提：真实样本、信度、项目参数（IRT/Rasch）与年龄参考数据齐备。

### 5.3 RT 质量规则（v4 修订）

| 规则 | 口径 |
|---|---|
| 时钟 | `performance.now()`（单调时钟，禁用 `Date.now()`） |
| 计时起点 | 同时满足：SVG 已渲染 + 布局尺寸已稳定 + 选项已启用可点击 |
| **动画禁用** | 刺激呈现不得有淡入/缩放/位移/选项逐个加载/CSS transition 尺寸变化（否则起点不可确定） |
| 响应时点 | **优先仅监听 `pointerdown`**（记录 pointerType）；仅在不支持 Pointer Events 的环境回退 `touchstart`（避免双触发） |
| 首次响应锁定 | 首次有效 pointerdown 后立即禁用全部选项；后续点击不得覆盖 RT 或答案；误点空白区域的处理在施测前定义并统一 |
| < 300 ms | 标记 `anticipatory_candidate`（**不直接判定误触**，除非同时有重复点击/错误位置/施测观察证据） |
| 失焦/中断 | `visibilitychange` / `window.blur` / `application_pause` / `screen_orientation_change` / `viewport_resize` → 标记 `interrupted` |
| 中断恢复 | 中断前未作答：恢复后重新呈现同题，准确率保留、RT 标记不可用；中断前已发生首次 pointerdown：按首次响应计分，不允许重答 |
| 超时 | > 30 s 未作答 → 统一提示再给 10 s → 仍未作答记 `omitted`（≠ 错误，报告单列漏答数） |
| 离群 | RT > 个人中位数 + 3 × MAD → 仅标记 `statistical_outlier`，不自动删除 |
| 汇总 | 用中位数，不用平均值 |
| 元数据 | input_method / pointerType / viewport_width / viewport_height / device_pixel_ratio / browser_zoom / stimulus_css_width / stimulus_css_height / target_bbox / option_bbox |
| 合理便利 | 放大、外接设备、眼控、教师代点、延长等待 → 正确率照常记录，RT 不与普通触屏条件比较 |

### 5.4 难度校准路径

试测阶段先完成：项目正确率、修正后项目总分相关（总分扣除该题）、错误分布（**近端/远端干扰分别统计**）、设备效应；样本足够后再用 Rasch / 2PL IRT 估计项目参数。

### 5.5 错误类型（v4 修订）

```text
shape_error            —— 选了异形
color_or_texture_error —— 选了异色/异纹理
rotation_error         —— 选了异方向
scale_error            —— 选了异大小（近端/远端分别统计）
mirror_error           —— 选了手性镜像
gap_error              —— 选了缺口方位错误
internal_mark_error    —— 选了内部标记方位错误
layout_error           —— 选了布局结构错误
anticipatory_candidate —— RT < 300 ms（仅标记，不直接判定误触）
interrupted_response   —— 失焦/暂停/窗口切换
omitted_response       —— 超时未作答
unclassified_error     —— 无法归类的错误选项
```

单次错误选项不得被判定为"随机作答"。

## 6. 报告与反馈模型

### 6.1 维度分（4 层）

| dimension code | 名称 | 能力标签 |
|---|---|---|
| match_basic | 基础匹配 | 形状 / 颜色整体辨别 |
| match_fine | 精细辨别 | 方向 / 大小细微辨别 |
| match_cross | 双属性交叉 | 多属性同步锁定与干扰抑制 |
| match_expert | 高相似逼近 | 手性镜像 / 缺口 / 内部点 / 布局精细加工 |

### 6.2 层级判读规则

| 判读 | 规则 |
|---|---|
| **稳定** | 该层 ≥ 3/4 正确 |
| **疑似边界** | L1–L3：该层 ≤ 2/4，且更高级别题合计正确率 ≤ 50%；L4 不适用，按 6.3 描述 |
| **结果不一致** | 单层下降，但更高层重新 ≥ 3/4（需复核题目与施测过程） |
| **不可判读** | 规则未理解（练习题两轮未过）、明显疲劳、情绪失调、连续拒绝；**"随机点击"需操作性定义**（如连续 ≥3 题 RT < 300 ms 且正答率 ≈ 25%），否则不得据此判不可判读 |

### 6.3 L4 描述规则

| L4 表现 | 报告措辞 |
|---|---|
| 0–2/4 | "高相似题本次正确率较低" |
| 3/4 | "高相似题多数完成" |
| 4/4 | "**准确率天花板**：当前题库可能无法确定更高水平的正确率边界"（v4 删除"无明显犹豫"主观条件） |

### 6.4 试测版专用提示

- **地板风险**：练习通过但 L1 ≤ 1/4 → "当前题库未能稳定测出更低能力边界"；
- **天花板风险**：L4 = 4/4 → "准确率天花板提示"（§6.3）；
- **层级置信**：每层仅 4 题，每错 1 题 = 层正确率变化 25%，结果仅作描述性参考；
- **不跨年龄排名**；**重测提示**：A/B 为顺序版本，短期重测存在记忆/熟练效应，前后差异不直接解释为能力变化。

### 6.5 报告增强（v4 修订）

1. **属性表现矩阵**：分母**由题目元数据动态生成**（禁止写死示例分母）；统计单位为**选项级**——"该属性作为可选错误干扰出现的题数" vs "该属性对应错误实际发生次数"，一题只计一次实际错误；
2. **错误选项缩略图**：target / 儿童选择 / 正确选项 / 差异属性；
3. **作答有效性卡片**：练习题是否一次通过、是否提示、休息、误触、失焦、中止、合理便利记录；
4. **训练建议最低证据门槛**：某属性 **≥ 3 次有效辨别机会且 ≥ 2 次同类错误** 才生成专项建议；不足时写"建议继续观察"。建议绑定错误类型（方向/大小/缺口/布局对应训练），不按总分给建议。

### 6.6 报告措辞约束

- 一律"本次表现提示"，禁止"能力瓶颈 / 能力缺陷 / 加工速度偏慢"；
- L1 ≤ 2/4 时先排查规则理解、视力、色觉、触控与注意状态，再决定是否建议专业评估；
- 转介建议必须基于重复测量、行为观察与其他资料；
- 无年龄/设备 RT 常模时，只写"本次较高难度题作答时间增加"。

## 7. 质量保障（v4：11 项试测门禁校验）

### 7.1 语义唯一性（现有机制）

正解与 target 完全相等、其余选项与 target 不等（`validateAllMatchQuestions`）。

### 7.2 视觉唯一性

- 对称等价表：circle 任意旋转等价；square 每 90°；triangle 每 120°；hexagon 每 60°；五角星每 72°；diamond 每 180°；**flag 无旋转等价（手性），mirrorX 为其独立属性**；
- 同题选项渲染截图 / SVG 标准化哈希 + **固定设备栅格化像素比较**（SVG 文本不同 ≠ 儿童可见差异足够）。

### 7.3 属性覆盖（全题库覆盖 + 各级按本级定义检查）

- 全题库覆盖：形状、颜色、方向、大小、手性镜像、缺口、内部点、布局；
- L1 查形状/颜色；L2 查方向/大小；L3 查方向/大小/颜色/内部点；L4 查方向/大小/手性镜像/缺口/内部点/布局。

### 7.4 正解位置平衡（构建测试）

16 题中 correctIndex 0/1/2/3 各 4 次；同一位置连续不超 2 次；运行时只打乱位置，不改刺激属性。

### 7.5 进入试测前的自动校验（v4：11 项）

1. 18 题（2 练习 + 16 正式）语义唯一性通过；
2. 18 题视觉等价检查通过（对称归一 + 像素渲染核对）；
3. 每题 4 个选项两两视觉不等；
4. **target 与 correct option 像素等价**（统一 88 px 基准下渲染一致）；
5. **变换顺序一致**（§3.3 固定顺序，构建测试按该顺序渲染）；
6. **干扰项属性差合同**：每个干扰项只改变规格表声明的属性，不因镜像/布局/缩放连带改变其他属性；
7. **练习题与正式题去重**：检查完整选项集合与排序前刺激集合，不只查 target；
8. **固定设备栅格化像素差阈值**：L2/L3 ≥ 7 px、L4 ≥ 5 px 实际边界差；
9. 题 16 布局枚举渲染无视觉重复；
10. 16 题正解位置 0–3 各 4 次、无连续超 2 次；
11. 实际渲染尺寸达到 §3.4 最低标准，目标设备截图通过人工复核。

## 9. 伦理与边界声明

1. 非诊断工具：自编、无标准化效度/信度；
2. 无标准分：不输出 IQ / 百分位 / 标准分；
3. 禁止高风险使用：不得用于入学、分班、安置、诊断、资格判定等决策；
4. 授权与解释：未成年人施测需监护人或机构授权；结果由受过培训的教师/治疗师/评估人员解释；
5. 合理便利：允许放大、休息、替代输入方式，并如实记录（相应 RT 不参与比较）；
6. 中止规则：明显疲劳、情绪失调、连续拒绝、随机点击（操作性定义见 §6.2）→ 中止并标记"不可判读"；
7. 数据管理：明确存储、访问权限、删除期限与导出范围；
8. 转介谨慎：转介建议必须基于重复测量、行为观察与其他资料；
9. 不得跨年龄排名。

## 10. 试测计划（v4：两阶段）

### 阶段 A：认知访谈与可用性试测（先做）

每龄组先选 **5–8 人**，观察：是否理解练习题、如何描述题目差异、是否误解内部点/手性镜像/缺口/布局、点击困难、屏幕反光/距离/姿势影响。完成题目与界面修订后再进入阶段 B。

### 阶段 B：探索性项目试测

- 每龄组（5.5–8 / 9–12 / 13–16.5）**20–30 名有效被试**，统一施测指导语 + 固定设备；
- **样本记录**：主要障碍类别、认知与语言支持水平、视力矫正情况、已知色觉问题、精细动作/触控困难、是否使用合理便利、施测者、设备型号；
- 分龄分析：各龄组分别看项目正确率、漏答率、RT、错误类型，不合并宣称难度单调；
- 设备差异表述：小样本下写"某设备错误率/漏答率出现**明显描述性差异**时优先检查渲染尺寸、色彩与触控条件"（不写"显著偏高"）；
- 选项分析：每个干扰项的选择比例、高/低总分儿童的选择分布、干扰项是否只在特定设备被选。

### 项目修订门槛（试测前确定）

- 非 L1 题正确率 > 95% → 检查是否过易；< 15% → 检查是否过难或呈现问题；
- 修正后项目总分相关为负 → 优先停用；
- 某干扰项几乎无人选择 → 无效干扰；
- 近端干扰被选率远高于远端 → 层级难度校准线索。

### 试测 SOP 与数据管理（v4 P0-6，试测前必须成文）

标准指导语、练习失败后的统一提示、中止流程、监护人或机构授权记录、数据保存期限、可访问角色、导出权限、删除流程。

### 后续

锚题 + 低龄/高能力扩展模块、24–32 题项目库（下一阶段优先）、真正平行题本、试测后按干扰项选择分布重组 L3/L4、样本足够后 Rasch / 2PL。
