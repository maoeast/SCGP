# 《管理员：数据备份》人工录制包

> **状态**：当前有效，待按本包录制与验收
> **产品**：SCGP / 星愿能力发展平台
> **受众**：首次使用系统的学校管理员
> **成片目标**：2–3 分钟、16:9；先无声录屏，再配 AI 旁白和字幕
> **范围**：在系统管理的数据备份页签中执行一次完整备份（设置口令），并读取备份文件信息验证备份有效
> **系列**：本片为第十三支，承接《管理员：用户与学年管理》（第十一支演示系统管理页签，本片演示数据备份页签）；业务数据已就绪。
> **不作为事实来源**：`output/videos/管理员：班级与学生管理.mp4`、`scripts/video/` 及其旧分镜仅为历史参考，不能复用其时长、分辨率、样例数据、旁白、选择器或语音配置。

## 1. 本片要解决什么

本片演示管理员在“系统管理 → 数据备份”中执行一次完整数据备份：设置并确认备份口令后导出备份文件，再选择该文件读取备份信息（版本、记录数、表数量），验证备份有效。

数据备份将当前数据库中的班级、分班、计划、报告、训练记录、资源与系统配置导出为口令保护的备份文件，用于迁移、归档或恢复。本片只演示备份与校验，不执行数据恢复。本片只说明这一业务结果，不承诺替代学校既有的备份制度或灾备流程。

### 角色与范围边界

- 录制账户为**管理员**，旁白以“管理员”指代操作者（系统管理仅管理员可进入）；不得把操作表述为教师、学生或其他角色。账号信息不出现在画面中。
- 演示页面：系统管理 → 数据备份页签（数据备份/数据恢复两张卡与备份文件信息区）。
- 备份口令为录制用虚构口令；备份文件保存到默认位置；仅使用演示数据。
- 不演示：数据恢复（“恢复数据”按钮不点击）、恢复确认、备份口令不一致的错误提示、资源健康检查细节、其他系统页签。
- 不演示导入、数据库替换、数据抽取、演示 ZIP 修改或产品数据目录写入。`docs/guides/seed-demo-data.md` 仅可作为历史参考，不是本片的执行路径。

## 2. 录制前置条件与安全检查

在打开录制软件前，由执行人逐项确认。任一项不满足时，停止录制并先修正环境，不用剪辑掩盖问题。

| 检查项 | 必须满足的条件 |
| --- | --- |
| 账户与页面 | 已使用管理员账户登录；左侧菜单“系统管理”可见可进入，数据备份页签可用。 |
| 数据环境 | 使用可丢弃、可完整恢复的录制数据库；备份文件保存到临时/默认目录，录制结束后随环境一并清理；绝不连接生产库或含真实人员信息的库。 |
| 备份口令 | 使用录制用虚构口令 `[备份口令]`（至少满足口令强度要求），两次输入一致；不输入两次不一致的错误场景。 |
| 文件位置 | 备份文件保存对话框出现后直接确认默认位置；画面不得聚焦展示完整文件路径（必要时跳剪至“备份成功”提示）。 |
| 运行状态 | 页面加载完成、无报错提示、浏览器/系统通知关闭，缩放和字体在 16:9 画面中清楚可读。 |
| 回滚 | 已明确录制结束后的恢复方式：还原该可丢弃数据库或按既有安全流程清理；删除本次备份文件；不得对真实库做清理。 |

运行时只使用以下占位符替换为已核验的实际值：

- `[备份口令]`（录制用虚构口令，两次输入一致）

### 2.1 录制效率提示

- **批次**：F-1（先行，总纲 §2；任何库均可，建议用批次 A 的库）。
- **预置**：`[备份口令]` 两次输入一致；保存对话框确认默认位置。
- **一次通过要点**：①口令两段式输入，两次必须一致（不一致报错重录）；②保存/选择对话框不聚焦路径（跳剪至"备份成功"）；③备份文件信息（版本/记录数/表数量）是校验证据，务必拍全。
- **净录制预估**：约 25 分钟/遍。


## 3. 画面、操作与后期总规则

### 3.1 画面规格

- 成片画布为 **16:9**，建议交付 `1920 × 1080`；若源窗口比例不同，应在录制前调整可见区域或后期裁切，不能拉伸界面。
- 录制原始画面时关闭系统声音、应用提示音和通知；录屏只保留清晰的界面操作，AI 旁白在后期单独合成。
- 每个镜头只表达一个意图。页面、下拉菜单和对话框完全稳定后再开始操作；不录入加载抖动、无关菜单或鼠标试探。
- 需要突出字段时仅做克制的局部放大，放大前后保留页面方向感；不使用快速摇镜、夸张缩放或遮挡主要操作区的特效。

### 3.2 鼠标与停留规则

- 鼠标沿短路径移动，点击后离开关键文字；不要绕圈、反复悬停或用光标代替旁白。
- 打开页面、页签或对话框后停留约 **1 秒**，让观看者看清标题和内容。
- 口令输入为密码框，输入后不悬停暴露明文；两次口令输入之间停留约 1 秒。
- 成功提示“备份成功”保留 **0.8–1.5 秒**；备份文件保存对话框确认后不聚焦路径。
- 出现任何可见错误、重复校验、错误数据、误点击或个人信息时，**从该镜头开头重录**；不要以裁切、马赛克或加速掩盖操作错误。

### 3.3 旁白与字幕规则

- 旁白使用经试听通过的中文 AI 声音；本包不指定具体供应商、声音名称或固定语速。
- 旁白应说明“为什么做”和“操作结果”，不逐字念出每次鼠标点击；画面中的按钮和字段由字幕辅助定位。
- 字幕与旁白同义、逐镜头校时。每条最多两行，避免遮挡口令对话框、按钮、备份文件信息区及成功提示。
- 术语以实时构建为准：如录制构建调整了文案，可替换字幕中的对应词，但不得改变“设置口令 → 导出备份 → 读取校验”的业务顺序。

## 5. 录制执行清单

1. 按第 2 节完成可恢复环境检查，记录全部运行时占位符的实际值。
2. 先静音录一遍完整画面；仅检查流程、隐私、光标和停留，不在此阶段生成旁白。
3. 回看原始录屏：任何数据泄露、加载异常、错误提示、误点“恢复数据”、口令两次不一致、文件路径进入画面或备份文件信息未能读取，都从受影响镜头开头重录。
4. 依据第 4 节生成 AI 旁白，先输出可试听音频，再与已确认的画面匹配；不要直接把未经试听的 TTS 音频导出为成片。
5. 依据字幕列制作字幕，逐句检查进入和离开时间；字幕出现应略早于或与对应动作同时，不应滞后到下一步。
6. 完成合成后，从头无中断观看一次；验收通过才导出交付版。录制结束后立即按预先确认的可恢复流程恢复环境并删除备份文件。

## 6. 音频、剪辑与导出门禁

### 6.1 音频试听门禁

在最终合成前，至少由录制者完整试听一次 AI 旁白，并逐项通过：

- 声音自然、适合面向学校管理员的说明语气；
- 语速能让观看者同时看清口令流程、按钮和操作，关键停顿自然；
- 音量在全片一致，未被系统声、背景音乐或提示音覆盖；
- “数据备份”“数据恢复”“立即备份”“选择备份文件”“备份口令”“备份成功”“备份文件信息”“备份版本”“记录数”“表数量”等中文术语发音正确；
- 无漏读、重读、截断、机械连读或难以辨识的词句。

任一项不通过时，只重生成或重校该段音频并复听；不要通过过度加速、压缩静音或堆叠背景音乐掩盖问题。

### 6.2 画面与字幕门禁

- 每个镜头都可独立看懂一个意图，转场不打断一次备份或校验动作。
- 关键页面标题、按钮“立即备份”“选择备份文件”、口令对话框、备份文件信息区和成功提示在 16:9 画面中可读。
- 字幕不遮挡口令对话框、按钮、备份文件信息区或成功提示；无错别字、占位符、旧产品名称或历史样例数据。
- 成片不得出现真实个人数据、管理员账号、令牌、**文件路径（含保存/选择对话框的完整路径）**、通知横幅、调试窗、密码管理器或录制工具控件。
- 导出为可播放的 16:9 MP4（H.264 视频与 AAC 音频为推荐兼容组合）；导出后使用独立播放器从头试听、查看字幕和核验总时长。

## 7. 验收标准

| 类别 | 通过标准 |
| --- | --- |
| 角色正确 | 旁白明确为管理员操作（系统管理仅管理员可进入）；未暗示教师、学生或其他角色执行备份。 |
| 业务闭环 | 画面依次出现：进入数据备份页签、立即备份并两次确认口令、保存默认位置后“备份成功”提示、选择备份文件并输入口令读取备份文件信息（版本/记录数/表数量/系统）；备份文件信息是备份落地的业务证据，成功提示仅作为界面反馈。 |
| 页面事实 | 页面标题与按钮文案与画面一致：“数据备份与恢复”“数据备份”“数据恢复”“立即备份”“选择备份文件”“恢复数据”“确定”“备份文件信息”“备份版本”“记录数”“表数量”；提示“备份成功”实际出现。 |

| 数据安全 | 无真实个人数据或生产数据；口令为虚构；备份文件已随录制环境清理；没有修改演示 ZIP 或产品数据目录。 |
| 可理解性 | 成片在 2–3 分钟内；旁白、字幕和关键交互同步且清晰，未经解释的跳步不影响新管理员复现。 |
| 质量 | 16:9 无拉伸；无可见错误；口令与文件对话框停留符合第 3 节；全片通过音频、画面和字幕门禁。 |

## 8. 当前实现依据与维护说明

本录制包依据当前界面和数据行为编写：

- `src/views/System.vue`：系统管理容器与“数据备份”页签（数据备份/数据恢复卡片、备份文件信息区、口令输入与“备份成功”提示）；

- `src/router/index.ts`：`/system` 路由（仅 admin）。

界面文案或业务规则变动时，先以当前代码和实际构建复核，再同步更新本包；不要反向用本包覆盖当前产品事实。
