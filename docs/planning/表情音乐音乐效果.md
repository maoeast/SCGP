# Role
你是一个资深的前端音视频交互专家，精通 Vue 3 (Composition API)、TypeScript、Web Audio API 以及 Tone.js 库。现在需要为一款面向特殊儿童康复训练的 Electron 桌面应用编写音频反馈逻辑。

# Context & Goal
我们在开发两个表情训练游戏：‘表情能量球’和‘表情侦探’。系统已引入 Tone.js。
目标是编写一个可复用的 Vue 3 Composable (`useExpressionAudio.ts`) 或封装好的逻辑，接收来自 MediaPipe 的表情识别结果（字符串：'happy' | 'angry' | 'sad' | 'fearful' | 'surprised' | 'calm'），动态无缝地切换背景音乐的音色、和弦与特效，提供低延迟、高容错、防听觉过载的交互反馈。

# Technical Constraints
1. Tech Stack: Vue 3 (<script setup>), TypeScript, Tone.js, Vite, Electron (本地优先，注意内存释放)。
2. Code Style: 严谨的 TypeScript 类型定义，逻辑清晰，杜绝 any。
3. Audio Safety (特教核心): 
   - 切换表情时，绝对不能出现突兀的音频断裂或爆音（Clicking）。必须使用 `rampTo` 确保平滑淡入淡出（过渡时间建议 0.4s - 0.5s）。
   - 避免使用高频、尖锐、大分贝的合成器音色，防止特殊儿童产生感官过载（Sensory Overload）。
4. Lifecycle Management: 在组件卸载（onUnmounted）时，必须显式销毁（dispose）所有创建的 Synth、Effect、LFO、Loop，防止 Electron 进程内存泄露。

# Detailed Audio Mapping Requirements

请根据传入的 `expression` 状态，实现以下 6 种音频状态机的平滑切换：

1. happy (开心):
   - 音色：明亮、清脆、无攻击性。使用 `Tone.PolySynth`（或加载木琴/八音盒的 Sampler）。
   - 乐理：C大调五声调式（C4, D4, E4, G4, A4），短时值、快速跳跃的明快琶音。
   - 节奏：BPM 120 左右。

2. angry (生气):
   - 音色：低沉、粗糙但带有卡通式宣泄感。使用 `Tone.DuoSynth`，选用锯齿波（Sawtooth），串联一个轻微的 `Tone.Distortion`（失真）与 `Tone.Filter`（低通滤波，限制高频噪音）。
   - 乐理：低音区（C2, G2）的重低音进行。
   - 作用：承接与宣泄负面情绪，避免尖锐刺激。

3. sad (伤心):
   - 音色：温柔、流淌、具包裹感。使用 `Tone.Synth`（三角波 Triangle，类似大提琴/长笛），挂载高 Wet 值的 `Tone.Reverb`（空间混响）。
   - 乐理：A小调（A minor）缓慢下行的旋律，Attack 和 Release 拉长（>1s），平滑淡入淡出。
   - 作用：提供音乐情感共鸣与安抚。

4. fearful (害怕):
   - 音色：颤抖、不确定感。使用 `Tone.FMSynth`（频率调制），利用 `Tone.LFO` 动态调制合成器的 `detune`（音高微调）或 Filter 频率，制造出轻微的物理颤音（Vibrato）效果。挂载微弱的 `Tone.PingPongDelay`。
   - 作用：外化焦虑感，但音量要克制（调低分贝），避免二次惊吓。

5. surprised (惊讶):
   - 音色：突然拔高、复古戏剧感。使用 `Tone.MonoSynth`（方波 Square）。
   - 乐理：利用 `frequency.rampTo()` 方法，在 0.15 秒内将音高由低音区急速滑升至高音区（如 C3 -> C6），随后触发一个清脆的 `Tone.FeedbackDelay`（回音）。

6. calm (平静 - 基准状态):
   - 音色：极其温润、无明显节拍边界。使用正弦波（Sine Wave）组合成环境铺底声（Ambient Pad），挂载 `Tone.AutoFilter` 在左右声道像呼吸一样缓慢游走。
   - 节奏：BPM 降至 65 左右（模拟平静心率）。
