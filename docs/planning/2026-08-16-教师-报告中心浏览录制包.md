# 《教师：报告中心浏览》人工录制包

> **状态**：当前有效，待按本包录制与验收
> **产品**：SCGP / 星愿能力发展平台
> **受众**：首次使用系统的学校教师（管理员可代为录制）
> **成片目标**：2–3 分钟、16:9；先无声录屏，再配 AI 旁白和字幕
> **范围**：在报告中心按学生、时间与报告类型筛选评估报告，并查看一份报告
> **系列**：本片为第九支，承接《教师：完成一次量表评估》（第三支从评估完成链进入报告页，本片从报告中心聚合入口回查报告）；学生档案、评估与训练链路均已就绪。
> **不作为事实来源**：`output/videos/管理员：班级与学生管理.mp4`、`scripts/video/` 及其旧分镜仅为历史参考，不能复用其时长、分辨率、样例数据、旁白、选择器或语音配置。

## 1. 本片要解决什么

本片演示教师如何通过“报告中心”集中查找并查看评估报告：进入报告中心，按学生、时间范围与报告类型筛选，定位目标报告并打开查看。

报告中心统一汇总评估、训练与情绪模块报告（评估报告卡片按激活授权过滤，与评估入口同源），减少跨模块查找成本。本片只说明这一业务结果，不承诺替代学校既有的报告归档、审核或档案流程。

### 角色与范围边界

- 录制账户为**教师或管理员**，旁白以“教师”指代操作者（报告中心对教师开放）；不得把操作表述为学生、家长或其他角色。账号信息不出现在画面中。
- 演示页面：报告中心（筛选栏、评估报告分布、训练与干预报告分布、报告列表）与一份 `[已选定的报告类型]` 报告页。
- 仅使用一名虚构学生与演示数据中的报告；不展示真实姓名、学号、诊断、联系方式或真实报告内容。
- 不演示：下载、删除报告、报告页导出 PDF/Word、报告列表分页翻页、空态（“当前筛选条件下暂无报告记录”）。
- 不演示导入、数据库替换、数据抽取、演示 ZIP 修改或产品数据目录写入。`docs/guides/seed-demo-data.md` 仅可作为历史参考，不是本片的执行路径。

## 2. 录制前置条件与安全检查

在打开录制软件前，由执行人逐项确认。任一项不满足时，停止录制并先修正环境，不用剪辑掩盖问题。

| 检查项 | 必须满足的条件 |
| --- | --- |
| 账户与页面 | 已使用教师或管理员账户登录；左侧菜单“报告生成”可见可进入（页面标题为“报告中心”）。 |
| 数据环境 | 使用可丢弃、可完整恢复的录制数据库；绝不连接生产库或含真实人员信息的库。 |
| 虚构学生 | 一名虚构学生 `[虚构学生姓名]` 已建档，且对录制账户可见（教师账户受数据范围限制时，改用管理员账户录制）。 |
| 报告数据 | 录制环境中 `[虚构学生姓名]` 存在至少一份 `[已选定的报告类型]` 报告（可由第三支流程产生或来自演示数据），报告标题 `[目标报告标题]` 可识别定位；该量表在录制环境已激活授权（分布卡片可见）。 |
| 时间条件 | 快捷筛选镜头以“本月”为例时，目标报告创建时间须在当前自然月内；不在则改用“本周”或“全部”，以实际数据为准。 |
| 运行状态 | 页面加载完成、无报错提示、浏览器/系统通知关闭，缩放和字体在 16:9 画面中清楚可读。 |
| 回滚 | 已明确录制结束后的恢复方式：还原该可丢弃数据库或按既有安全流程清理；不得对真实库做清理。 |

运行时只使用以下占位符替换为已核验的实际值，不在脚本中预设具体学生名、类型或标题：

- `[虚构学生姓名]`
- `[已选定的报告类型]`（推荐 SDQ 评估报告）
- `[目标报告标题]`

### 2.1 录制效率提示

- **批次**：B-2（依赖第 3 支产出的报告）。
- **预置**：目标报告创建时间在本月（否则"本月"快捷筛选改用"本周/全部"）。
- **一次通过要点**：①菜单文案是"报告生成"、页面 H1 是"报告中心"，两者不同；②查看报告后返回，筛选会重置为默认（无需保留）；③分布卡片随筛选同步变化，每次切换后停留 1 秒。
- **净录制预估**：约 20 分钟/遍。


## 3. 画面、操作与后期总规则

### 3.1 画面规格

- 成片画布为 **16:9**，建议交付 `1920 × 1080`；若源窗口比例不同，应在录制前调整可见区域或后期裁切，不能拉伸界面。
- 录制原始画面时关闭系统声音、应用提示音和通知；录屏只保留清晰的界面操作，AI 旁白在后期单独合成。
- 每个镜头只表达一个意图。页面、下拉菜单和对话框完全稳定后再开始操作；不录入加载抖动、无关菜单或鼠标试探。
- 需要突出字段时仅做克制的局部放大，放大前后保留页面方向感；不使用快速摇镜、夸张缩放或遮挡主要操作区的特效。

### 3.2 鼠标与停留规则

- 鼠标沿短路径移动，点击后离开关键文字；不要绕圈、反复悬停或用光标代替旁白。
- 打开页面、下拉列表或报告页后停留约 **1 秒**，让观看者看清标题和内容。
- 每次筛选（学生/时间快捷/报告类型）后列表刷新，停留约 1 秒再继续下一步。
- 出现任何可见错误、重复校验、错误数据、误点击或个人信息时，**从该镜头开头重录**；不要以裁切、马赛克或加速掩盖操作错误。

### 3.3 旁白与字幕规则

- 旁白使用经试听通过的中文 AI 声音；本包不指定具体供应商、声音名称或固定语速。
- 旁白应说明“为什么做”和“操作结果”，不逐字念出每次鼠标点击；画面中的按钮和字段由字幕辅助定位。
- 字幕与旁白同义、逐镜头校时。每条最多两行，避免遮挡筛选栏、分布卡片、报告列表操作列及报告内容。
- 术语以实时构建为准：如录制构建调整了文案（含更换学生、类型或标题），可替换字幕中的对应词，但不得改变“筛选 → 定位 → 查看报告”的业务顺序。

## 5. 录制执行清单

1. 按第 2 节完成可恢复环境检查，记录全部运行时占位符的实际值。
2. 先静音录一遍完整画面；仅检查流程、隐私、光标和停留，不在此阶段生成旁白。
3. 回看原始录屏：任何数据泄露、加载异常、错误提示、误点“下载”“删除”或报告页导出、误入空态、或未能打开目标报告，都从受影响镜头开头重录。
4. 依据第 4 节生成 AI 旁白，先输出可试听音频，再与已确认的画面匹配；不要直接把未经试听的 TTS 音频导出为成片。
5. 依据字幕列制作字幕，逐句检查进入和离开时间；字幕出现应略早于或与对应动作同时，不应滞后到下一步。
6. 完成合成后，从头无中断观看一次；验收通过才导出交付版。录制结束后立即按预先确认的可恢复流程恢复环境。

## 6. 音频、剪辑与导出门禁

### 6.1 音频试听门禁

在最终合成前，至少由录制者完整试听一次 AI 旁白，并逐项通过：

- 声音自然、适合面向学校教师的说明语气；
- 语速能让观看者同时看清筛选栏、列表和操作，关键停顿自然；
- 音量在全片一致，未被系统声、背景音乐或提示音覆盖；
- “报告中心”“评估报告”“训练与干预报告”“报告列表”“查询”“重置”“查看”“报告类型”“时间范围”等中文术语发音正确；
- 无漏读、重读、截断、机械连读或难以辨识的词句。

任一项不通过时，只重生成或重校该段音频并复听；不要通过过度加速、压缩静音或堆叠背景音乐掩盖问题。

### 6.2 画面与字幕门禁

- 每个镜头都可独立看懂一个意图，转场不打断一次筛选、定位或查看动作。
- 关键页面标题、筛选栏、分布卡片、报告列表操作列和最终报告页在 16:9 画面中可读。
- 字幕不遮挡筛选栏、分布卡片、报告列表操作列或报告内容；无错别字、占位符、旧产品名称或历史样例数据。
- 成片不得出现真实个人数据、教师/管理员账号、令牌、文件路径、通知横幅、调试窗、密码管理器或录制工具控件。
- 导出为可播放的 16:9 MP4（H.264 视频与 AAC 音频为推荐兼容组合）；导出后使用独立播放器从头试听、查看字幕和核验总时长。
