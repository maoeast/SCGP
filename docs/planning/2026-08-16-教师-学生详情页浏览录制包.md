# 《教师：学生详情页浏览》人工录制包

> **状态**：当前有效，待按本包录制与验收
> **产品**：SCGP / 星愿能力发展平台
> **受众**：首次使用系统的学校教师（管理员可代为录制）
> **成片目标**：2–3 分钟、16:9；先无声录屏，再配 AI 旁白和字幕
> **范围**：从学生管理进入一名虚构学生的详情页，浏览基本资料、概览统计与评估、器材、游戏三类记录，并打开一份评估报告
> **系列**：本片为第十四支，承接《教师：报告中心浏览》（第九支为报告中心聚合入口，本片为学生维度聚合入口）；学生档案、评估与训练链路均已就绪。
> **不作为事实来源**：`output/videos/管理员：班级与学生管理.mp4`、`scripts/video/` 及其旧分镜仅为历史参考，不能复用其时长、分辨率、样例数据、旁白、选择器或语音配置。

## 1. 本片要解决什么

本片演示教师如何通过“学生详情页”一站式了解一名学生的档案与成长记录：查看基本资料与分班状态，通过概览统计卡与三个记录页签（评估记录/器材训练/游戏训练）浏览历史记录，并打开一份评估报告。

学生详情页按学生维度聚合评估与训练数据，与报告中心（按报告类型聚合）互为补充，帮助教师快速定位单一学生的完整轨迹。本片只说明这一业务结果，不承诺替代学校既有的档案、评估或干预流程。

### 角色与范围边界

- 录制账户为**教师或管理员**，旁白以“教师”指代操作者（学生详情页对教师开放）；不得把操作表述为学生、家长或其他角色。账号信息不出现在画面中。
- 演示页面：学生管理 → 学生详情页（基本信息卡、事实卡、概览统计卡、评估记录/器材训练/游戏训练页签）→ 一份评估报告页。
- 仅使用一名虚构学生与演示数据中的记录；不展示真实姓名、学号、照片、诊断、联系方式或真实记录内容。
- 不演示：详情页“编辑信息”、AI 记忆卡交互、器材/游戏记录的“查看详情”、评估记录中的其他报告、空态。
- 不演示导入、数据库替换、数据抽取、演示 ZIP 修改或产品数据目录写入。`docs/guides/seed-demo-data.md` 仅可作为历史参考，不是本片的执行路径。

## 2. 录制前置条件与安全检查

在打开录制软件前，由执行人逐项确认。任一项不满足时，停止录制并先修正环境，不用剪辑掩盖问题。

| 检查项 | 必须满足的条件 |
| --- | --- |
| 账户与页面 | 已使用教师或管理员账户登录；学生管理列表可见，目标学生对录制账户可见。 |
| 数据环境 | 使用可丢弃、可完整恢复的录制数据库；绝不连接生产库或含真实人员信息的库。 |
| 虚构学生 | 一名虚构学生 `[虚构学生姓名]` 已建档（含头像、学号、诊断与班级状态），且对录制账户可见。 |
| 记录数据 | 该学生存在至少一份 `[已选定的报告类型]` 评估报告（供“查看报告”演示，可由第三支流程产生或来自演示数据），以及若干器材/游戏训练记录（页签计数非零，供浏览）。 |
| 运行状态 | 页面加载完成、无报错提示、浏览器/系统通知关闭，缩放和字体在 16:9 画面中清楚可读。 |
| 回滚 | 已明确录制结束后的恢复方式：还原该可丢弃数据库或按既有安全流程清理；不得对真实库做清理。 |

运行时只使用以下占位符替换为已核验的实际值，不在脚本中预设具体学生名或报告：

- `[虚构学生姓名]`
- `[已选定的报告类型]`（推荐 SDQ 评估报告）
- `[目标报告标题]`

### 2.1 录制效率提示

- **批次**：B-3（依赖第 3 支的评估记录；器材/游戏记录建议先录批次 C）。
- **预置**：评估报告与训练记录非零（页签计数可见）。
- **一次通过要点**：①入口是学生管理"查看详情"（或首页最近添加）；②三个页签统计卡可点击切换；③查看报告后返回即可，不点记录"查看详情"。
- **净录制预估**：约 20 分钟/遍。


## 3. 画面、操作与后期总规则

### 3.1 画面规格

- 成片画布为 **16:9**，建议交付 `1920 × 1080`；若源窗口比例不同，应在录制前调整可见区域或后期裁切，不能拉伸界面。
- 录制原始画面时关闭系统声音、应用提示音和通知；录屏只保留清晰的界面操作，AI 旁白在后期单独合成。
- 每个镜头只表达一个意图。页面、下拉菜单和对话框完全稳定后再开始操作；不录入加载抖动、无关菜单或鼠标试探。
- 需要突出字段时仅做克制的局部放大，放大前后保留页面方向感；不使用快速摇镜、夸张缩放或遮挡主要操作区的特效。

### 3.2 鼠标与停留规则

- 鼠标沿短路径移动，点击后离开关键文字；不要绕圈、反复悬停或用光标代替旁白。
- 打开页面、切换页签或进入报告页后停留约 **1 秒**，让观看者看清标题和内容。
- 每个页签切换后停留约 1 秒再继续下一步。
- 出现任何可见错误、重复校验、错误数据、误点击或个人信息时，**从该镜头开头重录**；不要以裁切、马赛克或加速掩盖操作错误。

### 3.3 旁白与字幕规则

- 旁白使用经试听通过的中文 AI 声音；本包不指定具体供应商、声音名称或固定语速。
- 旁白应说明“为什么做”和“操作结果”，不逐字念出每次鼠标点击；画面中的按钮和字段由字幕辅助定位。
- 字幕与旁白同义、逐镜头校时。每条最多两行，避免遮挡基本信息卡、统计卡、记录表格操作列及报告内容。
- 术语以实时构建为准：如录制构建调整了文案（含更换学生或报告），可替换字幕中的对应词，但不得改变“进入详情 → 浏览资料 → 浏览记录 → 查看报告”的业务顺序。

## 5. 录制执行清单

1. 按第 2 节完成可恢复环境检查，记录全部运行时占位符的实际值。
2. 先静音录一遍完整画面；仅检查流程、隐私、光标和停留，不在此阶段生成旁白。
3. 回看原始录屏：任何数据泄露、加载异常、错误提示、误点“编辑信息”或记录“查看详情”、误入报告导出、或未能打开目标报告，都从受影响镜头开头重录。
4. 依据第 4 节生成 AI 旁白，先输出可试听音频，再与已确认的画面匹配；不要直接把未经试听的 TTS 音频导出为成片。
5. 依据字幕列制作字幕，逐句检查进入和离开时间；字幕出现应略早于或与对应动作同时，不应滞后到下一步。
6. 完成合成后，从头无中断观看一次；验收通过才导出交付版。录制结束后立即按预先确认的可恢复流程恢复环境。

## 6. 音频、剪辑与导出门禁

### 6.1 音频试听门禁

在最终合成前，至少由录制者完整试听一次 AI 旁白，并逐项通过：

- 声音自然、适合面向学校教师的说明语气；
- 语速能让观看者同时看清资料、表格和操作，关键停顿自然；
- 音量在全片一致，未被系统声、背景音乐或提示音覆盖；
- “学生详情”“评估记录”“器材训练”“游戏训练”“查看详情”“查看报告”“总评估数”“涉及量表”“最近评估”“正确率”等中文术语发音正确；
- 无漏读、重读、截断、机械连读或难以辨识的词句。

任一项不通过时，只重生成或重校该段音频并复听；不要通过过度加速、压缩静音或堆叠背景音乐掩盖问题。

### 6.2 画面与字幕门禁

- 每个镜头都可独立看懂一个意图，转场不打断一次浏览、切换或查看动作。
- 关键页面标题、基本信息卡、统计卡、记录表格操作列和最终报告页在 16:9 画面中可读。
- 字幕不遮挡基本信息卡、统计卡、记录表格操作列或报告内容；无错别字、占位符、旧产品名称或历史样例数据。
- 成片不得出现真实个人数据、教师/管理员账号、令牌、文件路径、通知横幅、调试窗、密码管理器或录制工具控件。
- 导出为可播放的 16:9 MP4（H.264 视频与 AAC 音频为推荐兼容组合）；导出后使用独立播放器从头试听、查看字幕和核验总时长。
