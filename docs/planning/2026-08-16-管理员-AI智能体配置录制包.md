> **状态**：当前有效，待按本包录制与验收
> **产品**：SCGP / 星愿能力发展平台
> **受众**：首次使用系统的学校管理员
> **成片目标**：2–3 分钟、16:9；先无声录屏，再配 AI 旁白和字幕
> **范围**：在系统管理的 AI 智能体页签中完成模型服务配置（选择服务商、配置接口与密钥、测试连接、选择默认模型并保存）

## 1. 本片要解决什么

本片演示管理员在“系统管理 → AI 智能体”中完成模型服务配置：选择模型服务商（DeepSeek / 火山方舟），确认接口地址，输入 API Key 并测试连接，选择默认模型后保存配置。

AI 智能体是对话、报告生成与智能助手的模型服务底座；API Key 以密文保存，界面不回显明文。本片只演示配置流程，不承诺替代学校既有的采购、合规或密钥管理制度。

### 角色与范围边界

- 录制账户为**管理员**，旁白以“管理员”指代操作者（系统管理仅管理员可进入）；不得把操作表述为教师、学生或其他角色。账号信息不出现在画面中。
- 演示页面：系统管理 → AI 智能体页签（模型服务配置卡；全局用量与风控、业务与合规、智能体管理卡仅停留概览）。
- API Key 为**演示用虚构或临时测试密钥**（输入框为密码掩码，画面不展示明文；录制后轮换或清除）。
- 不演示：清除 Key、模型清单的编辑/新增/删除、拉取模型列表、全局用量与风控/业务与合规/智能体管理卡片内部操作。
- 不演示导入、数据库替换、数据抽取、演示 ZIP 修改或产品数据目录写入。`docs/guides/seed-demo-data.md` 仅可作为历史参考，不是本片的执行路径。

## 2. 录制前置条件与安全检查

在打开录制软件前，由执行人逐项确认。任一项不满足时，停止录制并先修正环境，不用剪辑掩盖问题。

| 检查项 | 必须满足的条件 |
| --- | --- |
| 账户与页面 | 已使用管理员账户登录；左侧菜单“系统管理”可见可进入，AI 智能体页签可用。 |
| 数据环境 | 使用可丢弃、可完整恢复的录制数据库；绝不连接生产库或含真实人员信息的库。 |
| 测试密钥 | 主路径：准备一枚可用的临时测试密钥 `[演示用 API Key]`（录制后立即轮换/清除）；输入框为密码掩码，画面不得展示明文。若无法提供有效密钥，改为备选路径：跳过“测试连接”，仅演示配置保存。 |
| 网络连通 | 主路径下录制环境可访问所配置服务商的接口地址；测试连接失败时从该镜头重录或切换备选路径。 |
| 运行状态 | 页面加载完成、无报错提示、浏览器/系统通知关闭，缩放和字体在 16:9 画面中清楚可读。 |
| 回滚 | 已明确录制结束后的恢复方式：还原该可丢弃数据库或按既有安全流程清理（含清除测试密钥）；不得对真实库做清理。 |

运行时只使用以下占位符替换为已核验的实际值：

- `[演示用 API Key]`（临时测试密钥，掩码输入，录制后轮换/清除）
- `[默认模型]`（如 DeepSeek 的可用模型选项）

### 2.1 录制效率提示

- **批次**：F-2（先行；第 18 支依赖本支配置成果）。
- **预置**：临时测试密钥 + 网络连通；无法提供有效密钥时走备选路径（跳过测试连接）。
- **一次通过要点**：①密钥绝不明文回显——掩码输入，不点"显示"图标；②测试连接为 toast（"连接成功：…"），无结果面板；③服务商仅 DeepSeek/火山方舟。
- **净录制预估**：约 25 分钟/遍。


## 3. 画面、操作与后期总规则

### 3.1 画面规格

- 成片画布为 **16:9**，建议交付 `1920 × 1080`；若源窗口比例不同，应在录制前调整可见区域或后期裁切，不能拉伸界面。
- 录制原始画面时关闭系统声音、应用提示音和通知；录屏只保留清晰的界面操作，AI 旁白在后期单独合成。
- 每个镜头只表达一个意图。页面、下拉菜单和对话框完全稳定后再开始操作；不录入加载抖动、无关菜单或鼠标试探。
- 需要突出字段时仅做克制的局部放大，放大前后保留页面方向感；不使用快速摇镜、夸张缩放或遮挡主要操作区的特效。

### 3.2 鼠标与停留规则

- 鼠标沿短路径移动，点击后离开关键文字；不要绕圈、反复悬停或用光标代替旁白。
- 打开页面、下拉列表或对话框后停留约 **1 秒**，让观看者看清标题和内容。
- API Key 为密码框：输入后不悬停暴露明文，不点击“显示”图标；测试连接等待结果时按钮呈加载态。
- 成功提示（“连接成功：…”与“AI 配置已保存”）保留 **0.8–1.5 秒**，随后再切换下一步。
- 出现任何可见错误、重复校验、错误数据、误点击或个人信息时，**从该镜头开头重录**；不要以裁切、马赛克或加速掩盖操作错误。

### 3.3 旁白与字幕规则

- 旁白使用经试听通过的中文 AI 声音；本包不指定具体供应商、声音名称或固定语速。
- 旁白应说明“为什么做”和“操作结果”，不逐字念出每次鼠标点击；画面中的按钮和字段由字幕辅助定位。
- 字幕与旁白同义、逐镜头校时。每条最多两行，避免遮挡表单字段、下拉列表、按钮及成功提示；字幕不出现密钥内容。
- 术语以实时构建为准：如录制构建调整了文案（含更换服务商），可替换字幕中的对应词，但不得改变“选服务 → 配密钥 → 测连接 → 选模型 → 保存”的业务顺序。

## 5. 录制执行清单

1. 按第 2 节完成可恢复环境检查，记录全部运行时占位符的实际值；确认测试密钥可用性与网络连通（或选定备选路径）。
2. 先静音录一遍完整画面；仅检查流程、隐私、光标和停留，不在此阶段生成旁白。
3. 回看原始录屏：任何数据泄露、加载异常、错误提示、密钥明文可见、误点“清除 Key”或模型清单操作、测试连接失败画面、或未能保存配置，都从受影响镜头开头重录。
4. 依据第 4 节生成 AI 旁白，先输出可试听音频，再与已确认的画面匹配；不要直接把未经试听的 TTS 音频导出为成片。
5. 依据字幕列制作字幕，逐句检查进入和离开时间；字幕出现应略早于或与对应动作同时，不应滞后到下一步。
6. 完成合成后，从头无中断观看一次；验收通过才导出交付版。录制结束后立即按预先确认的可恢复流程恢复环境并轮换/清除测试密钥。

## 6. 音频、剪辑与导出门禁

### 6.1 音频试听门禁

在最终合成前，至少由录制者完整试听一次 AI 旁白，并逐项通过：

- 声音自然、适合面向学校管理员的说明语气；
- 语速能让观看者同时看清表单、字段和操作，关键停顿自然；
- 音量在全片一致，未被系统声、背景音乐或提示音覆盖；
- “AI 智能体”“模型服务配置”“模型服务”“接口地址”“API Key”“测试连接”“默认模型”“保存配置”“AI 配置已保存”“已配置 Key”等中文术语发音正确；
- 无漏读、重读、截断、机械连读或难以辨识的词句。

任一项不通过时，只重生成或重校该段音频并复听；不要通过过度加速、压缩静音或堆叠背景音乐掩盖问题。

### 6.2 画面与字幕门禁

- 每个镜头都可独立看懂一个意图，转场不打断一次配置、测试或保存动作。
- 关键页面标题、表单字段、按钮“测试连接”“保存配置”、已配置回查和成功提示在 16:9 画面中可读。
- 字幕不遮挡表单字段、下拉列表、按钮或成功提示；无错别字、占位符、旧产品名称或历史样例数据；**画面与字幕均不得出现任何真实 API Key 明文**。
- 成片不得出现真实个人数据、管理员账号、令牌、文件路径、通知横幅、调试窗、密码管理器或录制工具控件。
- 导出为可播放的 16:9 MP4（H.264 视频与 AAC 音频为推荐兼容组合）；导出后使用独立播放器从头试听、查看字幕和核验总时长。

## 8. 当前实现依据与维护说明

本录制包依据当前界面和数据行为编写：

- `src/views/system/AiAgentConfig.vue`：模型服务配置卡（服务商下拉、接口地址、API Key 掩码输入与“测试连接”、默认模型、模型清单）、“保存配置”与“AI 配置已保存”提示；

界面文案或业务规则变动时，先以当前代码和实际构建复核，再同步更新本包；不要反向用本包覆盖当前产品事实。
