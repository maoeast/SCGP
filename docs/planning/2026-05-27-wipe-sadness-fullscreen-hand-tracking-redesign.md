# PRD · 擦亮坏心情 全屏沉浸 + 手势追踪改造

> SCGP 星愿能力发展平台 · 情绪训练模块 · 现有游戏重构
> 版本：v1.0 · 2026-05-27

---

## 一、改造目标

将"擦亮坏心情"从当前的"数据仪表盘"布局改造为"全屏沉浸 + 边缘 HUD"布局，并引入 MediaPipe 手势追踪支持大动作（Gross Motor）擦拭交互。

### 1.1 核心变化

| 维度 | 当前 | 改造后 |
|------|------|--------|
| 互动区 | 中心小方框（<20% 屏幕） | 全屏画布（>80% 屏幕） |
| 交互方式 | 仅鼠标/触摸指针 | 手势追踪 + 鼠标/触摸降级 |
| 信息展示 | 4 个巨大白色数据卡片 | 边缘 HUD 胶囊，半透明极简 |
| 指引文字 | 底部大段说明文字 | 中央 1 句指令，自动淡出 |
| 冰霜覆盖 | 仅覆盖小方框 | 覆盖整个背景 |

## 二、技术方案

### 2.1 手势追踪接入

**复用现有组件链：**
- `HandCameraLayer.vue`（共享摄像头 + 手势追踪壳）
- `useHandLandmarker` composable（MediaPipe HandLandmarker）
- `hand-game-gestures.ts` 工具函数

**集成模式：**
```html
<HandCameraLayer @primary-point="handlePrimaryPoint" @hands="handleHands">
  <!-- 全屏画布 + HUD 在此渲染 -->
</HandCameraLayer>
```

**手势映射：**
- `primaryPoint`（食指尖 landmark 8 的归一化坐标）→ 全屏画布擦拭位置
- 多手检测：两只手的食指尖都映射为擦拭点，双臂挥动 = 大面积擦拭
- pointer fallback：HandCameraLayer 自动降级到鼠标/触摸

### 2.2 全屏画布改造

**当前画布系统保留：**
- 双画布（frostCanvas 可见 + templateCanvas 离屏模板）
- 网格系统（Float32Array strength grid）
- 距离衰减侵蚀算法
- 霜冻重生机制（难度 2）

**改造点：**
1. `frostCanvas` 尺寸从 `scene-card` 内部尺寸改为 `window.innerWidth × window.innerHeight`
2. 网格覆盖整个屏幕
3. 擦拭输入从 canvas 内的 pointer 事件改为 HandCameraLayer 提供的归一化坐标
4. 背景风景图也从卡片内 SVG 改为全屏背景

### 2.3 HUD 设计

**顶部栏（半透明胶囊）：**
- 左侧：退出按钮 + 难度标签（如"简单 · 薄冰"）
- 右侧：学生姓名 + 设置按钮

**底部：**
- 全局进度条（粗条，高对比度），替代当前进度文字
- 进度条上方一行简短状态文字："越来越亮...太阳出来啦"

**中央（仅在 ready 阶段）：**
- 一句大字指令："挥动手臂，擦掉冰霜！"（开始擦拭后自动淡出）

**移除：**
- 4 个数据卡片（难度/进度/笔触/冰层厚度）
- 底部说明面板（大段文字）
- 庆祝后的徽章弹窗（简化为全屏庆祝动画）

## 四、难度配置保留

现有三级难度配置（DIFFICULTY_CONFIGS）完全保留，不改动：
- 难度 1：薄冰、快速融化、无重生
- 难度 2：冰霜重生、需连续擦拭
- 难度 3：厚冰（3 层）、需反复擦

唯一变化：brushRadius 可能需要根据屏幕尺寸动态调整（全屏后相对比例变化）。

---

## 五、摄像头布局

由于引入手势追踪，需要考虑摄像头画面放置：
- 摄像头画面放在**右上角小窗口**（约 160×120px），半透明，不遮挡游戏区
- 或者：使用 HandCameraLayer 内置的摄像头背景（低透明度）+ 右下角小窗口
- 当检测到手时显示绿色边框提示

## 六、注册表变更

需要更新 `CUSTOM_GAME_REGISTRY` 中 `G04_WIPE_ICE` 的条目：
- `requiredPermissions` 从 `[]` 改为 `['camera']`
- `permissionPolicy` 改为 `'degradable'`（允许无摄像头时降级为鼠标/触摸）
- tags 新增 `'手势追踪'`、`'MediaPipe'`
