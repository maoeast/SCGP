# 《教师：器材训练与记录》人工录制包

> **状态**：当前有效，待按本包录制与验收
> **产品**：SCGP / 星愿能力发展平台
> **受众**：首次使用系统的学校教师（管理员可代为录制）
> **成片目标**：2–3 分钟、16:9；先无声录屏，再配 AI 旁白和字幕
> **范围**：从器材训练入口组选择学生，连续录入两次器材训练，并在训练记录与器材训练记录页回查
> **系列**：本片为第六支，承接《教师：训练计划与训练记录》（第五支从训练计划进入快速录入，本片从器材训练菜单进入并演示连续录入与详情回查）；学生档案与班级已就绪。
> **不作为事实来源**：`output/videos/管理员：班级与学生管理.mp4`、`scripts/video/` 及其旧分镜仅为历史参考，不能复用其时长、分辨率、样例数据、旁白、选择器或语音配置。

## 1. 本片要解决什么

本片演示教师不经过训练计划、直接通过“器材训练”菜单完成一次完整的器材训练录入：选择训练入口组、选择学生、在快速录入页连续记录两次训练，最后在训练记录菜单与器材训练记录页回查。

器材训练是训练记录主链（明细表 + `training_session` 统一主表）的主要入口之一；“保存并继续”支持同一学生连续录入多条记录，适合一次训练课内多件器材的场景。本片只说明这一业务结果，不承诺替代学校既有的训练、评估或档案流程。

### 角色与范围边界

- 录制账户为**教师或管理员**，旁白以“教师”指代操作者（器材训练对教师开放）；不得把操作表述为学生、家长或其他角色。账号信息不出现在画面中。
- 演示页面依次为：器材训练 → 训练入口组卡片 → 选择学生 → 快速录入（保存并继续 / 保存记录）→ 训练记录菜单 → 对应入口的“器材训练记录” → 详情跳转的“器材训练记录”页（高亮定位）。
- 仅使用一名虚构学生与产品演示数据中的器材；不展示真实姓名、学号、照片、诊断、联系方式或真实训练记录。
- 不演示：训练计划或首页日程来源入口、删除记录、导出报告、IEP 训练评语、游戏训练、“继续为该生录入”按钮。
- 不演示导入、数据库替换、数据抽取、演示 ZIP 修改或产品数据目录写入。`docs/guides/seed-demo-data.md` 仅可作为历史参考，不是本片的执行路径。

## 2. 录制前置条件与安全检查

在打开录制软件前，由执行人逐项确认。任一项不满足时，停止录制并先修正环境，不用剪辑掩盖问题。

| 检查项 | 必须满足的条件 |
| --- | --- |
| 账户与页面 | 已使用教师或管理员账户登录；左侧菜单“器材训练”“训练记录”可见可进入。 |
| 数据环境 | 使用可丢弃、可完整恢复的录制数据库；绝不连接生产库或含真实人员信息的库。 |
| 虚构学生 | 一名虚构学生 `[虚构学生姓名]` 已建档，且对录制账户可见（教师账户受数据范围限制时，改用管理员账户录制）。 |
| 器材资源 | `[对应的训练入口]`（推荐“感官统合训练”）下存在至少两件可用器材 `[已选定的器材甲]`、`[已选定的器材乙]`；入口卡片计数可见；对应能力包已激活。 |
| 训练入口 | 训练记录菜单中存在同一训练入口，其“器材训练记录”初始为空或能与本次记录明确区分。 |
| 运行状态 | 页面加载完成、无报错提示、浏览器/系统通知关闭，缩放和字体在 16:9 画面中清楚可读。 |
| 回滚 | 已明确录制结束后的恢复方式：还原该可丢弃数据库（含本次两条训练记录）或按既有安全流程清理；不得对真实库做清理。 |

运行时只使用以下占位符替换为已核验的实际值，不在脚本中预设具体学生名、入口或器材：

- `[对应的训练入口]`（推荐“感官统合训练”）
- `[虚构学生姓名]`
- `[已选定的器材甲]`
- `[已选定的器材乙]`

### 2.1 录制效率提示

- **批次**：C-2（紧随第 5 支，复用器材与学生）。
- **预置**：两件器材；训练记录入口初始为空或可区分。
- **一次通过要点**：①"保存并继续"无弹窗（toast"保存成功"），"保存记录"弹"录入成功"；②菜单来源下"返回学生列表"回器材选人页；③回查走"查看详情"→高亮定位（recordId 驱动）。
- **净录制预估**：约 30 分钟/遍。


## 3. 画面、操作与后期总规则

### 3.1 画面规格

- 成片画布为 **16:9**，建议交付 `1920 × 1080`；若源窗口比例不同，应在录制前调整可见区域或后期裁切，不能拉伸界面。
- 录制原始画面时关闭系统声音、应用提示音和通知；录屏只保留清晰的界面操作，AI 旁白在后期单独合成。
- 每个镜头只表达一个意图。页面、下拉菜单和对话框完全稳定后再开始操作；不录入加载抖动、无关菜单或鼠标试探。
- 需要突出字段时仅做克制的局部放大，放大前后保留页面方向感；不使用快速摇镜、夸张缩放或遮挡主要操作区的特效。

### 3.2 鼠标与停留规则

- 鼠标沿短路径移动，点击后离开关键文字；不要绕圈、反复悬停或用光标代替旁白。
- 打开页面、入口卡片、对话框或下拉列表后停留约 **1 秒**，让观看者看清标题和内容。
- 镜头 4 的两次录入之间可用跳剪压缩；每次录入的表单与器材选择稳定后再操作。
- 成功提示（“保存成功”）与“录入成功”对话框保留 **0.8–1.5 秒**，随后再切换下一步。
- 出现任何可见错误、重复校验、错误数据、误点击或个人信息时，**从该镜头开头重录**；不要以裁切、马赛克或加速掩盖操作错误。

### 3.3 旁白与字幕规则

- 旁白使用经试听通过的中文 AI 声音；本包不指定具体供应商、声音名称或固定语速。
- 旁白应说明“为什么做”和“操作结果”，不逐字念出每次鼠标点击；画面中的按钮和字段由字幕辅助定位。
- 字幕与旁白同义、逐镜头校时。每条最多两行，避免遮挡器材卡片、表单字段、对话框底部按钮及成功提示。
- 术语以实时构建为准：如录制构建调整了文案（含更换入口或器材），可替换字幕中的对应词，但不得改变“选入口 → 选学生 → 快速录入 → 保存记录 → 记录回查”的业务顺序。

## 5. 录制执行清单

1. 按第 2 节完成可恢复环境检查，记录全部运行时占位符的实际值。
2. 先静音录一遍完整画面；仅检查流程、隐私、光标和停留，不在此阶段生成旁白。
3. 回看原始录屏：任何数据泄露、加载异常、错误提示、误点“删除”“导出报告”或“继续为该生录入”、误入游戏训练或计划/日程来源、或未能回查与高亮定位本次记录，都从受影响镜头开头重录。
4. 依据第 4 节生成 AI 旁白，先输出可试听音频，再与已确认的画面匹配；不要直接把未经试听的 TTS 音频导出为成片。
5. 依据字幕列制作字幕，逐句检查进入和离开时间；字幕出现应略早于或与对应动作同时，不应滞后到下一步。
6. 完成合成后，从头无中断观看一次；验收通过才导出交付版。录制结束后立即按预先确认的可恢复流程恢复环境。

## 6. 音频、剪辑与导出门禁

### 6.1 音频试听门禁

在最终合成前，至少由录制者完整试听一次 AI 旁白，并逐项通过：

- 声音自然、适合面向学校教师的说明语气；
- 语速能让观看者同时看清表单、字段和操作，关键停顿自然；
- 音量在全片一致，未被系统声、背景音乐或提示音覆盖；
- “器材训练”“快速录入”“保存并继续”“保存记录”“录入成功”“训练记录已成功保存！”“返回学生列表”“训练记录”“器材训练记录”“查看详情”等中文术语发音正确；
- 无漏读、重读、截断、机械连读或难以辨识的词句。

任一项不通过时，只重生成或重校该段音频并复听；不要通过过度加速、压缩静音或堆叠背景音乐掩盖问题。

### 6.2 画面与字幕门禁

- 每个镜头都可独立看懂一个意图，转场不打断一次选入口、选学生、录入或回查动作。
- 关键页面标题、入口卡片、器材列表、表单字段、按钮“保存并继续”“保存记录”“返回学生列表”和高亮记录卡在 16:9 画面中可读。
- 字幕不遮挡器材列表、表单字段、对话框底部按钮或成功提示；无错别字、占位符、旧产品名称或历史样例数据。
- 成片不得出现真实个人数据、教师/管理员账号、令牌、文件路径、通知横幅、调试窗、密码管理器或录制工具控件。
- 导出为可播放的 16:9 MP4（H.264 视频与 AAC 音频为推荐兼容组合）；导出后使用独立播放器从头试听、查看字幕和核验总时长。

## 8. 当前实现依据与维护说明

本录制包依据当前界面和数据行为编写：

- `src/views/equipment/EquipmentMenu.vue`：器材训练入口组卡片（已激活 tag、器材计数、授权过滤）；

界面文案或业务规则变动时，先以当前代码和实际构建复核，再同步更新本包；不要反向用本包覆盖当前产品事实。
