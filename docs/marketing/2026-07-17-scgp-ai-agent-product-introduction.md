## 一、建议的营销传播方向

### 方向一：特殊教育教师的专业工作伙伴（推荐主方向）

核心表达：把 AI 放进教师真实工作流程，帮助教师更快完成个别化教学设计、课堂沟通支持、成长观察、家校沟通和情绪支持等日常工作。

推荐口号：**让专业支持更及时，让每名学生都被认真看见。**

适用场景：官网首屏、产品彩页、展会介绍、教育主管部门及学校客户方案。

### 方向二：从平台数据到教学行动的智能连接器

核心表达：AI 助手可在教师授权和明确指令下调用学生档案、评估记录、训练记录和器材资源，将分散的数据转化为备课建议、观察线索、训练计划和阶段性报告草案。

推荐口号：**让数据不只被记录，更能服务下一步教学。**

适用场景：产品演示、数字化校园方案、能力平台升级方案和招投标介绍。

### 方向三：学校可配置、可治理的智能体平台

核心表达：系统提供内置智能体、专业知识技能库、工具权限和自定义智能体配置。学校可按实际岗位和业务场景启停智能体、选择知识资料、限定可调用工具，并统一管理模型服务和使用额度。

推荐口号：**一套平台，构建学校自己的 AI 专业助手团队。**

适用场景：集团校、区域平台、资源中心和有二次配置需求的客户。

### 方向四：面向教师场景的安全边界设计

核心表达：内置智能体统一采用教师端角色边界，强调客观记录、个别化判断和学校协作流程，不输出医学诊断，不替代正式评估、治疗决策或危机处置。

推荐口号：**AI 提供工作支持，专业决定始终由人作出。**

适用场景：校方管理者沟通、产品可信度说明、采购论证和项目验收材料。

### 方向五：开放模型接入与成本可控

核心表达：平台提供 DeepSeek、豆包（火山方舟）模型服务配置，可设置接口地址、模型或接入点、月度预算和超额控制，让学校根据能力、成本和部署条件选择模型服务。

推荐口号：**模型灵活选择，能力统一管理，使用成本心中有数。**

适用场景：技术交流、信息中心汇报和软件技术参数说明。

## 二、产品定位

SCGP AI 助手智能体是星愿能力发展平台面向特殊教育、融合教育和资源教室教师打造的智能工作支持系统。它将大模型对话能力、学校业务数据、专业知识技能和本地工具调用整合在同一个教师工作台中，支持教师围绕具体学生、具体情境和具体目标开展备课、观察、沟通、复盘与文档整理。

教师可以从系统首页直接选择所需智能体，也可以在任意业务页面打开全局 AI 助手。系统通过场景化智能体明确角色与专业边界，通过知识技能提供方法支持，通过工具调用连接 SCGP 中已有的学生、评估、训练和器材数据，帮助教师缩短资料查找和文档整理时间，把更多精力留给观察、互动与教学决策。

## 三、内置 AI 智能体

| 智能体 | 产品角色 | 主要支持内容 |
| --- | --- | --- |
| 一人一策 | 个别化教学专家 | 个别化目标、课堂调整、资源教室训练、视觉提示、任务分解、环境与材料适配 |
| 沟通有方 | 课堂沟通支持专家 | 语言理解、功能性表达、视觉沟通、图片选择、等待时间和替代沟通支持 |
| 成长看得见 | 成长观察助手 | 将零散课堂观察整理为客观、连续、可复盘的记录和协作线索 |
| 家校好好说 | 家校沟通助手 | 根据已确认事实起草微信、电话或面谈内容，减少标签化表达，促进合作 |
| 心晴陪伴 | 情绪支持助手 | 帮助教师识别情绪与行为变化，整理课堂支持、家校协作和校内转介步骤 |

五个内置智能体均提供场景简介、能力标签和快捷提问示例。管理员可按学校实际需要启用或停用，也可创建自定义智能体，配置角色提示词、可调用工具和专业知识技能。

## 四、产品特点

### 1. 场景化智能体，覆盖教师高频工作

AI 能力以教师任务为入口组织，回答结构更贴近备课、训练、观察和沟通流程。教师无需从空白问题开始，可通过首页智能体卡片和快捷提问快速进入工作情境。

### 2. 连接平台数据，减少重复查找与整理

在教师明确指定对象和用途后，智能体可按授权工具查询学生档案、评估记录、训练场次和器材资源。系统将查询结果返回给当前智能体，用于生成更贴近实际记录的建议和草案。

### 3. 专业知识技能库，支持持续扩展

当前系统内置 7 类知识技能，涵盖特殊教育、融合训练调整、课堂沟通与言语支持、发展观察、蒙氏活动设计、家校沟通和儿童青少年心理支持。知识技能由主体内容和引用资料组成，可按智能体选择需要注入的资料，兼顾专业性、上下文长度与模型使用成本。

管理员还可新增、编辑、启停和删除本地自定义知识技能，并维护适用角色、风险等级、证据说明、许可和来源信息，为学校沉淀本地经验提供统一入口。

### 4. 工具调用，让 AI 从“回答”走向“协助完成”

平台当前提供 8 项 AI 工具能力，包括学生列表查询、学生详情查询、学生搜索、评估记录查询、训练记录查询、器材查询、本月 AI 用量查询和 Word 报告生成。每个智能体通过工具白名单获得与其职责相匹配的能力，未挂载工具会被系统拒绝调用。

### 5. 支持图片与常用办公文档理解

在模型具备视觉能力时，教师可添加图片进行辅助分析；系统还支持读取带文本层的 PDF、Word（.docx）和 Excel（.xlsx）文件，将提取到的文本纳入当前对话。该能力适合处理脱敏后的课堂材料、观察记录和表格资料。

### 6. 对话留存与报告输出

系统支持按当前用户保存历史会话、切换会话和删除会话。具备报告工具的智能体可将确认后的内容组织为结构化 Word 文档，用于训练计划、观察总结、评估摘要等材料的后续编辑与归档。

### 7. 模型、额度和启用状态统一管理

管理员可切换模型服务，配置 API Key、接口地址和默认模型，查看当月消息与估算费用，设置月度预算、超预算截断和 AI 总开关。模型服务与全局 AI 能力可分别启停，便于学校按阶段开展试用和推广。

## 五、产品优势

### 懂场景

内置智能体围绕特殊教育教师的真实工作设计，能够根据目标、观察事实、环境条件和可用材料组织建议，减少通用问答与具体教学任务之间的距离。

### 懂数据

AI 助手与 SCGP 的学生、评估、训练、器材和报告能力相连接。教师在同一平台内即可完成资料查询、内容整理和报告输出，形成从记录到支持建议的连续工作链。

### 可配置

智能体角色、工具权限、知识技能和引用资料相互独立。学校既可直接使用内置方案，也可按本地教研成果、岗位职责和管理要求创建自定义智能体与知识技能。

### 可治理

平台提供智能体启停、知识来源与风险元数据、工具白名单、管理员会话管理、AI 总开关、模型服务开关和预算控制，便于学校建立清晰的使用边界。

### 可延展

AI 子系统采用模型服务、智能体、知识技能和工具能力分层设计。随着 SCGP 业务模块完善，可继续扩展新的教师工作场景、知识资料和平台工具，而无需改变教师统一使用入口。

## 六、典型应用场景

1. **资源教室备课**：围绕一名学生的目标、近期训练表现和可用材料，生成 20—30 分钟的活动结构与观察点。
2. **课堂参与调整**：在保留训练目标的前提下，调整任务步骤、视觉提示、沟通方式、等待时间和环境条件。
3. **训练复盘**：查询指定学生的近期训练记录，归纳稳定变化、支持程度和下一次需要验证的问题。
4. **客观观察记录**：将口语化课堂描述整理为“情境—行为—支持—结果”的事实性记录。
5. **家校沟通准备**：根据已确认的课堂事实和共同目标，生成微信草稿、电话提纲或面谈要点。
6. **器材与活动参考**：结合目标和能力标签查询平台器材资源，为教师提供活动设计参考。
7. **文档与报告整理**：读取脱敏后的 PDF、Word 或 Excel 材料，结合平台记录生成可继续编辑的 Word 草案。
8. **情绪与危机识别支持**：对一般情绪和行为变化提供观察、课堂稳定和协作建议；遇到高风险线索时提示教师立即启动学校既有流程。

## 七、主要技术参数

| 参数类别 | 当前产品参数 |
| --- | --- |
| 产品形态 | Windows 桌面应用中的教师端 AI 助手 |
| 平台技术栈 | Electron + Vue 3 + TypeScript + Vite + SQL.js |
| 当前版本 | V1.0.6 |
| 内置智能体 | 5 个教师场景智能体 |
| 内置知识技能 | 7 类专业知识技能，支持主体与引用资料分层选择 |
| AI 工具 | 8 项平台工具，支持按智能体白名单配置 |
| 模型服务 | 内置 DeepSeek、豆包（火山方舟）配置；接口地址和模型/接入点可配置 |
| 模型能力标识 | 可识别并展示视觉、工具调用和深度思考等服务能力位，实际能力取决于所配置模型服务 |
| 对话方式 | 支持流式文本输出；工具调用模型采用多轮工具执行流程 |
| 附件类型 | 图片，以及 PDF、.docx、.xlsx 文档 |
| 附件限制 | 单张图片不超过 5 MB；单个文档不超过 10 MB；文档文本提取上限为 20,000 字符 |
| 报告输出 | 支持生成 .docx 格式 Word 文档 |
| 会话管理 | 当前用户历史会话、本地消息记录、会话删除；管理员可查看和管理全部会话 |
| 数据存储 | 会话、配置和用量记录保存在本地 SQL.js 数据库；附件保存于本机应用数据目录 |
| API Key | 加密保存于本地数据库，调用模型服务时在 Electron 主进程解密使用 |
| 用量控制 | 月度费用估算、月度预算、超预算截断、模型服务开关和 AI 总开关 |
| 网络要求 | AI 对话需要连接已配置的第三方模型服务；平台本地业务功能不以 AI 服务为前提 |

## 八、对外宣传推荐文案

### 100 字精简版

SCGP AI 助手智能体是面向特殊教育与资源教室教师的智能工作伙伴。系统内置个别化教学、课堂沟通、成长观察、家校沟通和情绪支持五类智能体，可连接学生档案、评估、训练和器材数据，支持专业知识注入、文档理解与 Word 报告生成，让教师从资料整理到教学支持拥有更连贯、更高效的数字化工作体验。

### 300 字标准版

SCGP AI 助手智能体是星愿能力发展平台面向特殊教育、融合教育和资源教室教师打造的智能工作支持系统。产品内置“一人一策”“沟通有方”“成长看得见”“家校好好说”“心晴陪伴”五类教师场景智能体，覆盖个别化教学设计、课堂沟通支持、成长观察、家校协作和情绪支持等高频工作。

AI 助手可在教师明确指令下调用平台中的学生档案、评估记录、训练记录和器材资源，将已有数据转化为备课建议、观察线索、沟通草案和可编辑的 Word 报告。系统同时提供专业知识技能库、自定义智能体、工具权限、模型服务、预算额度和启停管理，帮助学校在统一入口中建设符合自身业务特点的 AI 助手团队。通过场景、数据、知识和工具的协同，SCGP 让 AI 真正进入教师工作流程，让每一次记录更有价值，让每一步支持更有依据。

## 九、适用边界说明

当前 AI 助手面向已登录教师、资源教室工作人员和学校管理人员，不提供学生端对话。系统输出用于工作辅助和草案生成，不构成医学或心理诊断，不替代正式评估、治疗、个别化教育决定、学校管理流程或危机处置。

当教师使用第三方模型服务时，当前问题、所附材料以及经工具查询并进入对话上下文的数据，会按任务需要发送至所配置的模型服务。正式使用前应按学校制度完成授权、脱敏、账号权限和模型服务条款确认，避免上传与当前任务无关的可识别个人信息。

## 十、建议的公司营销组合

对外传播建议采用“方向一 + 方向二”为主叙事，以“方向三 + 方向四”为采购可信度支撑，以“方向五”为技术参数补充：

- 官网和宣传册突出“特殊教育教师的专业工作伙伴”；
- 产品演示重点展示“选择智能体—查询平台记录—形成建议—导出 Word”的完整链路；
- 面向校长和管理者强调可配置、可启停、可控额度和角色边界；
- 面向信息化负责人说明本地数据底座、模型服务配置和附件支持；
- 面向招投标材料将功能描述拆成可验证参数，避免使用无法验收的效果承诺。
